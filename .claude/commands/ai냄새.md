# AI 냄새 빼기

대상: **$ARGUMENTS** (비어 있으면 사용자가 뒤에 붙여넣은 글, 그것도 없으면 무엇을 볼지 한 줄로 묻는다.)

판정 체계는 epoko77-ai/im-not-ai (MIT) 의 humanize-korean 분류를 쓴다.
**플러그인을 설치하지 마라.** 규칙은 아래에 다 있다. 더 깊이 봐야 하면
https://github.com/epoko77-ai/im-not-ai 의

## 0. 실패하는 두 가지 방식

첫째, 멀쩡한 글을 고친다. 사람이 공들여 쓴 문장에 규칙을 대면 뭐라도 걸린다.
원 저장소가 직접 경고한다 — 2020년 사람이 쓴 글이 쉼표 습관 하나로
최고 위험 판정을 받은 실측 사례가 있다. 지표 하나로 판정하지 마라. 겹칠 때만 신호다.

둘째, 빼면서 새로 심는다. 결말을 다듬다가 "결국", "~하는 이유다"를
없던 자리에 만들어 넣는다. 원래 있던 것보다 나쁘다.

그래서 순서를 강제한다. 진단 → 보고 → 승인 → 수정. 진단 없이 고치지 마라.

## 1. 절대 건드리지 않는 것

- 금액·날짜·인원·시간 — 250만/330만, 25명, 140분, D-149, 예식 일시
- 고유명사 — 모먼트에디트, Moment Edit, Kawana Miku, 캔들존, 화이트존, 향동
- 법률·계약 문구 — contract/ 전체, privacy.html, 개인정보처리방침, 청약철회,
  위약 구간, 현금영수증 안내. **이 파일들은 아예 열지 마라.**
- UI 라벨·버튼·폼 안내문 — 짧은 게 정상이다. 리듬 규칙을 대지 마라
- 내용 앵커 — 각 문장의 핵심 명사는 결과에도 최소 한 번 원형 그대로 남긴다

## 2. 브랜드 선

- 금지어: 가성비 · 저렴한 · 할인 · 패키지 · 느낌표
- 전각 줄표(—) 대신 ·
- 문장을 활기차게 만들지 마라. 차분한 게 의도다
- 원문이 "~합니다"면 결과도 "~합니다". 평어체로 떨어뜨리지 마라
- 짧은 문장이 많은 건 랜딩 페이지의 의도다. 에세이 기준을 웹 카피에 대지 마라

## 3. 진단 — 임계를 넘은 것만 센다

| ID | 패턴 | 임계 | 고칠 방향 |
|---|---|---|---|
| D-1 | 결론적으로·정리하자면·요약하면·이를 통해·그러므로 | 3회 초과 | 1~2개만 남기고 삭제 |
| D-2 | 시사하는 바가 크다·주목할 만하다·매우 중요하다 | 1회+ | 삭제 또는 구체 결론 |
| D-3 | 크게 세 가지로·다음과 같은 | 1회+ | 도입구 빼고 바로 본론 |
| D-4 | 혁신적·획기적·압도적·파격적·폭발적 | 3회+ | 구체 수치·사실로 |
| D-5 | 의인화 주어 "기술이 묻는다" | 1회+ | 사람·기관 주어로 |
| D-6 | ~할 때입니다·~시점입니다 | 2회+ | 구체 동사 단언으로 |
| D-8 | 분열문 "필요한 것은 X이다"·"핵심은"·"문제는" | 2회+ | "X가 필요하다" 직결 |
| D-10 | 문말 도치 "~하는 이유입니다" | 2회+ | "그래서 ~다" 순방향 |
| A-7 | 가지고 있다 | 1회+ | "경쟁력이 강하다" |
| A-8 | 이중 피동 되어진다·보여집니다 | 1회+ | 능동 또는 단일 피동 |
| I-1 | ~한 것입니다·~일 것입니다 | 연속 3회+ | 일부만 "~다"로 |
| I-3 | ~다는 것입니다·~다는 뜻입니다 | 2회+ | "~다" 직접 종결 |
| C-8 | "A가 아니라 B" 대구 | 2회+ | 한 번은 남긴다. 전멸 금지 |
| C-10 | 콜론 부제 헤딩 "X: Y" | 2회+ | 단일 명사구로 압축 |
| H-4 | "즉" 남발 | 2회+ | "곧" 또는 생략 |
| F-5 | "~적 N" 체인 (전략적 함의) | 3회+ | "전략 함의" |

수치 지표
- 쉼표 든 문장 비율 — 사람 26.3% · AI 61.0%. 50% 넘을 때만 신호
- 연결어미 뒤 쉼표 (~하고, ~하며,) — 15% 넘을 때만
- 문장 길이 균일 + 100자 이상 부재 — 긴 산문에만 적용. 랜딩·UI 제외

세는 건 손으로 하지 말고 스크립트를 짜서 재라. 눈대중 금지.

## 4. 보고 — 고치기 전에 내놓고 멈춘다

🔍 진단 — (대상) · 문장 N개 · M자

걸린 것
 · D-8 분열문 3건 (임계 2)
     L42 「중요한 것은 속도입니다」

안 걸린 것
 · D계열 나머지 · A계열 · 리듬 — 전부 임계 이하

판단
 · (고칠 값이 있는가. 없으면 "손댈 것 없음")

수정안
 · L42  중요한 것은 속도입니다 → 속도가 중요합니다

아무것도 임계를 안 넘으면 "손댈 것 없음"으로 끝낸다. 억지로 찾지 마라.
그게 이 명령의 정상 종료 중 하나다.

## 5. 수정 — 승인 후에만

- 수정안에 적은 것만 고친다. 김에 다른 걸 손보지 마라
- 변경률 30% 넘으면 경고, 50% 넘으면 중단하고 롤백. 재서 보고해라
- 고친 뒤 자체 점검 — 금액·날짜·고유명사 100% 보존됐는가.
  격식 등급 그대로인가. 없던 관용구를 새로 심지 않았는가
- git diff 를 붙여 무엇이 바뀌었는지 보인다
