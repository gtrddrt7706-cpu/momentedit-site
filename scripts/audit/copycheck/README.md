## ★번호가 겹칩니다 — 배타표에서 반드시 갈라야 합니다
진행 클립 06·07·21·22 와 배역 클립 06·07·19·21·22 가 **다른 셈판인데 번호가 같습니다.**
그냥 두었더니 배타 묶음이 뒤엉켜 «22와 23이 같이 나가는 예식»이라는 있을 수 없는 조합이
만들어졌고, 거기서 「지켜봐」가 두 번으로 잡혔습니다.
→ 이 묶음에서는 배역 쪽에 `06w`·`07w`·`19c`·`21c`·`22c` 를 붙였습니다.
저장소에 넣으실 때 그쪽 실제 키로 바꿔 주십시오.

## 배타 갈래를 반드시 적어 주십시오
`json` 의 `excl` 이 «한 예식에 하나만 나가는 묶음»입니다. 이게 틀리면 검사가 통째로 틀립니다.
- 안 적으면 → 있을 수 없는 조합을 겹침으로 셉니다
- **짝으로 잘못 묶으면 → 실제로 나갈 수 있는 조합을 통째로 못 봅니다** (입장에서 실제로 났던 일)

## ★항목을 새로 넣으면 자가시험도 함께
`selftest-check.py` 에 «그 항목이 빨개지는 고장»을 넣어 주십시오. 그게 없는 항목은 있으나 마나입니다.
오늘 이 자가시험이 **자기 자신의 고장**을 하나 잡았습니다 — 회차 목록을 손으로 적어 둬서
4회차를 건드리는 시험 셋이 조용히 헛돌았습니다.
