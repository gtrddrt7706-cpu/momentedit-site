★**tone32.json 에서 원문으로 되돌렸습니다.** 사장님이 「제한 때문에 개선 못 하는 일은 없다」 하셨으니

### 그래서 여쭙니다 — 이 줄, 누가 왜 잠갔습니까?

| | |
|---|---|
| 지금 | 이제 두 사람이 천천히, 함께 내립니다. |

③ 「두 사람이」로 여는 문장이 한 예식에 **셋**이 되어 문턱에 걸립니다(헌정·선언·케이크).

**사장님 문면이면 그대로 둡니다.** 게이트 닻일 뿐이면 chk 를 새 글자로 옮겨 주십시오.
사장님 판정 화면에도 «누르실 필요 없음»으로 적어 올렸습니다.

★그리고 그쪽 경고 그대로 적어 뒀습니다 — **이 tsv 는 «지금 이 순간»의 사진**이라 원본으로 안 삼고,

## 3. 헌정 `plain` 셋 닫는 문장 — ★**이미 `tone32.json` 안에 있습니다**

「아직 안 왔다」 하셨는데, 셋째 판 `tone32.json` 에 들어 있습니다. 못 찾으신 것 같아 여기 옮깁니다.

| 벌 | 전 | 후 |
|---|---|---|
| `tribute·flower·plain` | **이제,** 두 사람이 부모님께 꽃을 드리러 **갑니다.** / **두 사람이** 천천히 다가갑니다. | 두 사람이 부모님께 꽃을 **드립니다.** / 천천히 다가갑니다. |
| `tribute·bow·plain` | **이제,** 두 사람이 부모님께 큰절을 올립니다. / 두 사람이 **천천히 다가갑니다.** | 두 사람이 부모님께 큰절을 올립니다. / **천천히 자리를 잡습니다.** |
| `tribute·hug·plain` | **이제,** 두 사람이 부모님께 갑니다. / 말없이 안아 드리는 자리입니다. / 두 사람이 천천히 다가갑니다. | 두 사람이 부모님께 갑니다. / 말없이 안아 드리는 자리입니다. **(셋째 줄 삭제)** |

- **「이제,」 셋 다 뺐습니다.**

- 따뜻판 셋도 전부 「두 분, 부모님께 다가가 주세요」로 똑같이 닫던 것을 갈랐습니다(「다가가 주세요」 / 「앞에 서 주세요」 / 「가 주세요」).
