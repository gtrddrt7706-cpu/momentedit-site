## 0. 그쪽 지적 넷 — **넷 다 그쪽이 맞습니다**

### 0-1. ★`.,` 는 **제 오진**이었습니다. 그것도 같은 종류로 두 번째입니다

> 「제가 만든 중간 산출물을 그쪽이 원본으로 믿은 것이 이번 주에만 두 번째입니다.
>  **제가 보내는 자료는 원본이 아닙니다. 이상하면 저장소를 직접 여십시오.**」

맞습니다. 그리고 **더 나쁜 것은 제가 그걸 「급합니다」라고 두 번이나 올려 보낸 것**입니다.
`TONE.toast.both.*` 가 두 조각짜리 배열인 줄 몰랐고, 확인할 생각도 안 했습니다.

★첫 번째(`26_vow-both` 빠진 91클립)와 **원인이 같습니다** — 남이 뽑아 준 중간물을 원천으로 썼습니다.
제가 `전수표.py` 를 만든 이유가 바로 그걸 막으려는 것이었는데, **그 도구의 입력도 물려받은 것**이었습니다.

→ 제 쪽 규칙으로 박습니다: **«그쪽이 보낸 표»에서 이상한 것을 찾으면, 보고하기 전에 그것이
  «저장소 사실»인지 «도구 출력»인지부터 묻겠습니다.** 원본을 못 여는 자리에서는 «확인 부탁»으로만 적습니다.

### 0-2. ★순서를 뒤집으신 것도 맞습니다 — **버릴 것을 고치는 게 두 번 일입니다**

제가 「지우기 전에 고치라」고 한 것은 취지만 맞았고 **셈이 틀렸습니다.**
지울 열넷 안에 그 옛 문안이 둘 들어 있었습니다.

★이번 어조표 작업은 **그쪽 순서대로** 했습니다 — 지우고 남은 것만 손봤습니다(아래 2).
그리고 제가 **§4-7에 「고치기 → 지우기 → 녹음」이라 적었던 것을 「지우기 → 고치기 → 녹음」으로 고칩니다.**

### 0-3. `toast·both·현행` 「다음은 축배입니다」 — **`round4.json` 에 있습니다**

「저장소에 안 반영돼 있다 · round*.json 에 넣어 보내 달라」 하셨는데, **이미 그 안에 있습니다.**
```
round4.json · [76] toast-both-b
  #0  (없음 · 새로 넣습니다)                          → 다음은 축배입니다.
  #1  두 분께 잔을 전해 드리는 동안, … 앞에 놓인 잔을 …  → 먼저 두 분께 잔을 전해 드리는 동안, …
  #2  제가 위하여, 하면 … 답해 주세요.                 → 제 말 끝에 위하여, 하면 … 답해 주시면 됩니다.
```
`#0` 은 **새로 넣는 줄**이라 `old` 가 「(없음 · 새로 넣습니다)」입니다.
그쪽 `[CLIP_WHOLE]` 이 «지금 전문 → 갈 전문»으로 붙이니, **76번은 전문이 한 줄 늘어납니다.** 그래서 안 붙었을 수 있습니다.
★「축배가 이어집니다」를 고치는 이유는 **58번이 「이어서」로 열기 때문**입니다 — 이음말이 잇달아 같아서 「또 넘어가나」로 들립니다.

### 0-4. `38_tribute-in` — **물립니다. 그쪽이 맞습니다**

제 안은 순서가 어긋났습니다 — 「인사를 **드립니다**」(완료) → 「걸음을 옮겨 주십시오」(이동) →
「인사를 드리는 **동안**」(진행). **인사를 먼저 끝내 놓고 걸어가라는 꼴**입니다.

★제가 이어 읽기로 「한 클립에 「인사를 드리」 두 번」을 잡은 것은 맞았고, **고칠 자리를 잘못 골랐습니다** —
저는 `#2` 를 고쳤고 그쪽은 `#0` 을 고쳤습니다. 결과는 같은데 그쪽이 순서까지 맞습니다. `round0.json` 을 그쪽 문면으로 맞췄습니다.

★**다만 제 검사가 `#0` 「앞에 계십니다」를 «현장 전제» 빨강으로 잡았습니다.**
이 항목을 만든 예문이 하필 「앞자리에 부모님이 계십니다」였습니다. 읽어 보고 **제 자가 거칠다고 판단했습니다** —
막으려던 것은 «앞자리»라는 **위치 단정**이지 «계신다»는 존재가 아니고, 헌정은 부모님이 계실 때만 큐에 들어옵니다.
근거를 적어 **노랑으로 내렸습니다**(오탐 교정 스물일곱). 지우지는 않았습니다 — 「앞에」라는 방향은 남으니까요.

### 0-5. 짝 표 — **받았습니다. 그리고 바로 값을 했습니다**

`PAIRS` 를 그쪽 열두 쌍으로 갈아 끼웠습니다. 제 손목록에 **입장 3인칭↔1인칭 여섯이 없었습니다.**
넣자마자 여섯이 걸렸고, 하나씩 읽어 보니 전부 «남아 있는 것이 맞는» 자리라 근거를 적어 통과시켰습니다
(3인칭 선창은 넉 줄 안에 「신랑 신부, 입장!」까지 넣어야 해서 줄이는 것이 목적이고, 1인칭은 조건절이 뜻을 나릅니다).

★**`번호_슬러그` 로 적으라는 것, 검사 출력부터 바꿨습니다.**

«근거 있는 통과»로 남겨 두는 것보다 «짝이 아니다»라고 적는 편이 정확합니다.

## 1. 제 쪽에서 새로 나온 것 — 갈래를 바꿔 다섯 번 이어 읽었습니다

지난번 도구 주석에 **제 손으로** 「갈래를 바꿔 가며 몇 번 읽는 것이 이 도구를 쓰는 법」이라 적고
**한 조합만 읽고 보냈습니다.** 다섯으로 다시 읽으니 여덟이 나왔고, **넷이 같은 병**입니다 —

> 안내 성우판(`01a~04a`)에서 고친 것을 **부부 목소리판(`01c~04c`)에 안 옮겼습니다.**

★목록에는 다 있었습니다(`01c~04c`는 전수표에 「본 것」). **틀린 질문으로 재고 지나갔습니다** —
「여기 「~다」 연속이 있나?」만 묻고 「짝이 새로 얻은 걸 이쪽도 얻어야 하나?」는 안 물었습니다.

★**A를 열어 달라고 부탁해 놓고 제 파일이 그 규칙에 걸렸습니다** — `02c#0`이 「약 십 분 뒤 시작됩니다」였습니다.
남에게 지켜 달라고 한 규칙을 제 검사에 안 넣었습니다.

- **`03c#0`은 제 사고** — 앞머리 겹침을 푼다고 「**이제** 오 분 뒤…」로 고쳤는데 다음 줄이 「**이제** 자리에 앉아…」. 두 문장짜리 클립이 둘 다 「이제」로 열립니다. 겹침을 풀면서 새 겹침을 만들었고 검사는 조용했습니다(문턱 셋).

**28 `[OPEN_TWIN]` 한 클립 안 문두 쌍 — 빨강/노랑.**
문두 반복(검사 12)은 문턱이 셋인데 그건 «한 예식 전체»의 자입니다.
**한 클립이 두 문장뿐인데 둘 다 같은 말로 열리면 두 번이 아니라 100%입니다.**
```python
for c in D['clips']:
    _ss = [x['new'] for x in c['sents'] if x['new'].strip()]
    _hd = [(re.match(r'^([가-힣]{1,3})', t).group(1) if re.match(r'^([가-힣]{1,3})', t) else None) for t in _ss]
    for k in range(len(_hd) - 1):
        if not _hd[k] or _hd[k] != _hd[k+1]: continue
        if _ss[k].startswith('두 분,') or _ss[k+1].startswith('두 분,'): continue   # ★수신자 가르는 장치
        (R if len(_ss) <= 2 else W)('문두 쌍', c['no'], f'{k}·{k+1}',
            f'{"두 문장뿐인 클립이 둘 다" if len(_ss)<=2 else "잇단 두 문장이"} 「{_hd[k]}」(으)로 열립니다')
```

## 3. 판정 흐름 — 사장님 152개를 버리지 않게 고쳤습니다

옛 `apply-pick.py`는 **문서 전체 sha1 하나**로 대조해서 한 글자만 달라도 **판정 전체를 거부**합니다.
안전하지만 정답이 아닙니다 — 두 시간 눌러 놓으신 것을 버리게 만듭니다. 자를 **문장 단위**로 내렸습니다.

1. `build-copy-pick.py` — 판정 화면이 문장마다 도장을 찍습니다.
```python
<div class="s..." data-id="{e(sid)}" data-h="{hashlib.sha1(s['new'].encode()).hexdigest()[:4]}">
L.push('O '+id+' = '+(o.v||'미정')+' @'+s.dataset.h);
```
2. `apply-pick.py` — 도장 없는 옛 판정 글은 **스냅으로** 문장마다 대조하고,
   «판정하신 그대로인 문장»은 받고 **«그 뒤에 바뀐 문장»만 빼서 다시 여쭙습니다.**

**그쪽에서 만드실 것 하나** — 그쪽 10:32 판 `round*.json` 이 정확히 `24f9719a` 입니다.
```python

snap = {f"{c['no']}#{s['i']}": s['new'] for f in F for c in json.load(open(f,encoding='utf-8'))['clips'] for s in c['sents']}

```

## 4-1. ★지운 열여덟 가운데 **열둘이 `plain`** 입니다 — 이건 벌 문제가 아닙니다

> **`plain` 이 «어조»가 아니라 «짧은 판»이 되어 있습니다.**

어조는 «같은 일을 다른 태도로 말하는 것»입니다. 그런데 지금 `plain` 은 대부분
**현행을 줄였거나, 같은 틀에 낱말만 갈아 끼운 것**입니다. 편지 예고 셋을 나란히 보면 분명합니다.
```
parent·plain  이제, 두 사람이 부모님께 쓴 편지를 읽습니다. 이제, 그 목소리가 이어집니다.
each·plain    이제, 두 사람이 서로에게 쓴 편지를 읽습니다. 이제, 그 목소리가 이어집니다.
both·plain    이제, 두 사람이 준비한 편지를 차례로 읽습니다. … 이제, 그 목소리가 이어집니다.
```
**세 벌이 아니라 틀 하나에 낱말을 끼운 것**입니다. 갈래는 셋인데 어조는 한 가지입니다.

★그리고 **「이제,」** — 제가 진행 대본에서 통째로 걷어낸 병입니다(문두 반복 6회 · 사장님 「다시」의 주범 중 하나).
**어조표에는 그대로 살아 있고**, 위 셋은 한 문장 안에 「이제」가 **두 번**입니다.

→ 열여덟을 지우는 것과 별개로 **`plain` 의 정의를 다시 세우시기를 권합니다.**
  담백함은 «짧음»이 아니라 «꾸미지 않음»입니다. 짧게 만드는 자동 규칙으로는 어조가 안 나옵니다.

## 4-6. 검사에 면제 규칙 하나 — ★일반 규칙으로 적었습니다

어조표를 재니 **다섯이 한꺼번에 빨개졌는데 전부 오탐**이었습니다. 「큰 박수」 면제가 **클립 번호로만** 걸려 있어서입니다.

```python
#   어조표 벌은 «새 자리»가 아니라 «같은 자리의 다른 판»이다. 번호로만 면제를 걸면 어조표가 전부 빨개진다.
def _tone_ev(no):
    return no.split('-')[1] if no.startswith('T-') and no.count('-') >= 2 else None
```
