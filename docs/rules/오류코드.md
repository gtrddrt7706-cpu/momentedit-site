**왜** — «지금은 AI 목소리를 만들 수 없어요»가 서버 거절 · 연결 끊김 · 시간 초과에 똑같이 나와 세 번(10/04 · 10/05 · 10/07) 원인을 못 찾았다. 조사해 보니 사이트 전체가 그랬다.

**규칙**
- 서버 · 연결 · 기기 실패 문구는 한 줄 + 끝에 «(코드 X#)». 글자 = 자리 · 숫자 = 무슨 일(모든 자리 같은 뜻). 표 = `assets/err-codes.js` 하나.
  - 0 거절(글이 곧 까닭) · 1 몰림 · 2 계정 · 요금제 · 키 · 3 설정 · 배포 · 4 처리 실패 · 5 시간 초과(결과 모름) · 6 연결 끊김 · 7 서버 답 깨짐 · 8 로그인 풀림 · 9 예상 못 한 오류(사고번호와 함께)
  - 자리: V 목소리 · U 올리기 · D 지우기 · S 저장 · L 불러오기 · P 결제 · C 계약 쪽 · B 상담 예약 · A AI 상담 · G 하객 · R 결과물 · M 기기(번호 뜻이 따로) · X 그 밖
- 브라우저가 가르는 셋: AbortError → 5 · fetch 실패 → 6 · `r.json()` 실패 → 7. **5 는 «실패»가 아니라 «결과 모름»** — 쓰기 동작이면 상태를 다시 불러 결과를 말한다.
- 서버(GAS)는 실패 응답에 `ecode` 를 싣고 1~9 는 한글 글 끝에 코드를 붙여 보낸다(`_errStamp` · 95_notify). **화면은 두 번 붙이지 않는다**(`/\(코드 [A-Z]\d/`).
- 입력 확인 문구(«비밀번호를 입력해 주세요»)에는 붙이지 않는다. 코드는 서버 · 연결 · 기기 실패에만.
- 새 동작(action)을 만들면 `95_notify` 의 `ERR_AREA` 에 자리를 적는다(없으면 X). 새 코드 뜻은 `assets/err-codes.js` 에 같은 커밋으로.
- 관리자: 검색창에 «S6» → 뜻 · 할 일 / 사고번호 4글자 → 오류기록의 그 줄 / 고객 상세 «최근 실패». 시트 «오류기록»에 다 남는다.

  같은 식순 화면에 V8 이 두 뜻으로 떴다(로그인 · 서버 멈춤). 이제 V9(사고번호 대신 «· 61초»처럼 초가 붙는다). 자리마다 숫자 뜻을 바꾸고 싶으면 숫자를 새로 쓰지 말고 표의 note 로 «덧붙인다».
