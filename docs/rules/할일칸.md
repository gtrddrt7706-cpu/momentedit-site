## 응답 마무리: 🙋 네가 할 일

수정·작업 요청을 처리할 때는 **내가 할 수 있는 작업을 전부 끝낸 뒤**, 응답 **맨 마지막**에 항상 아래 제목의 칸으로 "사용자가 직접 해야 할 일"을 정리한다. 사용자가 놓치지 않게 하기 위함.

### 형식
- 제목은 항상 `## 🙋 네가 할 일`
- 둘 중 하나로 표시:
  - **✅ 없음** — 내가 다 처리함. + 왜 없는지 한 줄 (예: `momentedit.kr`은 Vercel 자동 반영 / `.gs` 주석만이라 재배포 불필요).
  - **⚠️ 있음** — 사용자가 직접 해야만 하는 것만 번호 목록으로 (예: GAS에 `.gs` 반영 + `R3n9Mr` 재배포 / 외부 결제 / 라이브 직접 확인).

### 원칙
- "있음"에는 **내가 못 하는 것만** 적는다. 내가 할 수 있는 건 먼저 다 해놓고 보고만 한다.
- 헷갈려도 "없음"이라고 한 줄 이유를 붙여, 사용자가 안심하고 넘어가게 한다.
- 이 칸은 항상 응답의 가장 아래, 같은 제목으로 둔다.
- **★기계 알림에는 이 칸을 붙이지 않는다 (2026-08-15 사용자 지적 "왜 3개씩 나오지?")**
  백그라운드 작업 종료·타이머 만료 같은 **시스템 알림**은 사용자의 말이 아니다.
  알릴 내용이 없으면 **한 줄로 끝내거나 아무 말도 하지 않는다** — 같은 상자를 다시 그리지 않는다.
  실제 사고: PR 하나에 CI 대기 타이머를 3개 겹쳐 걸었고, 셋이 차례로 종료되자
  그 알림마다 응답을 만들어 **내용 없는 '네가 할 일'이 세 번 연달아 쌓였다.**
  - 겸사 규칙: **한 대상에 대기 타이머는 하나만.** 이미 걸어 둔 것이 있으면 새로 걸지 말고 그것을 기다린다.
  - 이 칸을 다시 그리는 경우는 **할 일이 실제로 바뀌었을 때뿐**이다.
- **★병합·배포 대기는 여기 안 적는다** — 내가 하는 일이다(위 「병합은 내가 한다」). "CI 초록 뜨면 병합한다"는 보고이지 사용자의 할 일이 아니다.
