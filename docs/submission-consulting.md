### 이력

| 구분 | 내용 |

| 과거 창업 | 두다스튜디오(인물사진촬영업) 2020.3~2022.11, **2년 8개월 운영** — 웨딩·촬영 도메인 경험 |
| 현 창업 | 모먼트에디트 (사업자등록 2026.4.1, 개업 2026.10.26 예정) |

### 전공·경력이 아이템과 표면적으로 다른 점 (정공법)

심사에서 중요한 것은 "전공 일치" 자체가 아니라 **대표가 자기 사업을 깊이 이해하는가, 이 구조로 수행 가능한가**입니다. 세 가지로 답합니다.

1. **결과물이 전공보다 강한 증거.** 학위가 아니라 실제로 만든 **약 86,800줄 규모의 라이브 시스템**으로 개발 역량을 증명합니다(3장·별첨 팩트시트). 계획서가 아니라 **이미 돌아가는 시스템**입니다.
2. **현장 PM 역량 = 소프트웨어 프로젝트 역량.** 공정 관리→개발·배포 관리, 협력업체·발주처 조율→이해관계자(고객·외부 API·결제사) 조율, 도면 검토→시스템 설계·명세 검토, 안전관리→코드 안전 점검, 준공 검수→배포 전 테스트·검증(CI 4종·감사 7종). **복잡한 다자 프로젝트를 마감까지 책임·검수하는 훈련**을 소프트웨어에 그대로 적용했습니다.
3. **웨딩 도메인 2년 8개월 검증.** 두다스튜디오 운영으로 촬영·고객 응대·시장 통점을 몸으로 익혔고, 그 이해가 지금 시스템 설계(추가금 없는 통합가·투명 계약)에 직접 반영돼 있습니다.

> 폐업 이력은 감추지 않습니다. 2년 8개월 직접 운영한 현장 경험이 자산이며, 그 경험을 반영해 이번에는 **운영 전 과정을 시스템으로 자동화**하는 방향으로 설계했습니다.

### 부족 역량 보완 계획

1인 창업의 부족 역량(디자인 고도화·마케팅·영업 확장)은 **매출 발생 시점에 순차 채용·외부 협업**으로 보완합니다(6장 로드맵). 개업 초기에는 자체 시스템의 자동화로 1인 운영 효율을 극대화합니다.

## 3. 직접 개발한 시스템 (실적·준비도 = MVP)

계획이 아니라 **이미 운영 중인 시스템**입니다. 이 자체가 실행력과 의지의 증거입니다.

### 규모 (2026-07-21 실측)

| 구분 | 라인 수 |
|---|---:|
| 백엔드 로직(Google Apps Script 23모듈) | 13,777 |
| 서버리스 함수(16개) | 2,007 |
| 관리자·상담 화면 | 3,004 |
| 공용 JS 모듈 | 1,851 |
| 테스트·감사 스크립트 | 3,078 |
| 고객 화면 HTML(15페이지) | 26,004 |
| 청첩장 템플릿(24개) | 37,036 |
| **합계** | **약 86,800** |

외부 의존성 최소(프론트 프레임워크 0·서버리스 npm 의존성 0). **직접 작성 코드 비중이 사실상 전부**.

### 구현된 주요 시스템

1. **고객 여정 관리** — 상품별 진행 상태머신, 개인코드·로그인·알림·리마인드 자동화, 캘린더 더블부킹 방지
2. **전자계약·정산** — 손서명 + 동의기록 보관, 결제 마일스톤 엔진(계약금·중도금·잔금), 환불·변경 견적 엔진
3. **AI 상담·컨시어지 6종** — Claude API 연동, 비용·안전 대시보드, 환각 방지 설계
4. **모바일 청첩장 16종 + 하객 시스템** — 좌석 조회·디지털 참석·하객 편지·안내 허브
5. **운영자 콘솔** — 약 60개 관리 기능, CI 4종·감사 7종 자동 검증 체계

**스택:** 바닐라 JS + Google Apps Script + Vercel 서버리스 + Google Sheets + 외부 API(Claude·Solapi 알림톡·Kakao 지도·Toss 결제·Vimeo·Google Workspace). 서버·DB 고정비 없이 1인이 유지·확장 가능.

### 지식재산 계획

핵심 단위를 **소프트웨어 저작권 등록**으로 보호할 계획입니다(고객여정 관리 플랫폼 / AI 상담 시스템 / 청첩장·하객 시스템 / 전자계약·정산). 이는 향후 초기창업패키지·청창사의 특허·지식재산 가점 경로와도 연결됩니다.

## 4. ② 비즈니스모델·시장성·차별성

### 4-1. 시장성 (실데이터)

- **결혼 시장 규모:** 2024년 혼인 **22.2만 건**(전년비 +14.8%), 결혼서비스(예식장·스드메) **평균 지불액 2,468만 원**(정부 실태조사, 신혼부부 995쌍). *(실측 · 통계청 2024 혼인통계 · 관계부처 「결혼서비스 발전 지원방안」 2024.11)* 웨딩 전체 시장은 업계에서 통상 20조 원대로 **추정**(공식 단일통계 아님).
- **정부 정책과 정렬(강력):** 정부·소비자원은 스드메의 **"깜깜이 견적·계약서 미명시 추가비용"을 공식 문제로 규정**("추가옵션 없이 결혼준비 곤란" 67.7%)하고 **표준약관·가격공개 의무화(결혼서비스 발전방안)**를 추진 중입니다. *(실측 · 한국소비자원·정책브리핑)* → 모먼트에디트의 **사전 공개 단일가·추가금 없는 통합가**는 정부 정책 방향과 정확히 일치합니다.
- **B2B SaaS 기회:** 국내 SaaS 시장 5,780억(2020)→**1.14조 원(2025 전망, CAGR 14.9%)** *(추정 · SPRi 인용)*. 소상공인은 **디지털화 기초단계 80%·전자상거래 실적 보유 11.4%**로 예약·CRM SaaS 침투가 낮습니다 *(실측 · 소상공인실태조사)*. 즉 웨딩 벤더 대부분이 상담·계약·고객관리를 수기·엑셀·카톡으로 처리 → **버티컬 SaaS 미충족 수요**.
- **벤치마크:** 예약·CRM 버티컬 SaaS **캐치테이블**(누적투자 742억·가맹 7,425곳), 웨딩테크 **웨딩북**(누적투자 158억)은 "SMB가 예약·CRM SaaS에 실제 지불한다"는 시장 검증 사례. *(실측 · 언론·THE VC)*

*(웨딩 벤더 정확 사업체 수는 통계청 KSIC 세분류 직접 추출 필요 · 현재 미확인. 최종 사업계획서에서 확정 인용 예정)*

### 4-2. 비즈니스모델

- **현재(B2C):** 마이크로웨딩 스튜디오. 촬영+예식 통합 140분 시그니처 시퀀스. 가격 공개(VAT 포함) **평일 210만 / 주말 280만**. 1일 최대 3팀. 의상 자체 보유·헤어메이크업 자유 선택.
- **전환(B2B SaaS):** 자사 운영 시스템을 웨딩 벤더용으로 일반화(멀티테넌트). 재사용 모듈은 이미 구현(인증·고객여정·결제·전자계약·AI상담·관리자 콘솔). 수익모델은 **월 구독(SaaS) + 결제 연동 수수료** 방향. 전환의 본질은 신규 구축이 아니라 **검증된 도메인 로직의 일반화·격리**.

### 4-3. 차별성 (경쟁우위·진입장벽)

1. **도메인 + 개발을 한 사람이 보유.** 웨딩 현업을 운영하며 그 업무 전 과정을 스스로 코드로 구현. "현장 모르는 개발자"도 "만들지 못하는 사장"도 아닌 **양쪽 겸비 1인**. B2B 전환 시 고객(벤더)의 실제 업무를 정확히 아는 것이 최대 진입장벽.
2. **웨딩플래너 없이 자체 시스템으로 완결.** 통상 플래너·대행사가 청첩장·계약·일정·하객 안내를 중개하는 것을, **자체 개발 시스템으로 직접 제공**. 중개 마진을 기술로 대체.
3. **디지털 예식 경험을 자체 시스템에 통합(선도적 시도).** 광고 없는 비공개 라이브·설치 없는 원터치 하객 안내를 외부 서비스 의존이 아니라 자사 시스템에 통합. 웨딩 업계에서 흔치 않은 접근.
4. **정책 정렬.** 가격 투명성·표준약관 방향과 상품 구조가 일치 → 규제 리스크가 낮고 정책 수혜에 유리.
5. **가벼운 비용 구조 + 검증 체계.** 서버·DB 없이 운영, 1인이지만 CI·자동 감사로 품질 관리.

## 5. ③ 대표자의 의지

- **개업 전 단계에서 이미 약 86,800줄 규모의 라이브 시스템을 팀·외주 없이 1인으로 구축·운영** 중입니다. 계획 단계 창업자와 달리 **실행으로 증명된 의지**입니다.
- 안정적 직장(엘리베이터 PM)을 **퇴사(10.17)하고 창업에 전념**하는 결정 자체가 몰입의 근거입니다.
- 폐업(두다스튜디오) 후에도 웨딩 도메인으로 재도전하며, 실패 경험을 **자동화 시스템**으로 구조적으로 보완했습니다.
