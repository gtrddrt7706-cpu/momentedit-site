## 0. 요약

모먼트에디트는 **양가 직계가족 중심의 마이크로웨딩 스튜디오**이자, 그 운영 전 과정을 **대표자가 직접 개발한 웹 플랫폼으로 자동화**한 사업입니다. 상담 예약부터 전자계약·결제·제작·결과물 전달·하객 안내까지 하나의 시스템으로 흐르며, 총 코드량은 **약 8만 5천 줄(실측)**, 순수 백엔드·서버리스 애플리케이션 로직만 **약 1만 6천 줄**입니다. 프레임워크·외주 없이 1인이 기획·설계·개발·결제연동·운영까지 완주했습니다.

핵심 논지는 하나입니다. **"웨딩 현업 도메인 지식과 소프트웨어 개발 역량을 한 사람이 동시에 보유한다."** 이 결합이 이 사업의 차별성이며, 지금의 B2C 스튜디오를 **웨딩 벤더 대상 B2B SaaS**로 확장하는 근거입니다.

## 1. 대표자

**정희준** (1992.3.26생, 만 34세)

### 학력·전공
- 전기공학 전문학사

### 경력
- **현재: 엘리베이터 설치 PM** (2026.10.17 퇴사 예정)
  - 승강기 설치 공정 관리, 협력업체·발주처 조율, 시공 도면 검토, 현장 안전관리, 준공 검수
- **과거 창업: 두다스튜디오** (인물사진촬영업, 2020.3.16 개업 ~ 2022.11.7 폐업 · 2년 8개월 운영)
- **현재 창업: 모먼트에디트** (사업자등록 2026.4.1 · 개업일 2026.10.26 · 현재 개업 전 준비·개발 단계)

### 전공·경력과 정보통신업의 정합성 (정면 검토)

표면적으로 전기공학 전공과 엘리베이터 PM은 SW 개발과 다릅니다. 이 점을 숨기지 않고, 세 가지로 답합니다.

1. **"무엇을 만들었는가"가 전공보다 강한 증거입니다.** 대표자는 학위가 아니라 **실물 시스템 약 8만 5천 줄**로 개발 역량을 증명합니다. 상담 예약 상태머신, 전자계약 손서명, 결제 마일스톤 엔진, AI 상담 6종, 청첩장 16종을 기획·구현·운영까지 완주한 결과물이 그대로 근거입니다(3장·별첨 팩트시트).

2. **현장 PM 역량이 곧 소프트웨어 프로젝트 역량입니다.** 승강기 설치 PM의 핵심 업무는 그대로 SW 개발·운영으로 전이됩니다.
   - 공정 관리 → 개발 단계·배포 파이프라인 관리
   - 협력업체·발주처 조율 → 이해관계자(고객·외부 API·결제사) 요구 조율
   - 시공 도면 검토 → 시스템 설계·명세 검토
   - 현장 안전관리 → 코드 안전 점검(레드라인 자동 프로브·XSS 감사·금액 계산 감사)
   - 준공 검수 → 배포 전 테스트·검증(CI 4종·감사 스크립트 7종)
   즉 대표자는 "코드를 처음 만지는 사람"이 아니라 **복잡한 다자간 프로젝트를 마감까지 책임지고 검수하는 훈련이 된 사람**이며, 그 역량을 소프트웨어에 적용했습니다.

3. **웨딩 도메인은 이미 2년 8개월 검증했습니다.** 두다스튜디오(인물사진촬영업) 운영으로 촬영·고객 응대·시장 통점을 몸으로 익혔고, 그 도메인 지식이 지금 시스템의 설계(추가금 없는 통합가·투명 가격·계약 신뢰 구조)에 직접 반영돼 있습니다.

> 폐업 이력은 감추지 않습니다. 2년 8개월간 사업을 직접 운영하며 얻은 **현장 경험과 시장 이해**가 이번 사업의 자산이며, 실패 경험을 반영해 이번에는 **운영 전 과정을 시스템으로 자동화**하는 방향으로 설계했습니다.

## 2. 개발 이력

### 무엇을, 언제부터, 혼자

- **착수 시점(근거 기반):** 사업자등록 2026.4.1, 문서 저장소 최초 커밋 2026.5.18, 회계 체크리스트 기준일 2026.5.19. 즉 **2026년 4~5월부터** 개발·운영 준비를 시작해 현재까지 이어지고 있습니다.
- **개발 방식:** 팀·외주·에이전시 없이 **1인이 기획·설계·개발·결제연동·운영**을 모두 수행합니다. AI 코딩 도구를 개발 보조 수단으로 활용하되, 기획·아키텍처·검증·운영 판단은 대표자가 직접 내립니다.

## 3. 시스템 상세

### 3-1. 고객 여정 관리 (예약 → 납품)

- **상품별 진행 상태머신:** 시그니처(예식) 9단계 · 웨딩스냅 6단계, 각 단계별 "지금 할 일" 한 문장 자동 안내.
- **자동화:** 가입 시 개인코드·로그인 토큰 자동 발급, 접수 메일·자동로그인 링크 자동 발송, 상담예약 동시 생성, 캘린더 가예약/예식확정 자동 전환, 미서명 계약 72h 자동 파기, D-day 리마인드 자동 발송.
- **데이터:** Google Sheets(고객 시트 58컬럼) 단일 저장소, 별도 서버·DB 없이 운영비 최소화.

### 3-2. 전자계약·정산

- 계약 요청 → 관리자 발송 → **캔버스 손서명(PNG)** + 클릭 동의 → 서명본 Google Drive 자동 보관.
- **동의기록(JSON 스냅샷)**: 약관버전·표시금액·약관지문·서명시각을 저장해 효력 재현 근거 확보.
- **결제 마일스톤 엔진:** 시그니처(예약금 10만 → 계약금 10% → 중도금 40%[D-149] → 잔금 50%[D-9]), 웨딩스냅(계약금 20% → 잔금 80%). 입금은 "고객 신호 → 관리자 통장 대조 확인" 2단계.
- **환불·변경 견적 엔진:** 계약서 조항(청약철회·무상취소·위약금·변경수수료)을 코드로 구현, 단위 테스트로 검증.

### 3-3. AI 상담·컨시어지

- **6종 엔드포인트**(Anthropic Claude API): 홈·마이페이지 상담, 상담일정 컨시어지, 식순 빌더, 애프터웨딩 컨시어지, FAQ 초안, 인계 브리핑.
- **운영 안전장치:** 장소 추천은 검증 DB·지도 API에서만(환각 방지), 캘린더 전체를 AI에 노출하지 않음, 호출당 토큰 비용 적재, 일일 레드라인 안전 프로브, 회귀셋 상시 점검, 관리자 비용/안전 대시보드.

### 3-4. 청첩장·하객 안내

- **모바일 청첩장 16종**(커버 8 + 가족형 8) + 갤러리 데모 8종. `?e=eventId`(랜덤 접미로 열람 보호) 하이드레이션 방식, 커플별 파일 생성 없이 시트 데이터로 렌더.
- 하객 좌석 조회, 디지털 참석(Vimeo 스트림), 하객 편지(금칙어·회피 탐지 필터), 통합 안내 허브.

### 3-5. 운영자 콘솔

- **약 60개 관리자 액션**(단일 게이트웨이 라우팅), 처리할 일 큐·파이프라인·설문·AI 운영 8탭 대시보드.
- **운영자 알림 메일 전용**(문자비 0), 주간 백업·영수증 감사·월간 장소검증 자동화.

### 3-6. 기술 스택·품질

- 프론트: 바닐라 JS/HTML(프레임워크·빌드 없음). 백엔드: Google Apps Script + Vercel 서버리스. 저장소: Google Sheets. 외부: Claude·Solapi(알림톡)·Kakao(지도)·Toss(결제·현재 비활성)·Vimeo·Google Workspace.
- **품질 체계:** GitHub Actions CI 4종(마커 역전 차단·AI 안전·라이브 시뮬·배포 검증) + 감사 스크립트 7종(금액 계산·XSS·정산 E2E 등) + 단위 테스트. 1인 개발이지만 **자동 검증 체계를 갖춰 운영**합니다.

### 3-7. 화면 목록(스크린샷 제시 순)

마이페이지 진행바 → 관리자 처리 큐/파이프라인 → 전자계약 손서명 → 결제 마일스톤 → AI 상담 위젯/관리자 AI 8탭 → 청첩장 갤러리·라이브 청첩장 → 하객 좌석·디지털 참석·안내 허브 → CI 그린 체크.

## 4. 사업 모델

### 4-1. 현재: B2C 마이크로웨딩 스튜디오

- **상품:** 양가 직계가족 25명 규모 마이크로웨딩. 촬영과 예식을 하나로 엮는 **140분 시그니처 시퀀스**. 웨딩스냅 별도.
- **가격(공개·VAT 포함):** 평일 210만 원 / 주말 280만 원. **추가금 없는 통합가·사전 공개 가격**으로 웨딩 시장의 "깜깜이 가격·추가금·끼워팔기" 통점을 정면으로 해소.
- **차별 운영:** 의상 자체 보유, 헤어·메이크업 자유 선택(특정 제휴 비강제). 상담부터 납품까지 자체 플랫폼으로 자동화해 1인 운영이 가능한 구조.

### 4-2. 전환 목표: B2B SaaS (웨딩 벤더 대상)

- **문제의식:** 소규모 웨딩 스튜디오·플래너 대부분이 상담·계약·결제·일정·하객 안내를 수기·카톡·엑셀로 처리합니다. 모먼트에디트가 **자사 운영을 위해 만든 시스템이 곧 이들에게 필요한 도구**입니다.
- **재사용 가능한 핵심 모듈(이미 구현):** 인증/세션, 고객여정 상태머신, 결제 마일스톤 엔진, 전자계약, 환불/변경 견적, AI 상담 스택, 알림 게이트웨이, 관리자 콘솔.
- **전환에 필요한 일반화 작업:** 상품·단계·결제 비율·템플릿·브랜드 문구의 설정화(현재 상수 하드코딩), 단일 Google Sheets → 멀티테넌트 데이터 격리, 테넌트 온보딩·구독 과금·권한 모델.
- **핵심:** 신규 구축이 아니라 **검증된 도메인 로직의 일반화·격리**가 전환의 본질입니다. (구체 개발 공수는 별도 산정 예정)

## 5. 차별성

1. **도메인 + 개발을 한 사람이 보유.** 웨딩 스튜디오를 실제 운영(두다스튜디오 2년 8개월 + 모먼트에디트)하면서, 그 업무 전 과정을 스스로 코드로 구현했습니다. "개발자가 이해 못 하는 웨딩 현장"도, "현장은 알지만 만들지 못하는 사장"도 아닌, **양쪽을 겸비한 1인**입니다. B2B SaaS로 갈 때 고객(웨딩 벤더)의 실제 업무를 정확히 아는 것이 가장 큰 무기입니다.

2. **기획→개발→결제연동→운영까지 완주.** 아이디어·명세가 아니라 **실제로 돌아가는 시스템**을 혼자 끝까지 만들었습니다. 전자계약 손서명, 결제 마일스톤, AI 상담, 자동 알림, CI/감사까지 실운영 수준으로 갖췄습니다.

3. **비용 구조가 가볍다.** 서버·DB 없이 Google Workspace + 서버리스로 운영해 고정비가 낮고, 1인이 유지·확장할 수 있는 아키텍처입니다. 초기 창업 자본 효율이 높습니다.

4. **투명·신뢰 중심의 상품 설계.** 시장 통점(추가금·깜깜이 가격) 리서치를 코드·계약·가격 정책에 직접 반영해, 차별화가 마케팅 문구가 아니라 **시스템으로 구현**돼 있습니다.

## 6. 향후 계획

### 6-1. 개업 전 (~2026.10.26)
- 엘리베이터 설치 PM 퇴사(10.17) 후 개업(10.26)에 전념.
- 통신판매업 신고, Toss 카드결제 라이브 전환(현재 구현 완료·비활성), 정식 주소·신고번호 계약서 반영.
