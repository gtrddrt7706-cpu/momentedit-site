# 제작안: 단체촬영 구도 고르기 (2026-07-19 · 사용자 검토 대기)

폐식·단체촬영 카드(식순 빌더 맞춤 고르기 맨 끝 고정 카드)를 열리는 카드로 승격해, 부부가 원하는 단체 사진 구도를 미리 고르게 한다. 새 화면·새 행 없음.

## 고객 여정
- 발견: 맞춤 고르기 목록 맨 끝 '폐식·단체촬영' 카드 탭 → 열림
- 닫힘 요약: "지금 · 전체 하객" / 구도 추가 시 "지금 · 전체 하객 + N컷"
- 열림: 안내 1줄 + 칩 다중 선택 + 직접 추가 입력 + 순서 안내 1줄

## 칩(기본 후보)
- 전체 하객(기본 · 항상 포함 · 해제 불가)
- 양가 부모님과 / 신랑 측 가족 / 신부 측 가족 / 친구들과 / 직장·지인과 (다중 선택)
- 직접 추가: 20자 제한 · 중복 무시 · ✕ 삭제 (예: 대학 동기 · 부케 토스)
- 고른 순서 = 촬영 순서 · "보통 부모님·가족 구도를 앞에 두면 먼저 가셔야 하는 어른들이 편해요"
- 상한 12컷(화면에 숫자 비노출 · 초과 시 "고른 순서대로 단체 기록 시간에 진행돼요" 안내만)

## 데이터·반영처
- 저장: S.photo = ['parents','groomFam',...,'c:대학 동기'] (배열 순서=촬영 순서 · 'c:' 접두=직접 추가). 전체 하객은 고정이라 저장 안 함
- 식순 초안(S)에 실려 로컬·서버·타기기 자동 (GAS 변경 0)
- 디렉터 큐: fullBlocks '_close'.cue에 구도 순서 나열 → 연습 공간·당일 진행 자동
- 완성 화면: '단체촬영 구도' 요약 + 수정 진입(폐식 카드로)
- 관리자: admin.html 식순 상세 row 1개
- 예식 확인서(선택): 식순 줄에 '단체촬영 N컷' — 변경 시 재확인 트리거는 기존 규칙 그대로

## 엣지
- 미선택=전체 하객 1컷(압박 없음) · 코스 변경 시 구도 유지(applyCourse 리셋 제외) · 확인서 확인 후 변경=재확인 · 빈/중복/장문 입력 가드 · 표시 전부 esc
