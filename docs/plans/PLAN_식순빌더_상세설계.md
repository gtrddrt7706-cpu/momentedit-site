## 0. 제1원칙: "선택 피로" 문제에 대한 답

**우려**: 스텝마다 고르고 또 고르는 위저드가 고객에게 좋은가?

**답: 선택지는 많되, 필수 결정은 3개로 제한한다.**

| 구분 | 개수 | 내용 |
|---|---|---|
| **필수 결정** | **3** | ① 분위기 톤 ② 서약 형태 ③ 환영 인사 방식 |
| 선택 결정 | 0~N | 이벤트 더하기(0개 가능), 디테일, 지정곡 |

- 필수 3개 외엔 전부 **기본값이 이미 정답**: 진행=나레이션(기본), 예물 교환=포함(기본), 이벤트=0개(기본), BGM=톤 큐레이션(기본), 순서=추천 배치(기본).
- **미니멀 경로**: 톤 1탭 → 서약 1탭 + 환영 1탭 → "안 더할게요" → 완성 확인·저장. **탭 7~8회, 약 2~3분, 체감 3스텝.**
- 풀커스텀 경로도 스텝당 결정 1~2개를 넘지 않게 화면을 쪼갠다(한 화면 한 주제).
- 모든 선택엔 **즉각 보상**(나레이션 미리보기·예산 바·실시각 갱신)이 따라온다. 고르는 행위가 일이 아니라 내 결혼식을 미리 보는 재미가 되도록.
- **완료는 확정이 아니다**: "저장하면 디렉터가 확인하고 상담 때 함께 다듬어요"를 명시해 완성 부담을 내린다(완료율의 핵심 심리 장벽 제거).
- **첫 작성=위저드, 재방문=편집기**: 완료 후 재진입은 위저드가 아니라 큐시트 홈(§8)으로. 몇 주에 걸쳐 5~10회 돌아오는 도구임을 전제.

## 1. 진입점 (대시보드)

- 위치: 예식 준비(Production) 카드 > `식순` 행 (기존 자리 유지).
- 버튼 라벨: 시작 전 `시작하기` / 진행 중 `이어하기` / 완료 `완료 · 수정`.
- 완료 시 행 요약 추가: `식순 ✓ · 7순서 · 26분` (order 개수 = 고정 6 + 선택 N, 분 = 계산 합).
- **미입력 뱃지**: 완료했지만 나중에 채우기로 한 항목(마지막 문장·곡명·영상 링크 등)이 있으면 행에 `채울 것 2개` 뱃지 → 탭 시 해당 카드로 점프.
- D-9 이후(예식 9일 전~): 수정 진입 시 소프트 락 안내(§9).

## 2. 스텝 구성 (동적 6스텝 · 조건 스킵)

표시 번호는 동적 계산(스킵된 스텝은 카운트에서 제외). 이어하기는 기존 `_step` 방식 유지.

```
S1 시작·톤     →  S2 뼈대·형태  →  S3 더하기  →  [S4 순서]  →  [S5 디테일]  →  S6 완성
                                              (선택 0개면 스킵)  (내용 없으면 축소·스킵)
```

### S1 · 시작 + 분위기 톤

**목적**: 형식(나레이션) 각인 + 톤 1택. 결정 1개.

**화면**
- 헤드: `우리 예식, 어떤 분위기로 흐를까요?`
- 서브(형식 소개): `모먼트에디트의 예식은 성우 나레이션이 처음부터 끝까지 진행을 이끌어요. 사회자를 구하지 않아도 돼요.`
- (선택) 대표 샘플 오디오 재생 버튼: `▶ 나레이션 목소리 미리 듣기` (mp3 1개). **파일 없을 때 폴백**: 예시 문장을 글로 노출 `예시: "서로의 가장 좋은 친구이자 이제 평생의 동반자가 될 두 사람입니다."`
- 톤 3택(inv-opt 재사용):
  - `차분하고 감동적으로` sub: 편지·서약 중심의 깊은 시간
  - `밝고 유쾌하게` sub: 웃음이 있는 가벼운 시간
  - `담백하고 심플하게` sub: 꼭 필요한 순서만, 짧고 깊게
- 톤 아래 안심 문구: `추천 순서를 골라 드리는 기준이에요. 언제든 바꿀 수 있어요.`
- 하단 작은 링크: `지인 사회자와 함께하고 싶으신가요? · 사회자 진행으로 바꾸기` → 탭 시 `host:'mc'` 전환 + 안내 1줄: `진행 대본은 저희가 완성해 드려요. 사회자분은 읽기만 하면 돼요.` (재탭으로 복귀)

**검증**: 톤 미선택 시 `분위기를 골라 주세요.`
**저장**: `tone`, `host`('narration' 기본 | 'mc')

### S2 · 뼈대 확인 + 형태 선택

**목적**: "이미 완성돼 있다" 안심 + 결정 2개(서약·환영). 예물 옵트아웃은 기본 유지.

**화면**
- 헤드: `이 뼈대는 저희가 완성해 뒀어요`
- 고정 타임라인 카드(읽기 전용 · 실시각 표기, base.weddingTime 기준):

```
13:20  개식 나레이션          ✓ 준비돼요
13:22  신랑·신부 동시 입장     ✓ 준비돼요
13:27  환영 인사              ✓ (방식 아래에서 선택)
  …    (여기에 두 분의 순서가 들어가요)
       혼인 서약              ✓ (형태 아래에서 선택)
       예물 교환              ✓
       성혼 선언              ✓
13:49  폐식 · 단체촬영 안내    ✓ 준비돼요
```

- ※ 잠금(자물쇠) 아이콘 금지: 고정 블록은 "통제"가 아니라 "저희가 준비해요"로 표현(✓·라벨). 같은 사실을 선물 프레임으로.
- 서브: `여기까지만으로도 완성된 예식이에요. 다음 단계에서 두 분다운 순간을 더할 수 있어요.`
- **혼인 서약 형태** 2택: `문답형` sub: 나레이션이 묻고 두 분이 "네"로 답해요 · 3분 / `직접 쓴 서약 낭독` sub: 서로에게 쓴 약속을 읽어요 · 4분 `추천`
  - 문답형 선택 시 실제 질문 문장 즉시 미리보기(엄숙한 순간에 대한 신뢰): `"이제 두 사람에게 묻습니다. 서로를 평생 아끼고 지키겠습니까."`
- **환영 인사 방식** 2택: `두 분이 직접` sub: 첫 인사를 두 분의 목소리로 / `나레이션에 맡기기` sub: 준비한 환영 문구가 흐르게
- **예물 교환** 체크(기본 ON): `반지 교환 포함` 해제 시 sub: `빼도 괜찮아요. 성혼 선언으로 바로 이어져요.`

**검증**: 서약·환영 미선택 시 각 안내.
**저장**: `vow`('문답'|'자작'), `welcome`('직접'|'나레이션'), `ringExchange`(bool)

### S3 · 더하기 (이벤트 선택)

**목적**: 0개도 정답임을 명시하고, 고르면 미리보기로 보상.

**화면**
- 헤드: `더하고 싶은 순간이 있나요?`
- 서브: `하나도 더하지 않아도 괜찮아요. 뼈대만으로 이미 완성된 예식이에요.`
- **예산 바**(상단 고정): `남은 시간 12분 · 보통 3~4개를 더해요` → 선택마다 갱신 `축가 4분 더함 · 남은 시간 8분`. 초과 시 주황: `약 2분 초과예요. 저장은 되고, 상담 때 함께 조정해요.` (기준점 문구로 "잘하고 있나" 불안 제거)
- **칩 그리드**(기존 .trk-chips 재사용 · 각 칩에 분 표기 `편지·덕담 · 3분`):
  - 톤에 따라 정렬 + `추천` 뱃지(차분: 편지·베일다운·서명식 / 유쾌: 퀴즈·덕담릴레이 상단 승격 / 심플: 와인·케이크만 추천, 안내 `뼈대만으로도 충분해요`)
  - 유쾌 톤일 때 1줄: `하객이 가족 위주라면 유쾌한 순서는 1개 정도가 적당해요.`
- **칩 탭 시 인라인 카드 펼침**(선택 확정 전 미리보기):
  - `이때 이런 나레이션이 흐릅니다` + 템플릿 문장(이름 치환) + `[더하기] [닫기]`
- 하단 `더 보기` 접힘 → 더보기 칩들 + `직접 추가`(이름+분 입력, 기본 2분)

**칩 목록**: §5 카탈로그 참조. 링워밍 뱃지 `이 규모라서 가능한 순서`.
**검증**: 없음(0개 허용). 저장: `events[]`(key 배열)

### S4 · 순서 배치 (선택 1개 이상일 때만)

**목적**: 자유 구간 안에서 순서 확정. 추천 배치가 기본이라 안 만져도 됨.

**화면**
- 헤드: `순서를 확인해 주세요`
- 서브: `추천 순서로 놓아 드렸어요. ▲▼로 바꿀 수 있어요.`
- 전체 타임라인: 고정 🔒(이동 불가) + 선택 블록(▲▼ 버튼) + 각 행 실시각 자동 갱신.
- **배치 규칙(자동)**:
  - 베일다운 → 입장 직전 고정(이동 불가·자유 구간 밖).
  - 자유 구간 = 환영 인사 뒤 ~ 혼인 서약 앞 (기본). 단 케이크·와인·건배는 서약·예물 뒤(성혼 선언 앞) 배치 허용 — 추천 배치: [환영 뒤] 영상→편지→축사→축가, [예물 뒤] 와인→케이크→건배.
  - 마지막 자유 블록이 유쾌 카테고리면 안내 1줄: `마지막은 차분한 순서로 마무리하면 촬영으로 자연스럽게 이어져요.` (강제 없음)

**저장**: `order[]`

### S5 · 디테일 (선택 이벤트당 카드 1장)

**목적**: 고른 것만 묻는다. 이벤트 카드 안에서 변수·마지막 문장·담당자 입력.

**화면**: 카드 세로 나열(§5 카탈로그의 detail 스키마대로 렌더). 공통 요소:
- 카드 헤드 = 이벤트명 + 분
- 🔊 나레이션 문장(잠금·이름 치환 완료 상태로 표시)
- 입력 필드(이벤트별)
- **마지막 문장**(말 이벤트만): 라벨 `마지막 문장` 힌트: `이 말이 끝나는 순간 음악이 스며들어요. 내용은 당일까지 비밀로 간직하셔도 돼요. 아직 안 쓰셨다면 나중에 채워도 돼요.` (선택 입력 · 미입력 시 대시보드 `채울 것` 뱃지로 회수)
- **지정곡 3포인트**(카드들 아래 공통 섹션): `입장곡` / `편지·서약 배경` / `마무리 음악` 각각 `모먼트에디트 추천 무드로`(기본) 또는 곡명·가수 입력. (기존 entryMusic·exitMusic 칸 대체)
- 요청 메모 1칸(자유): `그 밖에 알려주실 것이 있나요? (선택)`

**검증**: 필수는 담당자류만(퀴즈=진행 지인, 축사=하시는 분). 나머지 전부 선택.
**저장**: `details{}`, `music{entry,peak,closing}`, `note`

### S6 · 완성 (큐시트 미리보기 + 저장)

**목적**: 클라이맥스. 내 결혼식이 대본으로 완성된 것을 보여주고 저장.

**화면**
- 헤드: `{신랑} · {신부}의 예식 대본이 완성됐어요`
- 3열 큐시트(모바일은 시각+장면 / 나레이션 접힘 펼침):

```
13:20  개식            🔊 "오늘 {신랑}, {신부} 두 사람이 부부가 되는…"
13:22  동시 입장        🔊 + 🎵 입장곡
13:27  환영 인사(직접)   끝 신호: 인사 마침
13:29  편지(신부→부모님) 🔊 + 🎵 · 마지막 문장: "…감사했습니다"
  …
13:49  폐식·촬영 안내    🔊
```

- 합계 줄: `총 28분 · 본예식 30분 안에 여유 있게 들어가요.` (초과 시: `약 2분 초과 · 상담 때 함께 다듬어요.`)
- **안전망 문구(핵심)**: `저장하면 디렉터가 한 번 더 확인하고, 상담 때 함께 다듬어요. 예식 9일 전까지 언제든 고칠 수 있어요.` (완료=확정 아님을 명시해 완성 부담 제거)
- **준비물 체크리스트 자동 생성**(선택 기반): 예) 편지 선택 → `부모님께 드릴 편지 쓰기` · 축가 → `{부르는 분}과 곡 연습` · 영상 → `영상 파일 예식 3일 전까지 전달` · 자작 서약 → `서로에게 쓸 서약 준비`. 큐시트 아래 체크 목록으로 노출(대본을 행동 계획으로 승격).
- **대본 복사 버튼**: `대본 텍스트 복사` (카톡 붙여넣기용 · 신랑·신부 상호 공유 니즈 해결. 공유 링크·이미지는 v2)
- 사회자 모드(host='mc')일 때: 🔊 라벨을 `사회자 멘트`로, 안내를 `이 대본을 사회자분께 전해 주세요. 읽기만 하면 되도록 완성돼 있어요.`
- 버튼: `완료` (last=true 저장 → 대시보드 복귀)

## 3. 시간 계산 스펙

```
총 예산            = 30분 (입장 5분 포함 · sequence-modal 근거)
고정               = 10분: 개식 2 + 입장 5 + 성혼 2 + 폐식 1
형태 고정          = 환영 2 + 서약(문답 3 | 자작 4) + 예물 2 (해제 시 0)
자유 예산          = 30 - 고정 - 형태 고정   (= 11~13분)
선택 합            = Σ 카탈로그 분(이벤트별 · 나레이션 진입 포함 정의) · 영상은 입력 길이 사용(기본 3)
남은 시간          = 자유 예산 - 선택 합   (음수 = 초과 경고 · 저장 허용)
실시각             = base.weddingTime(10:00|13:20|16:40)부터 누적 (미확정이면 0:00 상대 표기)
```

## 4. 데이터 스키마 (ritualDraft v2)

```js
{ _v:2, _step:0,
  tone:'차분'|'유쾌'|'심플',
  host:'narration'|'mc',                    // 기본 narration
  vow:'문답'|'자작', welcome:'직접'|'나레이션', ringExchange:true,
  events:['letter','song',...],             // 선택 칩 key

```

**고정 블록 나레이션(초안 · 검수 대상)**
- 개식: `오늘 {신랑}, {신부} 두 사람이 부부가 되는 자리에 함께해 주셔서 감사합니다. 지금부터 두 사람의 결혼식을 시작합니다.`
- 입장: `서로의 가장 좋은 친구이자 이제 평생의 동반자가 될 두 사람입니다. 신랑 {신랑}, 신부 {신부}, 함께 입장합니다.`
- 환영(나레이션 대행): `먼 걸음 해 주신 한 분 한 분께, 두 사람이 마음 깊이 감사드립니다.` / (직접): `먼저, 두 사람이 준비한 첫 인사가 있습니다.`
- 서약(문답): `이제 두 사람에게 묻습니다. 서로를 평생 아끼고 지키겠습니까.` / (자작): `두 사람이 서로에게 직접 쓴 약속을 꺼냅니다.`
- 예물: `약속의 증표로, 두 사람이 반지를 나눕니다.`
- 성혼: `두 사람은 오늘, 가장 소중한 분들 앞에서 부부가 되었음을 선언합니다.`
- 폐식: `이것으로 예식을 마칩니다. 이어서 가족·지인 단체 사진 촬영이 있겠습니다. 하객 여러분은 잠시 자리에서 기다려 주세요.`

※ 문구 규칙: 고객 노출 문구에 전각 줄표 금지(CLAUDE.md). 이름 미입력 시 `신랑`/`신부`로 폴백.

## 8. 완료 후 (대시보드·큐시트 홈)

- tracks.ritual='완료' (기존 흐름 그대로 · GAS 무변경).
- 행 요약: `7순서 · 26분` (+사회자 모드 시 `· 사회자 진행`) + 미입력 시 `채울 것 N개` 뱃지.
- **재진입 = 큐시트 홈(위저드 아님)**: 완료 후 `완료 · 수정` 탭 시 S6와 같은 큐시트 화면이 먼저 열리고, 섹션별 `수정` 버튼으로 해당 스텝만 점프(수정 후 큐시트 홈으로 복귀). 처음부터 6스텝을 다시 걷지 않는다. 첫 작성=위저드 · 재방문=편집기.
- `채울 것` 뱃지 탭 → 큐시트 홈의 해당 미입력 카드로 바로 스크롤.
- D-9 소프트 락(§9): 큐시트 홈은 열람 가능 · 수정 버튼만 잠금.
