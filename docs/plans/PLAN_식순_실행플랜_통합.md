## A. 확정된 시스템 (한 장 요약)

**철학**: 사회자·주례 없이 성우 나레이션이 예식을 이끈다. 고객은 완성된 뼈대에 순간을 얹고,
자기 예식 나레이션을 미리 듣고 당일 전에 연습한다. 운영자는 1회 녹음으로 전 고객 무한 재사용.

**구조**
- 자물쇠 3(전 예식 공통): 입장 · 환영/첫인사 · 폐식·단체촬영
- 코스 프리셋(담백·감동·가족) 택1 → 슬롯 1~3개 스왑
- 오디오 = 코스별 묶음 세그먼트 [BGM + 앞 마무리멘트 + 브릿지 + 다음 시작멘트]
- 멘트: 자기완결 문형(이어서·다음은 금지) · 이름 무이름 통일 · 따뜻+유려+심리장치 · 핵심블록 2~3버전
- 당일: 반자동 GO 콘솔(운영자 "다음"만) · 마이페이지 미리듣기와 manifest 공유

**한국 근거(연구1~2)**: 주례없는 식 표준 · 감동 1위=편지·서약 · 축가/내빈축사 배제 · 어른 격식+진심 · peak-end(정점 65~85%·종점 정돈된 벅참) · 통과의례 통합.

**이벤트 카탈로그(담백 코스)**: 입장·환영·서약·반지·성혼선언·편지·폐식 (+옵션: 와인/케이크·부모덕담).

## D. 개선책 (이번에 새로 도출)

1. **대표 목소리를 진짜로 들려주기** — 사장님이 이미 나레이션 샘플 mp3를 갖고 계심. "대표 목소리 들어보기"에 **실제 파일 1개만 연결**하면, 목업이 아니라 진짜로 들려 "이 상품이 되는구나"가 즉시 증명됨. (프로토타입 신뢰도 급상승 · 파일 1개만 assets에 올리면 됨)
2. **코스 화면의 버튼 중복 정리** — "추천 바로완성/하나씩 다듬기" 두 CTA + 하단 "다음"이 겹침. 하단 버튼을 숨기거나 역할 분리해 혼란 제거.
3. **완성 화면 길이** — 대본 전문이 길어 스크롤이 김. "순서별 대본"을 기본 접힘 + 펼치기로 하면 완성 첫인상이 깔끔.
4. **하객 입장 스텝을 미니멀 경로에선 건너뛰기** — 결정이 없는 정보 스텝이라, "추천 바로완성" 흐름에선 생략하고 완성 화면에 요약만.
5. **기한 통일** — 화면 D-9 vs AI 상담사 "2주 전" 불일치. 이식 때 한쪽으로 통일(추천: D-9 또는 D-14 택1).
