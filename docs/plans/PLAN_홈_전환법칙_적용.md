# PLAN — 랜딩·상세페이지 전환 법칙 연구 종합 · 홈 적용안

작성: 2026-07-04 · 근거: 이중 연구(딥리서치 워크플로 검증 + 클로드 연구모드 리포트) 교차 대조
워크플로 검증: 50ms 첫인상(Lindgaard 2006)·17ms 재현(Tuch 2012) 관련 8건 판정 전원 통과(반박 0)

## 1. 법칙별 최종 판정 (두 연구 교차)

### 양쪽 합치 · 신뢰 강함 (원칙으로 채택)
| 법칙 | 내용 | 근거 |
|---|---|---|
| 50ms(~17ms) 첫인상 | 미적 판단은 0.05초 안에 형성·이후 불변. 낮은 시각 복잡도 + 높은 원형성(익숙한 업종 신호)이 유리 | Lindgaard 2006 ✓검증 + Tuch 2012 ✓검증 |
| 상단 집중·스크롤은 함 | 시청 시간 57%가 첫 화면, 74%가 두 화면 안. 그러나 76%는 스크롤함 → "fold 아래는 안 본다"는 절대주의는 오류 | NN/g 2018 + ClickTale·Chartbeat |
| F패턴 = 실패 모드 | F패턴은 포맷 안 된 텍스트에서 나오는 스캔 습관. 소제목·시각 위계로 레이어케이크 스캔을 유도해야 | NN/g 2006·2017 재검토 |
| 양면 메시지(단점 인정) | 단점을 함께 말하면 신뢰도↑ → 구매의도↑ (메타 217개 효과크기). **고관여 소비자에서 더 효과** = 웨딩에 적합 | Eisend 2006 메타 + O'Keefe 1999 |
| 잼 실험 보편화는 반박 | 선택지 수 평균 효과 ≈ 0 (50개 연구 메타). 단일 패키지 구조는 어차피 무관 | Scheibehenne 2010 |

### 워크플로만 확보한 뉘앙스 (적용 시 주의점)
- **양면 메시지 역U자**: 단점 인정은 '적당량'일 때만 효과. 과하면 역효과. 자발적 공개 + 배치 위치가 조절 변수.
- **고관여 조건**: 양면 메시지 효과는 고관여(웨딩) 소비자에서 증폭 → 모먼트에디트의 "정직하게 말씀드리면(1인당 단가는 오를 수 있다)" 류 화법은 실증적으로 옳음.

### 연구모드만 확보 (등급 보통 · 방향성으로 채택)
- Highrise 사례: 사람 사진 히어로 +47~102%, 단 정보 추가로 -22%도 → 첫 화면은 감정+한 줄, 정보는 단계적으로.
- Unbounce 벤치마크(18,639개): 경쟁 CTA 1개 13.5% > 2개 11.9% > 3개+ 10.5% → 전환 목표 단일화.
- 캐러셀 반박(Runyon): 자동 회전 배너 클릭 1.07%·그중 84%가 첫 슬라이드 → 자동 캐러셀 금지(사용자 통제 갤러리는 예외).
- Binet & Field 60/40: 감정 6 : 정보 4 (원연구는 대형 브랜드 광고 기반 · 랜딩 직접 적용은 근사치).
- 위험 역전: 환불 보증을 CTA 옆에 명시 시 고가일수록 효과 큼 (사례 기반 · 방향성 강함).
- 8초 집중력·금붕어 = 허구(BBC 팩트체크) → "3초 안에 다 보여줘야" 강박으로 정보를 깎지 말 것.

### 충돌·조정 지점
1. **히어로 무드 화면 vs 가치제안**: 연구모드 1순위 권고는 "첫 화면에 한 줄 가치제안+CTA". 우리 진사 화면은 시각 복잡도는 낮으나(유리) **원형성이 낮음**(웨딩 사이트임을 0.05초에 전달 못함). 절충: 브랜드 무드 유지 + 워드마크 아래 한국어 한 줄(무엇을·누구에게) + 기존 Scroll 단서 유지. 커플 사진·CTA까지 첫 화면에 넣는 건 브랜드 톤 훼손이라 보류.
2. **시선 유도·얼굴 효과 vs 무얼굴 원칙**: 시선 단서·얼굴의 효과는 실증되나, 오픈 전 AI 얼굴은 신뢰 리스크(기존 결정 유지). 실촬영본 확보 후 2단계로 승격. 그 전에는 구도·방향선으로 대체.

## 2. 현 사이트 대조 — 이미 맞는 것 (유지)

- ✅ 가격 투명 공개 + 포함/불포함 표(Transparency 블록) = 신뢰 신호 1순위 이행 중
- ✅ 단일 패키지 = 선택 과부하 무관
- ✅ 자동 캐러셀 없음 · 갤러리는 정지 그리드
- ✅ 문제 제기(A Long Day) → 해결 구조 = PAS와 부합(단 PAS 자체는 휴리스틱)
- ✅ 긴 페이지 + 섹션별 감정/정보 분리 ≈ 60/40
- ✅ 반론 선제 처리 일부: 스몰웨딩 단가 정직 화법(양면 메시지)·부모님 안내문·환불 조건 명시
- ✅ 소제목·시각 위계(레이어케이크 스캔 유도)

## 3. 개선 후보 (우선순위 · ★=즉시 반영 가능)

1. ★ **히어로 한 줄 가치제안**: 진사 화면 워드마크 아래(eyebrow 근처)에 "양가 가족 25명 · 140분의 프라이빗 웨딩" 류 한국어 한 줄. 50ms 원형성 보강. 디졸브 연출과 공존.
2. ★ **CTA 옆 위험 역전 한 줄**: 'Start Your Narrative' 버튼 바로 아래에 "상담 예약금은 계약을 진행하지 않으셔도 전액 환불됩니다" 명시(현재 terms 블록에는 있으나 버튼 옆에는 없음).
3. **CTA 단일성 점검**: '상담 예약' 단일 목표 유지 확인. 우측 FAB의 예약 아이콘은 동일 목표라 유지, 경쟁 CTA 병렬 노출은 금지 원칙 문서화.
4. **가격 도달 전 이탈 대비**: 가격이 페이지 중반 → 상단 1/3에 "280/210만원 · 필수 추가비용 없음" 예고 한 줄 검토(연구모드 2순위 권고. 단 프리미엄 톤과 상충 여지 → 사용자 판단 필요).
5. (2단계·실촬영 후) 얼굴 있는 실사진 승격 + 시선 방향을 가격표·CTA로.
6. (계측) 스크롤 깊이·섹션 도달률 측정 도입 후 A/B — 모든 사례 수치는 타사 맥락이므로 자체 검증 필수.

## 4. 한계

- CRO 사례 수치(Highrise·Unbounce·보증 사례)는 단일 기업 A/B라 방향성으로만.
- 가격 공개 우위 데이터는 B2B/이커머스 편중(원리는 고가 감성 구매에 더 강하게 적용될 개연성).
- 아이트래킹은 언어·기기 의존 → 모바일 비중 높으면 재확인.
