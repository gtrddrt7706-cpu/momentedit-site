## 2. 제작 크래프트 — 엔드투엔드 (이 문서의 척추)

### 2-1. 프리프로덕션 (여기서 완성도의 70%가 갈린다)
- **무드보드 2장**(캔들/화이트) 확정 → 색·질감·조도·구도 레퍼런스를 모아 "정본 룩"을 눈으로 고정.
- **키프레임(마스터 스틸) 설계**: 각 장면의 **첫 프레임을 이미지로 먼저 생성**한다. 텍스트→영상보다 **이미지→영상(i2v)** 이 톤·구도·브랜드 일관성에서 압도적으로 유리. 스틸에서 색·구도가 이미 맞으면 영상은 "움직임만" 얹는 문제로 축소됨.
- **샷리스트**: 각 컷에 `무드 / 프레이밍 / 피사체·동작 / 조명 / 렌즈 / 카메라무빙 / 길이 / 피할 것`을 미리 적어둔다(§4 표가 그 틀).

### 2-2. 프롬프트 크래프트 (프로 vs 아마추어)
아마추어=명사 나열("웨딩, 반지, 예쁜"). 프로=**촬영 지시서처럼 광학·조명·모션을 특정**. 순서 템플릿:

> `[프레이밍/샷] + [피사체·동작 — 얼굴 최소화] + [공간] + [조명·색온도] + [렌즈/광학] + [카메라 무빙] + [무드·그레이드] + [필름 질감] + [속도/길이] + [피할 것(negative)]`

- **얼굴 최소화 = 최대 무기**: AI의 최대 약점(얼굴 모핑·언캐니)을 프레이밍으로 원천 회피. "over-the-shoulder / from behind / hands only / silhouette / cropped at chin" 등을 명시.
- **손·반지 클로즈업은 오히려 위험**(손가락 왜곡). → 동작을 단순화·느리게, 부분 프레이밍, 얕은 심도로 디테일만.
- **텍스트를 영상에 굽지 말 것**(자막·타이포는 전부 HTML 오버레이 — AI 텍스트는 깨지고 수정·접근성·i18n도 불리).

### 2-3. 생성·반복 (리롤은 비용이자 실력)
- **쓸 컷 1개 = 보통 4~10회 리롤** 각오(장면 난이도·도구별 상이). 예산·시간은 이 배수로 계산.
- **흔한 실패 모드 → 대응**
  - 얼굴 뭉개짐/모핑 → 얼굴을 프레임 밖으로(뒷모습·손·실루엣), 클립 짧게(5s), 모션 약하게
  - 손가락·사물 왜곡 → 복잡한 손동작 금지, 와이드/부분 프레이밍, 슬로우
  - 플리커·떨림 → 깨끗한 스틸에서 i2v, 카메라 이동 최소화
  - 배경 왜곡·녹아내림 → 단순한 배경, 카메라 트래블 축소
  - 과한 좀비 슬로우모 → "natural real-time motion, subtle" 지정
- **선별 기준**: ① 물리 자연스러움(중력·천의 흔들림) ② 조명 방향 일관 ③ 모핑 0 ④ 심도 자연 ⑤ 무드 적중. 하나라도 깨지면 버림.

### 2-4. 포스트프로덕션 (제네릭을 프리미엄으로 바꾸는 단계)
- **컬러그레이딩 = 브랜드 통일의 핵심.** 서로 다른 AI 클립을 **두 개의 LUT**로 묶어 한 컬렉션처럼:
  - **캔들 LUT**: 웜(약 3200~3600K)·앰버, 블랙 살짝 리프트, 부드러운 할레이션, 미세 필름 그레인 → 온기·몽환·필름 감성
  - **화이트 LUT**: 뉴트럴~살짝 쿨(5200~5600K), 하이라이트 클린, 저채도, 여백감, 그레인 최소 → 미니멀·에디토리얼
- **업스케일**(Topaz Video AI 등)로 HD/4K·디테일 회복 · **디노이즈**로 AI 특유 노이즈 제거.
- **스피드 램프**로 정적 우아함 연출(살짝 느리게) · **심리스 루프**(끝→처음 크로스페이드 또는 처음부터 루프 가능하게 생성).
- 웹은 **무음 루프**라 사운드 불필요 → 대신 **모션 리듬**(느린 푸시인의 호흡)이 사운드 역할.

### 2-5. 완성도 루브릭 (프리미엄 vs 싸구려 체크)
✅ 프리미엄: 절제된 모션 · 일관된 조명방향 · 자연 심도 · 필름 질감 · 세트 전체 색 통일 · 얼굴 노출 최소 · 한 컷당 "하나의 순간"만
🚫 싸구려 신호(피할 클리셰): 과한 슬로우모+렌즈플레어 남발 · 비현실적 매끈함(플라스틱 피부) · CG 꽃잎 폭우 · 무의미한 드론 회전 · 모핑·6손가락 · 스톡틱한 미소 정면 · 서구 대성당 디폴트

**두 무드를 구분하되 한 브랜드로 통일**: 프레이밍 문법(느린 푸시인·얕은 심도)과 절제된 페이싱은 공유, 색·질감만 분기.

| | 캔들존 | 화이트존 |
|---|---|---|
| 감정 | 온기·친밀·몽환 | 정갈·여백·에디토리얼 |
| 빛 | 촛불·역광·실내 텅스텐, 그림자 살림 | 창가 자연광·소프트, 그림자 최소 |

## 5. 일관성 워크플로 (수십 컷 = 한 컬렉션)

1. **공간별 마스터 키프레임 2장**(캔들/화이트) 확정 → 모든 클립은 이 스틸의 색·조도에서 파생.
2. **레퍼런스 이미지 시딩**: i2v로 시작 프레임을 고정(같은 공간·톤 반복).
3. **렌즈 언어 통일**: 얕은 심도 + 느린 무빙 문법을 전 컷 공유.
4. **소품·의상·색 팔레트 고정**: 얼굴을 안 쓰므로 **손·의상·공간·색이 일관성의 새 축**.
5. **후반 LUT 일괄 적용**: 서로 다른 도구/세션 클립도 두 LUT로 묶으면 한 룩.

## 6. 웹·마이페이지 삽입 실행안 (기능적 완결)

**포맷·성능**
- 코덱: **MP4(H.264)** 기본 + 가능하면 **WebM(VP9/AV1)** 병행(용량↓). **poster**(첫 프레임 JPG) 필수.
- 스펙: 5~10s 루프 · 720~1080p · **목표 용량 1~2MB/클립** · `muted autoplay loop playsinline preload="metadata"`.
- **lazy load**: IntersectionObserver로 뷰포트 진입 시 로드(초기 로딩·모바일 데이터 절약).
- **`prefers-reduced-motion` 존중**: 모션 민감 사용자에겐 **poster 정지 이미지만**(접근성·필수).
- **onerror 폴백**: 현행 jpg 슬롯처럼 실패 시 이미지로 대체.

**호스팅 (중요)**
- 대용량 MP4를 **git에 커밋 금지**(레포·Vercel 비대). → **CDN/Cloudflare Stream/Bunny/Vimeo** 등 외부 호스팅 후 링크. 정적 슬롯만 소용량이면 `/assets`도 가능하나 여러 클립이면 CDN 권장.

**삽입 지점 현황(코드 확인 완료)**
- **E(스냅 무드)** → `mypage.html` SNAPFLOW **무드 타일에 교체 지점 이미 설계됨**(주석: "톤 스와치 임시·추후 실제 예시로 교체"). **바로 붙일 수 있음.**
- **A(홈 이미지 슬롯)** → `/assets/home/*.jpg`를 `<video poster>`로 교체(구조 소규모 변경).
- **C(식순 이벤트)** → `order-preview.html` 이벤트 상세가 **텍스트 전용 → 영상 슬롯 UI 신규 제작 필요**(파일 교체 아님·별도 작업).

**샘플 스니펫**
```html
<video class="ph-vid" poster="/assets/home/snap.jpg"
       muted loop playsinline preload="none"
       onerror="this.replaceWith(Object.assign(new Image(),{src:this.poster}))">
  <source data-src="cdn.../snap.webm" type="video/webm">
  <source data-src="cdn.../snap.mp4"  type="video/mp4">
</video>
<!-- IntersectionObserver로 data-src→src 승격 후 play() · prefers-reduced-motion이면 승격 스킵 -->
```

## 7. 가드레일 (핵심은 아니나 놓치면 큰일)

- **표시 정직성**: AI 생성컷은 실촬영 포트폴리오로 오인되지 않게 **라벨 표기**("연출 예시" · "AI로 시각화한 예시"). 이 브랜드의 '진정성' 가치와 직결 → 위반 시 신뢰 타격. (실촬영 자산이 생기면 우선 교체 — `나중에할일_체크리스트.md` 방침과 동일)
- **상업권**: 유료 플랜·상업 사용 허용 확인, 생성물 소유권·저작권·면책 조항 점검.
- **초상권**: 실존 인물 닮은 얼굴 생성 회피 → **얼굴 최소화 전략이 리스크를 크게 낮춤**(그래서 지금 방향이 옳음).
- **문화 정확성**: AI는 서구 대성당·유니티캔들·라이스샤워를 디폴트로 내는 경향 → 한국 마이크로웨딩(소규모·주례 없음·정갈)로 프롬프트 교정, 어색한 한복·예식 소품 자동생성 주의.
- **웹 성능/SEO**: 영상 다수 = 무거움 → §6 lazy·poster·용량예산·CDN로 방어.
