# 기획 스탠바이: 마이페이지 스냅사진 파트 (2026-07-19 · 정보 수집 완료 · 방향 확정 대기)

> 목적: "예식 준비" 앞 적절한 위치에 **스냅사진 파트**를 추가하기 위한 기획 준비. 이 문서는 사이트 전역의 스냅 관련 사실을 한곳에 모은 **단일 근거 자료**다. 방향(범위·위치·대상 상품)이 확정되면 이 문서를 실제 제작안으로 승격한다.

## 0. 한눈에 — 지금 비어 있는 자리

- **사후(결과물)** 는 이미 촘촘함: 원본 도착 → 보정할 컷 번호로 선택 → 보정본 확인 → 후기. (`renderResult`, 상태 5종)
- **사전(촬영 전 스냅 기획)** 은 비어 있음: 부부가 원하는 **무드·레퍼런스·필수 컷·포즈·가족 조합**을 촬영 전에 디렉터에게 전달할 자리가 **없다.** (마케팅·문의폼에도 구조화된 필수컷/포즈/가족조합 체크리스트 없음 — 세 조사 모두 '순증 콘텐츠 필요'로 표시)
- 가장 가까운 선례: **단체 사진 구도**(`PHOTOFLOW`, guideinfo 트랙의 `photo`/`photoFx`) — 본식 뒤 Group Record용. 스냅 파트는 이 패턴을 그대로 확장 가능.

## 5. 확정된 방향 (2026-07-19 사용자 결정)

- [x] **범위/목적 = 촬영 전 사전 기획** — 무드/레퍼런스·필수 컷·포즈 톤 등을 디렉터에 전달. (Private Snap 부부 단독 중심 — Group Record는 단체사진 트랙이 이미 담당)
- [x] **위치 = 여정 STEP으로** — 트랙 행/별도 카드가 아니라 상단 여정에서 "예식 준비(제작)" 앞에 보이는 **하나의 단계**로 노출.
- [x] **대상 = 시그니처(예식) 먼저** — 이후 웨딩스냅 확장.

### ★ "여정 STEP" 구현 갈림길 (제작안에서 확정)
'촬영 전 사전 기획'은 **부부가 셀프로 채우는** 성격 → 관리자가 현재단계를 옮겨야 진행되는 진짜 `STAGE_FLOW` 단계와 성격이 다름. 두 실현안:
- **(A) 진짜 STAGE_FLOW 단계 신설** — `입금완료`와 `제작중` 사이에 `스냅기획` 단계 추가. 진행바에 독립 dot로 명확. 단 관리자 게이팅·자동전이 로직·알림톡·6종 문구까지 파급 큼. 셀프서브와 궁합 안 좋음(누가 다음 단계로 넘기나).
- **(B) 셀프서브 STEP 렌더(추천)** — 백엔드 STAGE_FLOW는 그대로. 마이페이지 진행바에서 `제작중` 앞에 **'스냅 기획' 스텝을 시각적으로 삽입**하고, 데이터는 `제작임시저장`의 새 `snap` 트랙에 저장(셀프서브). 부부가 채우면 스텝 완료 표시. 청첩장·식순처럼 셀프 진행하되 **표현만 독립 스텝**. 파급 최소·의도(진행바에 보이는 단계) 충족.
- 추천 = **(B)**. 제작안 v0은 B 기준으로 작성.

### 부수 정리 필요(정본화)
- 140분 중간 구간 분배 상충(마케팅 30 vs 모달 5+25+입장20) — 문구 재사용 전 통일.
- 스냅 결과물 "N일 후 전달"의 날짜 vs 주 표기(계약 2주/4주 vs 프론트 '약 2주/4주') — 일치 확인.

## 7. 제작안 v0 (제안 · 방향 B 기준 · 사용자 검토 대기)

### 7.1 고객 여정
- 진행바에서 `계약금 입금(입금완료)` 다음, `제작(예식 준비)` **앞**에 **'스냅 기획'** 스텝이 보인다(방향 B: 시각 삽입·셀프서브).
- 스텝 진입 → 전용 화면(**`SNAPFLOW`** — 좌석/단체사진과 동일한 '들어가서 채우고 저장 후 나가기' 패턴).
- 미완료여도 예식 준비는 진행 가능(스냅 기획은 **권장·비강제**). 완료 시 스텝 체크 + 요약.

### 7.2 입력 항목 (Private Snap 부부 단독 중심 · 전부 esc·길이가드)
1. **무드/톤** — 캔들존(따뜻)·화이트존(정갈) 각각 원하는 느낌. 칩(예: 잔잔한·유쾌한·시크·클래식·러블리) 다중 + 자유 한 줄.
2. **레퍼런스** — 참고 이미지 **링크**(핀터레스트·인스타 URL, 최대 N개) + 메모. *업로드는 저장/보관 부담이라 링크 우선. (결정: 업로드 지원 여부)*
3. **꼭 담고 싶은 컷(필수 컷)** — 칩(예: 전신·클로즈업·손·반지·뒷모습·창가 역광·후면 베일·소지품 플랫레이) 다중 + 직접 추가. (단체 조합은 여기 말고 '단체 사진' 트랙 안내로 링크)
4. **포즈/연출 톤** — 자연스러운/정적 에디토리얼/무빙·유쾌 중 택 + 한 줄.
5. **소품·의상 메모** — 가져올 소품, 착용 순서/의상 벌 수 관련 메모.
6. **디렉터에게 한마디** — 자유 서술(요청·꺼리는 것·컴플렉스 등).

### 7.3 데이터·반영처 (방향 B)
- 새 트랙 키 **`snap`** → `제작임시저장` JSON 안 `snapDraft:{ moods[], moodNote, refs[], mustCuts[], poseTone, poseNote, propsNote, directorNote }`. **새 시트 컬럼 0**.
- 저장: `apiTrackSave({action:'saveProductionTrack', track:'snap', draft, done})` — 전체 교체(guideinfo 방식).
