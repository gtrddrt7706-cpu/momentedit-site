## 5. 확정된 방향 (2026-07-19 사용자 결정)

- [x] **범위/목적 = 촬영 전 사전 기획** — 무드/레퍼런스·필수 컷·포즈 톤 등을 디렉터에 전달. (Private Snap 부부 단독 중심 — Group Record는 단체사진 트랙이 이미 담당)
- [x] **위치 = 여정 STEP으로** — 트랙 행/별도 카드가 아니라 상단 여정에서 "예식 준비(제작)" 앞에 보이는 **하나의 단계**로 노출.
- [x] **대상 = 시그니처(예식) 먼저** — 이후 웨딩스냅 확장.

### ★ "여정 STEP" 구현 갈림길 (제작안에서 확정)
'촬영 전 사전 기획'은 **부부가 셀프로 채우는** 성격 → 관리자가 현재단계를 옮겨야 진행되는 진짜 `STAGE_FLOW` 단계와 성격이 다름. 두 실현안:
- **(A) 진짜 STAGE_FLOW 단계 신설** — `입금완료`와 `제작중` 사이에 `스냅기획` 단계 추가. 진행바에 독립 dot로 명확. 단 관리자 게이팅·자동전이 로직·알림톡·6종 문구까지 파급 큼. 셀프서브와 궁합 안 좋음(누가 다음 단계로 넘기나).
- **(B) 셀프서브 STEP 렌더(추천)** — 백엔드 STAGE_FLOW는 그대로. 마이페이지 진행바에서 `제작중` 앞에 **'스냅 기획' 스텝을 시각적으로 삽입**하고, 데이터는 `제작임시저장`의 새 `snap` 트랙에 저장(셀프서브). 부부가 채우면 스텝 완료 표시. 청첩장·식순처럼 셀프 진행하되 **표현만 독립 스텝**. 파급 최소·의도(진행바에 보이는 단계) 충족.
- 추천 = **(B)**. 제작안 v0은 B 기준으로 작성.

### 부수 정리 필요(정본화)
- 140분 중간 구간 분배 상충(마케팅 30 vs 모달 5+25+입장20) — 문구 재사용 전 통일.
- 스냅 결과물 "N일 후 전달"의 날짜 vs 주 표기(계약 2주/4주 vs 프론트 '약 2주/4주') — 일치 확인.
- Group Record(단체 사진 구도)는 **이미 트랙 존재** → 스냅 사전 기획은 **Private Snap(부부 단독)** 중심으로 잡아 중복 회피.

### 11.2 부부 화면 — 다섯 걸음 (묻는 칸 = 알면 좋은 것 + 공간별 전할 말 · D16)
1. **이날의 스냅** (보여 주기만) — 도착 › 캔들존 · 화이트존 촬영 › 입장 준비 › 본식 흐름(D15 · 공간별 분 없이) · «헤어·메이크업을 마치고 도착 시각에 맞춰 와 주세요 · 늦으면 스냅 시간이 줄어요» · «안 고르셔도 공간마다 기본 4장면을 찍어요» · 마감 날짜
2. **캔들존** — 공간 사진 · 무드 한 줄 · «기본으로 담아요» 4장(고를 수 없음) · 고를 수 있는 8장 중 최대 4장(번호 1~4 = 우선순위) · 고른 장면에 준비물이 있으면 그 자리에서 안내 · «찾던 그림이 없나요?» 사진 3장 + 링크 · «사진작가에게 전할 말»(선택 · D16)
3. **화이트존** — 같은 구성
4. **작가가 알면 좋은 것** — 한 칸(잘 나오는 쪽 · 신경 쓰이는 점 · 피하고 싶은 것 · 가져오는 소품)
5. **작가에게 이렇게 전해요** — 공간별 기본 + 고른 장면(번호) + 올린 그림 + 전할 말 + 한 칸 + 준비물 체크 → **동의 체크(D14 · 처음 한 번)** → 저장
