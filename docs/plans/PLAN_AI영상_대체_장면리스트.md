# AI 영상 대체·삽입 장면 리스트 (2026-07-20 · 놓치지 말고 전수)

> 목적: 현재 사이트·상품 흐름에서 **사진(placeholder)·설명만 있는 자리**를 **AI 생성 영상(상황컷)** 으로 만들어 대체·삽입하기 위한 **전수 장면 목록**.
> 각 항목 = `장면 슬롯(어디에 들어가나)` + `연출(무엇을 만드나)`. 실제 촬영본이 쌓이기 전(운영 초기·Opening Honor 구간)까지 AI 영상으로 자리 채움.
> 규칙: 인물은 얼굴 식별 최소화(뒷모습·측면·손·실루엣 위주)로 개인정보/초상권 리스크 회피 · 톤은 스튜디오 두 무드(캔들 온기 / 에디토리얼 선·여백)에 맞춤.

> ## ★확정 범위 (2026-07-20 사용자 지시: "c,d,e만")
> **핵심(이번 제작) = C 식순 이벤트 · D 단체사진 구도 · E 스냅 무드.** (= 사용자가 처음 말한 식순 이벤트·단체사진·스냅사진)
> - **E = 마이페이지 스냅 설명 부분(SNAPFLOW)** 확정. `mypage.html`의 스냅 사전기획 화면 무드 칩·"꼭 담고 싶은 것" 칩과 1:1로 붙는 소스.
> - A(홈 슬롯)·B(시퀀스)·F(평일스냅)·G(다이닝)·H(2차 후보)는 **확장 후보(이번 범위 밖)** — 삭제 아님, 참고용 보존. 필요 시 꺼내 씀.
