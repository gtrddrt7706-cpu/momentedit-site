## 0. 한 줄 진단

**카피·구조·브랜드 톤은 이미 완성도가 높다.** 문구 규칙 위반은 사실상 없고(전각 줄표 0건·이모지 0건·나레이션 포지셔닝 준수), 섹션 서사도 문제 공감 → 우리의 답 → 증거 → 전환으로 잘 짜여 있다.
남은 것은 **시스템 층의 누수 3가지**다. ①우측 FAB 레일이 모바일에서 본문 위에 겹쳐 보인다 ②골드 부제 색이 전 섹션에서 대비 미달(마이페이지에서 이미 고친 문제가 홈에는 그대로) ③작은 탭 타깃 17건. 여기에 콘텐츠 공백 1건(디렉터 얼굴 부재)이 더해진다.

측정 사실: 총 길이 **약 20,700px = 첫 화면 24.6개 분량**, 폰트 크기 **36종**, 대비 미달 **58건**, 40px 미만 탭 타깃 **17건**, JS 오류 0건, 가로 스크롤 0.

## 1. 계측 요약 (근거)

| 항목 | 값 | 판정 |
|---|---|---|
| FAB 레일 박스(390px) | `left 350 ~ right 396` (뷰포트 390 초과 6px) | 본문 우측과 20px 겹침 |
| 본문(.faq-q) 박스(390px) | `left 20 ~ right 370` | 겹침 구간 350~370 |
| FAB 클릭 가로채기 | 히트테스트 결과 **0건**(펼침 정상 동작) | **기능은 정상 · 시각 문제** |
| 대비 미달(WCAG AA) | 58건 · 대부분 `rgb(184,154,117)` 골드 = **2.54:1** | 필요 4.5:1 |
| 탭 타깃 40px 미만 | 17건 (최소 17px) | 모바일 기준 미달 |
| 폰트 크기 종류 | 36종 | 마이페이지 20종보다 많음 |
| 가로 스크롤 / JS 오류 | 없음 / 0건 | 양호 |

★ 히어로·푸터의 대비 수치는 배경이 **사진·다크**라 자동 계측이 부정확하다. 58건에서 제외하고 육안 판정했다(양호).

## 2. 섹션별 검토 (스크롤 순서)

| # | 항목 | 내용 | 상태 |
|---|---|---|---|
| H1 | 히어로 체류 시간 | 900px 전체가 로고+Scroll뿐. 첫 화면에서 "무엇을 파는지"가 한 줄도 없다. 아래 `.hero-tease`가 있으나 스크롤해야 보임 | 제안 |
| H2 | Scroll 힌트 대비 | `rgba(245,240,232,.6)` 9px — 사진 밝은 영역에선 거의 안 보임. 불투명도 .75 또는 그림자 | 제안 |

| R2 | 부제 대비 | "새벽부터 자정까지"·"다섯 번째 식"·"견적에 없던 비용" 전부 골드 11px = 2.54:1 | 제안 |

### 2-6. JOURNEY · 진행 (1512px)

잘 된 것: 실제 마이페이지 화면 목업 + 캡션("계약 후, 두 분께 열리는 실제 진행 화면") + 01~04 요점. 제품을 파는 가장 좋은 방식.

| # | 항목 | 내용 | 상태 |
|---|---|---|---|
| J1 | **한 문단 안 어투 혼용** | "…두 분이 직접 **합니다**. 막막할 틈 없이, 진행은 저희가 곁에서 거들어 **드려요**." 합쇼체와 해요체가 한 칸 건너 섞임. 페이지 전체는 합쇼체 123 : 해요체 3으로 합쇼체 기조 | 제안 |
| J2 | CTA 라벨이 영문 | 주 버튼 `START YOUR NARRATIVE`, 뜻은 아래 작은 링크("프라이빗 방문 상담 예약하기")가 담당. 마이페이지는 "버튼 한글 통일"로 이미 결정된 원칙 | 제안 |
