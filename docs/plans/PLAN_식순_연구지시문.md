# PLAN · 식순 개편 연구 지시문 (클로드 연구모드용)

> 2026-07-11 작성 · 2026-07-12 **3단계 순차 로드맵으로 재편성**(사용자 지시).
> 각 지시문을 통째로 복사해 클로드 연구모드(딥리서치)에 붙여넣는다.

## ★ 연구 로드맵 — 3단계 순차 (하고 → 분석 → 다음에 주입)

병렬이 아니라 **순차**. 앞 단계 결과를 다음 단계 프롬프트의 [선행 결과]에 넣어 눈덩이처럼 쌓는다.
각 단계 끝에 **검토 게이트**(사용자 확인) 후 다음으로. 모든 연구에 **불변 제약**을 고정 주입:
`하객 최대 25명 · 성우 나레이션 진행(사회자 없음) · 전원 지정좌석 · 140분 시그니처 시퀀스 · 본식 25~30분`.

| 단계 | 목적 | 사용 지시문 | 산출물 |
|---|---|---|---|
| **연구 1 · 발견** ⏳결과수집중 | 일반+트렌드 식순 이벤트 전수 → 후보 풀 (현 12종 검증 포함) | R-DISCOVER(신규) + R7(벤치마크) | 이벤트 후보 목록·수요·트렌드 · **사용자 연구모드 결과 도착=`식순연구/연구1_이벤트전수_사용자연구모드.md`** · Claude 세션 딥리서치 진행 중 → 종합 예정 |
| **연구 2 · 설계** | 우리에 맞는 선별 + 마음을 움직이는 코스 구성 심리 | R2(감정곡선)+R6(소규모심리)+R1(나레이션 적합)+R9(커스텀 노출) | 코스 설계 원칙 + **기준 코스 1개 초안** |
| **연구 3 · 멘트 ★최중요·반복** | 나레이션 강점 살린 완성도 높은 멘트·코스별 변주 | R3(전환문법)+R5(문체)+R1(강점)+R8(BGM) | 멘트 설계 원칙 + 기준 코스 완성 멘트 + **코스 무드별 BGM 추천(유튜브 오디오보관함)** |

- 연구 3은 1회로 끝내지 않고 **초안 → 비평 → 심화 → 코스별 변주** 여러 라운드(토큰·시간 아끼지 않음).
- R4(이벤트 런북)는 코스 확정 후 운영 문서로 별도 진행(연구 아님·실무 정리).

## R-DISCOVER · 식순 이벤트 전수·트렌드 (연구 1 핵심)

```
[불변 제약] 하객 최대 25명 · 성우 나레이션 진행(사회자 없음) · 전원 지정좌석 · 140분 시그니처
시퀀스 · 본식 25~30분의 한국 소규모 프리미엄 웨딩 스튜디오 '모먼트에디트'.

[연구 질문] 결혼식 본식에 들어갈 수 있는 '식순 이벤트'를 전수 조사해 달라. 코스를 설계하기 전,
세상에 어떤 순서·의식·연출이 존재하는지 폭넓게 모으는 것이 목적이다.
1. 한국 예식의 전통·표준 순서 (개식·화촉·서약·성혼선언·양가인사·폐백 등) 각각의 유래·의미·현황
2. 요즘 트렌드(최근 3~5년): 스몰웨딩·하우스웨딩·채플·호텔에서 유행하는 새 이벤트
   (서명식, 와인/샌드/캔들 세리머니, 링워밍, 타임캡슐, 퍼스트룩, 편지낭독 등) — 인기 이유와 확산도
3. 해외(일본·서양) 예식 이벤트 중 한국 소규모에 이식 가능한 것 (베일다운, first dance, unity
   ceremony, toast 등)
4. 각 이벤트별: 소요 시간, 감정 톤(엄숙/감동/유쾌/따뜻), 필요 인원·소품, 소규모(25명) 적합도,
   나레이션 진행 적합도(사람 사회자 없이 오디오로 진행 가능한가)
5. 최근 예비부부가 '하고 싶어하는' vs '식상해하는' 이벤트 (후기·커뮤니티·플래너 콘텐츠 기반)
6. 우리가 현재 후보로 둔 12종(혼인서약·반지교환·성혼선언·편지낭독·부모님덕담·베일다운·링워밍·
   와인세리머니·축가·케이크커팅·영상상영·내빈축사)에서 빠졌을 수 있는 매력적인 이벤트

[산출물]
- 식순 이벤트 마스터 목록 (이벤트 · 유래/의미 · 소요 · 감정톤 · 소품 · 소규모적합 · 나레이션적합 ·
  트렌드도)
- '넣을 만한 것' 추천 top / '굳이 뺄 것' 목록 (근거 포함)
- 현 12종 대비 추가·교체 제안
```

## R3 · 전환(트랜지션) 문법 — 연구 3 재료

```
[배경] 한국의 소규모 웨딩 스튜디오 '모먼트에디트'를 운영한다. 하객 최대 25명, 전원 지정좌석.
사회자·주례 없이 미리 녹음된 성우 나레이션과 BGM만으로 본식(약 25~30분)을 처음부터 끝까지 진행한다.
본식은 고정 순서(신랑신부 입장, 첫인사, 마무리·단체촬영 안내)와 커플이 자유롭게 고른 선택 이벤트
(혼인서약, 반지교환, 성혼선언, 편지낭독, 부모님 덕담, 베일다운, 링워밍, 와인 세리머니, 축가,
케이크 커팅, 영상 상영, 내빈 축사)를 조립해 만든다. 커플마다 이벤트 조합과 순서가 달라진다.

[연구 질문] 진행자(MC) 없이 오디오(내레이션+음악)만으로 프로그램을 매끄럽게 전환하는 기법을
전방위로 조사해 달라.
1. 참고할 도메인: 시상식의 VCR·무대 전환, 공연·연극의 암전과 장면 전환, 박물관 오디오가이드의
   섹션 이동, 기내방송, 테마파크 프리쇼·라이드 내레이션, 라디오 프로그램의 코너 전환,
   다큐멘터리 내레이션의 시퀀스 연결. 각 도메인에서 쓰는 전환 장치(멘트 문형, 음악 브릿지,
   침묵, 사운드 이펙트, 톤 변화)를 구체적으로.
2. 순서가 바뀌어도 깨지지 않는 '모듈형' 진행 구조를 만들려면 내레이션 문장을 어떻게 설계해야
   하는가. (앞 순서를 지칭하지 않는 자기완결형 도입, 공용 전환 문구, 되는 문형과 안 되는 문형)
3. 전환에서 침묵과 음악의 길이: 몇 초가 자연스러운가. 이벤트 종료 후 다음 내레이션까지의
   호흡에 대한 실무 관행이나 연구.
4. 사람 진행자가 즉흥으로 하는 전환(박수 유도, 정리 멘트, 다음 예고)을 녹음된 오디오가
   대체하려면 어떤 장치가 필요한가.

[산출물]
- 도메인별 전환 기법 카탈로그 (기법 · 원리 · 우리 예식 적용 아이디어)
- 모듈형 내레이션 구조 제안 (블록 구성 · 문장 설계 규칙)
- 한국어 전환 문장 예시 20개 이상 (상황별: 감동→밝음, 밝음→엄숙, 이벤트→이벤트 일반형 등)
- 전환 타이밍(침묵·브릿지 길이) 가이드
```

## R4 · 이벤트별 실전 런북 재료 — 1순위

```
[배경] 한국의 소규모 웨딩 스튜디오 '모먼트에디트'. 하객 최대 25명, 전원 지정좌석, 원형 테이블 6개.
사회자 없이 녹음된 성우 나레이션+BGM으로 본식(25~30분)을 진행한다. 커플이 아래 12개 이벤트 중
원하는 것을 골라 식순을 조립한다: 혼인서약(문답형/자작 낭독), 반지(예물) 교환, 성혼선언,
편지낭독(신랑신부→부모님), 부모님 덕담(부모님→신랑신부), 베일다운(입장 직전 어머니),
링워밍(반지가 하객 손을 도는 의식), 와인 세리머니(타임캡슐 결합), 축가, 케이크 커팅,
영상 상영(성장·프러포즈 등), 내빈 인사·축사.

[연구 질문] 위 12개 이벤트 각각에 대해, 실제 웨딩 현장에서의 표준 진행을 상세히 조사해 달라.
이벤트마다:
1. 진행 스텝: 시작부터 끝까지 누가 무엇을 하는지 단계별로 (예: 편지낭독 = 마이크 전달 → 낭독자
   위치 이동 → 낭독 → 마무리 포옹/꽃 전달 → 자리 복귀)
2. 현실 소요 시간 범위 (짧게/보통/길게)
3. 신랑신부가 사전에 준비해야 할 것 (물품·연습·섭외·파일)
4. 스튜디오(주최측)가 준비해야 할 것 (물품·동선·음향)
5. 자주 생기는 실수·어색한 순간과 예방법 (한국 웨딩 후기·플래너 글 기반)
6. 음악·내레이션 큐 타이밍: 어디서 음악이 들어오고 빠지는 게 자연스러운가
7. 25명 소규모에 맞는 변형 팁
[산출물] 이벤트별 1페이지 런북 초안 (위 7항목 구조로 통일)
```

## R2 · 감정 곡선·식순 순서 심리학 — 1순위

3. 클라이맥스는 어디에 두는 게 좋은가 (중반? 종반?), 그리고 마지막 순서가 전체 기억에 미치는 영향

5. 종료 후 단체촬영으로 자연스럽게 이동시키려면 마지막을 어떤 정서로 닫아야 하는가
6. 실제 웨딩 플래너·연출가들이 쓰는 순서 배치 경험칙 (국내외)
[산출물] 25~30분 본식의 이상적 감정 아크 모델 + 이벤트 배치 원칙 목록(근거 포함) +
피해야 할 배치 안티패턴

## R1 · 나레이션 진행의 강점·심리 — 2순위

```
[배경] 한국의 소규모 웨딩 스튜디오 '모먼트에디트'. 사회자·주례 없이 미리 녹음된 성우 나레이션이
예식(25~30분)을 처음부터 끝까지 이끈다. 이 포맷을 마케팅 강점이자 연출 철학으로 다듬으려 한다.

4. 하객 입장에서 '진행자 없는 예식'이 어색하지 않으려면 무엇이 필요한가
[산출물] 강점 목록(근거 포함) · 약점+보완책 표 · 우리 포맷에 적용할 연출 원칙 10개 ·
마케팅 문구에 쓸 수 있는 한 줄 논리 3개

## R5 · 나레이션 문체·성우 대본 작법 — 2순위

```
[배경] 한국의 소규모 웨딩 스튜디오. 성우가 녹음할 예식 진행 나레이션 대본(문장 30~40개)을 쓴다.
신랑신부 이름은 오디오에 넣지 않는다(공용 파일). 예식은 하객 25명, 차분하고 감동적인 톤 기본.

[연구 질문]
1. 좋은 내레이션 문장의 조건: 다큐멘터리 내레이션, 시상식 오프닝 멘트, 박물관 오디오가이드,
   광고 보이스오버의 문장론 (문장 길이, 리듬, 호흡, 구어체 vs 문어체)
2. 한국어 경어 설계: 하객(청자)과 신랑신부(제3자)를 동시에 존대하는 자연스러운 화법,
   이름 없이도 차갑지 않게 지칭하는 표현 ('두 사람', '신랑', '오늘의 주인공' 등의 온도 차이)

## R9 · 커스텀(특별) 이벤트의 절제된 노출 — 2순위

```
[배경] 소규모 웨딩 스튜디오. 예식을 '추천 코스 택1 + 슬롯 소수 스왑'으로 설계했고 오디오는 코스별로
미리 제작된다. 목록 밖 '특별 이벤트'를 고객이 원하면 오디오를 한 번 더 제작해서라도 수용할 의향은
있으나, 대다수는 정해진 코스대로 하길 바란다. 운영자 심리 = "정해진 코스로 충분하다는 안정감은
주되, '원하면 이런 것도 가능하다'는 여지도 은근히 느끼게 하고 싶다."

[연구 질문]
1. 선택 과부하(choice overload) 연구: 기본안(default)의 힘, 옵션을 '있지만 강요하지 않게' 배치하는
   UX 패턴 (프리미엄 옵션·add-on을 절제되게 노출하는 사례: 항공 좌석 업그레이드, 코스요리 추가,
   호텔 어메니티 등)
2. '커스텀 가능하다'는 인식이 실제 선택률을 높이지 않아도 브랜드 만족·프리미엄감에 주는 심리 효과
   (mere availability effect, 자율성 지각)
3. 강요 없이 특별 옵션을 노출하는 카피·배치 기법 (작게·나중에·조건부로 여는 UI 패턴)
4. 반대 위험: 특별 옵션 노출이 오히려 '기본 코스가 부족한가' 하는 불안을 유발하지 않게 하는 방법
[산출물] 커스텀 이벤트 노출 UX 원칙 · 화면 배치/카피 예시 3안 · 피해야 할 안티패턴
```
