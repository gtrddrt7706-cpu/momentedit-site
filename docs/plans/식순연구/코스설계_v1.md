# 추천 코스 설계 v1 (확정 대기) — 2026-07-12

> 근거: 연구1 카탈로그(12종)·연구2 감정아크. 아키텍처(§13): 자물쇠 3 + 코스 프리셋 + 슬롯 스왑 1~3.
> 시간은 잠정(시간 라운드서 확정). 멘트는 연구3서 작성. 이름은 가안.

## 공통 자물쇠 (모든 코스 고정)
```
입장  →  환영·첫인사  →  [ 코스 본문 ]  →  폐식·단체촬영 안내
```
- 성장영상은 옵션이며 위치는 **식전/오프닝(앞)** 고정(연구2 안티패턴 회피).
- 정점은 본문 후반(65~85%), 끝은 정점보다 한 톤 낮은 정돈된 벅참 → 단체촬영.

## 코스 A · "담백" ★표준 상품 (약 25분)
**분위기**: 과한 연출 없이 정갈하게. 어른 하객 비중↑·격식 중시.
**본문 배열**
```
혼인서약(직접) → 반지교환 → 성혼선언 → [밸리 슬롯] → 편지낭독 → 부모님 덕담(정점)
```
**감정 아크**: 약속(중반)→밸리 이완→편지·덕담 정점→따뜻한 마무리.
**스왑 슬롯 (1~2개 허용)**
- 밸리 슬롯: `와인·유니티` / `케이크커팅` / `없음(더 담백)`
- 성혼선언 낭독 주체: `성우` / `가족` / `하객 함께`
- 편지 대상: `부모님께` / `서로에게` / `성우 대리 낭독`(오열 우려 시)

## 코스 B · "감동" (약 29분)
**분위기**: 감정 표현에 적극적·친구 하객 비중 있음. 눈물의 아크.
**본문 배열**
```
(베일다운·입장 직전) → 혼인서약(직접) → 반지교환 → [밸리: 케이크] → 편지낭독 → 부모님 헌정(정점) → 성혼선언(하객 합송)
```
**감정 아크**: 베일다운 첫 스파이크→서약 상승→케이크 밸리→편지·헌정 정점→합송 통합 여운.
**스왑 슬롯 (1~3개 허용)**
- 밸리 슬롯: `케이크` / `와인·유니티` / `없음`
- 베일다운: `포함` / `제외`
- 성혼선언: `하객 합송` / `가족 낭독` / `성우`

## 코스 C · "가족" (약 30분)
**분위기**: 양가 가족 유대가 핵심. 어른을 의례의 주체로. 가족애 극대.
**본문 배열**
```
(베일다운) → 부모님 덕담 → 혼인서약 → 링워밍(가족 축소) → 반지교환 → [밸리: 케이크] → 편지낭독(부모님께) → 부모님 헌정(정점) → 성혼선언(가족·합송)
```
**감정 아크**: 가족 서사→약속→가족 참여(링워밍 동조)→편지·헌정 정점→가족 합송 통합.
※ 감동 과다 방지: 덕담·헌정을 '부모님 순서'로 한 흐름 묶기. 타임캡슐은 옵션 스왑.
**스왑 슬롯 (1~3개 허용)**
- 링워밍: `가족 축소형` / `제외`
- 타임캡슐: `추가(정점 뒤)` / `없음`
- 밸리 슬롯: `케이크` / `와인·유니티` / `없음`

## 설계 규칙 (전 코스 공통)
1. **감동 이벤트 2개 이내** 유지(편지 + 부모 순서). 연속 배치 금지·사이에 밸리.
2. **차별화·연출(케이크·유니티·링워밍·타임캡슐·베일다운)은 코스별 스왑 슬롯으로만** — 우리 흐름이 안 무너짐.
3. **성장영상 = 앞**(옵션). 편지 배경 영상 겸용은 예외 허용.
4. 끝은 통합(성혼선언/헌정)→정돈된 벅참→단체촬영.
5. 특별(목록 밖) 요청 = 셀프 아님·상담 경로.

## 확정 후 → 연구 3
- 확정된 코스별로 **모듈형 나레이션 멘트**(시작·마무리·브릿지) 작성.
- 정점(편지)·통합(성혼선언 합송)이 멘트 최우선 대상.
- 이후 시간 라운드에서 이벤트별 소요·총시간 확정.
