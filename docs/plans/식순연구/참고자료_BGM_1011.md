## 결 (우리 음악 판에 옮길 것)

1. **시작과 끝은 밝게 · 의식은 잔잔하게** — 개식 · 행진은 경쾌, 서약 · 인사는 연주곡.
2. **이어지는 두 순서는 한 곡으로** — 맞절 → 서약, 부모님 인사 → 하객 인사. 곡 바꾸는 틈이 없어 매끄럽다.
   우리 뼈대로 옮기면 «입장 → 첫인사», «마음 칸 안 서약 → 맺음 한 줄», «감사 → 닫는 인사»가 한 곡 묶음이 된다.
3. 입장 · 행진곡은 «몇 초부터 걷기 시작하나»를 함께 적는다(콘솔 큐).
4. 나레이션이 얹히는 자리(우리는 거의 전부)는 가사 없는 연주곡이 맞다 — 보컬 곡은 나레이션이 없는 걸음 구간(입장 · 행진)에만.
