「어조를 다시 녹음한다」가 아니라 **글을 처음부터 새로 짠다.**

## 2. ★이 사실이 기준을 바꾼다 — 이 글은 「본보기」다

예식 당일 스피커로 나가는 것이 아니다. `order-preview.html` 「이 순간 들어보기」에서
**계약 전 고객이 듣는 견본**이고, 당일에는 **고객이 자기 편지를 직접 읽는다**
(당일 나레이션은 「지금 직접 읽어 주시면 됩니다」로 넘겨줄 뿐이다).

그러니 이 여섯 편의 임무는 «감동시키는 것»이 아니라
**«아, 이 정도면 나도 쓰겠다»를 만드는 것**이다.

- 너무 잘 쓰면 고객이 **겁을 먹는다.** 「나는 저렇게 못 쓰는데」
- 틀이 하나뿐이면 고객이 **그 틀로만 쓴다.** 자기 이야기가 들어갈 자리를 못 본다

## 3. 「억지감동」의 정체 — 세어 보니 여섯이 한 공식이었다

한 편씩 읽으면 나쁘지 않다. 문제는 **연달아 들을 때** 드러난다.

| 잰 것 | 결과 |
|---|---|
| 첫 문장이 **호명**으로 열린다 | **6/6** (「서준아, 하윤아」·「엄마, 아빠」·「어머니, 아버지」…) |
| 마지막이 **9~15음절 짧은 한 줄** 여운 | **6/6** |
| **과거 장면 표지**로 이야기를 연다 | **5/6** (지난겨울·고등학교 삼학년·스물넷·삼 주 전·얼마 전) |
| **「그때는 몰랐다 → 이제 안다」** 계열 | **4/6** (「이제 압니다」가 두 편에 같은 말로) |
| `bless-father` 의 「~다」 종결 | **14/14 = 100%** ← 사장님이 짚은 그 자리 |

즉 공식이 이것 하나다:

> **호명 → 과거 장면 하나 → 그때 몰랐던 것 → 짧은 여운 한 줄**

기법 자체는 좋다. **여섯이 다 같은 것이 문제다.** 틀이 보이는 순간 「지어낸 것」이 되고,
그게 사장님이 「억지감동을 만들어내는듯한」이라고 부른 것이다.

★ 그리고 이건 본보기이므로, 틀이 하나면 **고객의 편지도 전부 이 틀로 나온다.**

## 4. 그래서 새로 쓸 때의 기준

### 4-1. 여섯 편이 서로 다른 문으로 들어간다 (제일 중요)

한 편도 같은 방식으로 열지 않는다. 열 수 있는 문은 이만큼 있다.

| 여는 방식 | 예 |
|---|---|
| 지금 눈앞의 일 | 「지금 손이 떨려서 글씨가 잘 안 보입니다」 |
| 사물 하나 | 「이 반지는 크기를 두 번 줄였습니다」 |
| 상대의 말버릇 | 「너는 「알았어」를 세 번 말해야 진짜 알았다는 뜻이야」 |
| 숫자·계산 | 「오늘까지 사천이백 일을 같이 살았습니다」 |
| 질문 | 「아빠, 그때 왜 아무것도 안 물어보셨어요?」 |
| 거절·실패 | 「사실 저는 이 결혼을 한 번 반대했습니다」 |
| 농담 | 「우리 딸이 밥은 안 해요. 그건 미리 말씀드립니다」 |

★**호명으로 여는 것은 여섯 중 한두 편만.** 지금은 여섯 다 그렇게 연다.

### 4-2. 끝도 서로 다르게

지금은 여섯 다 「짧은 여운 한 줄」이다. 이 중 둘셋만 남기고 나머지는 다르게 닫는다.
- 부탁으로 닫기 — 「서준아, 이거 하나만 부탁하자」
- 농담으로 닫기 · 웃음으로 내려놓기
- 이어지는 말로 닫기 — 끝나지 않은 채 다음 순서로 넘어가기
- 상대에게 되묻기

### 4-3. 「이제 안다」를 넷 중 하나로 줄인다

뒤늦은 깨달음은 힘이 센 장치라 **한 편에만 쓴다.** 나머지는 다른 감정으로 간다 —
자랑·미안함·걱정·홀가분함·서운함·웃김. **감정이 여섯 가지면 공식이 안 보인다.**

### 4-4. 아버지 덕담 — 「과묵한 아버지」 설정을 버린다

`14/14 = 100%` 가 「~다」인 것은 캐릭터 설정이었는데, 사장님 판단은
**「모자란듯한 컨셉 · 별로 멋이 없다」**이다. 말수가 적은 것과 말이 서투른 것은 다르다.
아버지도 **문장을 갖춘 사람**으로 쓴다. 대신 그 사람다운 자리를 다른 데서 만든다.

### 4-5. 손대지 않는 것

- **인물 설정** — 이서준·정하윤과 가족 이름은 그대로 (다른 화면·도표가 이 이름을 쓴다)
- **길이 대역** — 묶음당 4~17문장의 지금 폭을 크게 벗어나지 않는다(녹음 단가·듣는 시간)
- **옛 의례 순서** 관련 낱말은 쓰지 않는다 (게이트가 막는다)
- 장식 이모지·전각 줄표 금지
