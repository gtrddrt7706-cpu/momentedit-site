## 2. 기준 (두 자료가 겹치는 곳)

- **본식은 25~30분.** 셋 다 이 안에서 «깔끔하다»를 말한다.
- 묶음별 몫: 여는 4.5~7 · 입장 3.5~8 · 감사 3~4 · 맺음 2.5~5.
- ★**약속 + 축하는 한 칸처럼 움직인다** — A 9+0 · B 6+5 · C 1.5+6 = **7.5~11분.** 한쪽이 길면 다른 쪽이 짧다.
  이 칸이 «그 예식의 성격»이다(A 서약 중심 · C 축하 중심).
- ★**감사(부모님께 인사)는 셋 다 3~4분으로 거의 같다** — 줄이지 않는 칸.
- 순서 수는 6~13 — 개수보다 **묶음 몫**이 같다(C: «순서를 빼기보다 순서마다 길이를 정해 두는 방식»).
- 축하(축사 · 축가)는 없어도 «깔끔했다»(A).
