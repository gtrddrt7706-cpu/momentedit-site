## 2. 기준 (두 자료가 겹치는 곳)

- **본식은 25~30분.** 셋 다 이 안에서 «깔끔하다»를 말한다.
- 묶음별 몫: 여는 4.5~7 · 입장 3.5~8 · 감사 3~4 · 맺음 2.5~5.
- ★**약속 + 축하는 한 칸처럼 움직인다** — A 9+0 · B 6+5 · C 1.5+6 = **7.5~11분.** 한쪽이 길면 다른 쪽이 짧다.
  이 칸이 «그 예식의 성격»이다(A 서약 중심 · C 축하 중심).
- ★**감사(부모님께 인사)는 셋 다 3~4분으로 거의 같다** — 줄이지 않는 칸.
- 순서 수는 6~13 — 개수보다 **묶음 몫**이 같다(C: «순서를 빼기보다 순서마다 길이를 정해 두는 방식»).
- 축하(축사 · 축가)는 없어도 «깔끔했다»(A).

## 5. D. 예식 식순 템플릿(노션 체크리스트 · 시간 없음 · 순서와 선택지만)

- 기본 1부: 화촉 → 신랑 입장 → 신부 입장 → 맞절 → 혼인서약 → 성혼선언 → 덕담 또는 축사 → 축가 → 양가 부모님께 인사 → 하객 인사 → 행진
  = 4장 뼈대(여는 · 입장 · 마음 칸 · 감사 · 맺음)와 **순서가 같다.**
- 화촉 한 칸에 «어머님 입장 · 점화 · 어머님 맞절 · 하객 인사 · 착석»이 다 들어 있다 — 걸음 · 인사 몫이 시간에 들어가야 한다.
- 부모님께 인사 뒤 **하객 인사**가 따로 있다(C 도 «부모님 · 하객 인사 4분»).
- ★**케이크 · 축배 · 테이블 인사는 «2부»** 순서다(재입장 → 케이크 → 축배 → 축가 · 이벤트 → 테이블 인사 → 감사 인사).
  우리는 이 셋을 본식 안(케이크 · 축배)과 닫는 인사 뒤(테이블 인사)에 섞어 두었다 — 반지 · 케이크를 코스에서 뺀 것과 같은 방향.
- 특별 순서 = 편지 · 감사 영상 · 이벤트 → 우리 «편지» · «준비한 순서».
- 이 템플릿의 빈칸은 «순서별 시간 · 동작 팁»이다 — 우리가 이미 가진 것(시간 띠 · 콘솔 안내)이라 차별점이 된다.

## 6. G. 주례 없는 결혼식 사회 대본(애봉네 · 구글 문서 템플릿 · 시간 없음)

순서 14: 식전 안내(5~10분 전) → 개식사 → **양가 부모님 입장 → 부모님이 하객께 먼저 인사** → 화촉(어머님 맞절) →
신랑 입장 → 신부 입장 → 하객 인사 · 맞절 → 혼인서약(두 분 직접 · 사회자 한 줄로 맺음) → 성혼선언(사회자가 하객 대표로) →
축가 2회 → 부모님께 인사(그 전에 두 분의 감사 한마디를 사회자가 대신 전함) → 하객 인사 → 행진 → 폐식 · 촬영 안내

- 뼈대(여는 · 입장 · 마음 칸 · 감사 · 맺음) 순서가 **다섯 번째로 같다.** 예물(반지) 교환 · 축사가 없어도 예식이 선다.
- 서약 뒤 «사회자 한 줄로 맺음» = 우리 «서약 끝에 한 줄로 흡수»(선언문 대신)와 같은 모양.

### 가져올 연출 (우리 판으로)

| 장치 | 그 대본 | 우리에게 |
|---|---|---|
| 상대를 한 문장으로 | 신부가 쓴 «신랑은 ○○한 사람» 한 문장을 사회자가 읽고 입장 | 입장 멘트에 «서로를 한 문장으로» 갈래 — 두 분이 써 두면 나레이션이 읽는다. ★나레이터 목소리로 고객 글을 읽으려면 그 자리 소리를 새로 만들어야 한다(지금 나레이션은 미리 녹음) — 두 분 AI 목소리 줄로 두는 쪽이 지금 구조에 맞다 |
