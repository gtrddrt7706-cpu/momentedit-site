# 한 문장만 고치는 법 (자주 쓰실 것)

문장 하나를 고치실 때 클립을 통째로 다시 받지 않습니다. **그 문장만** 받으면 됩니다.

## 왜 되나
`assets/audio/_src/` 에 문장 «한 자리»의 소리가 받은 그대로 들어 있습니다.
이름이 «클립#문장자리»라 대본이 늘거나 줄어도 안 밀립니다(`[SLOT_NAME]`).
무손실 flac 이라 소리는 안 상하고 크기는 절반입니다(`[FLAC_HALF]`).

## 순서 (네 걸음)

### 1. 지금 무엇이 비었는지 본다
```
node scripts/sent-lib.mjs
```
자리마다 **있음 / 글이 바뀌어 낡음 / 아직 없음**을 성우별로 세어 줍니다.

### 2. 문안을 고친다
원천은 둘뿐입니다.
- 나레이션 → `assets/ritual-data.js`
- 배역 대사 → `docs/plans/식순연구/배역_예시_대사.txt`
- 어른께 드리는 편지 → `scripts/build-dubbing-script.mjs` **와** `parents.html` (두 벌 · `[LETTER_MIRROR]` 가 대조)

고친 뒤 다시 뽑습니다.
```
node scripts/build-dubbing-script.mjs && node scripts/build-typecast-import.mjs --write \
  && node scripts/build-voice-parts.mjs --write && node scripts/build-redub-byvoice.mjs --write \
  && node scripts/build-emotion-check.mjs
```
이제 `node scripts/sent-lib.mjs` 가 그 자리를 **「글이 바뀌어 낡음」**으로 셉니다.

### 3. 그 문장만 받아 창고에 넣는다
타입캐스트에 그 줄만 붙여넣고 받은 wav 하나를:
```
node scripts/sent-lib.mjs --patch --sent "<고친 문장 그대로>" --wav <받은.wav>
```
같은 문장이 여러 클립에 있으면 **그 자리 전부**에 넣습니다(입장 6곳처럼).
★성우가 다른 자리에 걸친 문장이면 «거부»합니다 — 한 소리로 덮으면 안 되는 자리입니다.

여러 줄을 한 번에 받으셨으면 붙여넣기 순서표째로:
```
node scripts/sent-lib.mjs --import <받은폴더나zip>
```

### 4. 클립을 다시 붙인다
```
node scripts/sent-lib.mjs --stage /tmp/붙일것 --clip =12_bless-father
node scripts/assemble-narration.mjs --in /tmp/붙일것 --clip =12_bless-father
```
`--patch` 가 끝나면 위 두 줄을 «그대로 복사할 수 있게» 찍어 줍니다.

## 안 되는 것 (일부러 막아 둔 것)
- **글이 바뀐 자리는 깔기를 거부합니다.** 옛 소리를 새 글의 자리에 끼우는 것이 가장 나쁜 실패라서입니다.
- **조립된 mp3 를 잘라 쓰지 않습니다.** 정규화·페이드가 걸린 결과물이라 다시 인코딩하면 소리가 상하고,
  문장 경계를 무음으로 «추정»해야 합니다. 추정한 자리는 언젠가 틀립니다.
- **클립 이름만으로 짚지 않습니다.** `entry-C` 는 07·20 둘이라 `=20_entry-C` 처럼 번호까지 씁니다(`[KEY_NN]`).

## 검사
`node scripts/audit/sent-lib-check.mjs` — merge-guard 가 자동으로 돌립니다.
대장에 없는 자리가 창고에 있거나 파일이 사라지면 빨개집니다.
«글이 바뀐 자리»는 빨강이 아닙니다 — 문안을 고치면 당연히 낡고, 다시 받으면 됩니다.
