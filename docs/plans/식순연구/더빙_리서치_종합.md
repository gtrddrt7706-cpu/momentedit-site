## 가드레일 필터에서 '보류/탈락'시킨 것 (무분별 반영 방지)
- **핸드파스팅(손 묶기)** — 이국적·설명 필요 → 무이름·절제 결과 상충. 보류.
- **감사의 정적(10~20초 침묵 의식)** — 소규모라도 정적 관리 난도↑ → 운영 리스크로 보류.
- **오싱/위싱 스톤** — 우리 '링 워밍'과 메커니즘 중복 → 탈락.
- **샌드 유니티·나무 심기·반려동물 참여** — 캐주얼/로지스틱/오프브랜드 → 탈락(커플이 강히 원할 때만 개별).
- 문체: 예능형 감탄("자~ 갑니다·소리 질러"), 최상급 남발("세상에서 가장 아름다운"), 실명 호명 → 전부 채택 안 함.

# 버킷 A · 문안 수정 (정점 클립 재점검) — 출처 갈래 2

현재 대본은 이미 무이름·무클리셰로 양호. 아래는 **정점 4구간(입장·성혼선언·편지·폐식) 재점검 체크포인트**로, 미세 개선 후보입니다. (원천 `ritual-data.js`·`parents.html` 수정 → 빌더·AI 동시 반영. **코워크 확인 후 적용**)

**공통 원칙(P1)**
- 형용사 과잉 대신 **장면 명사**로 보여주기(감정은 하객이 느끼게, 나레이터는 '명명'만).
- 감정 **명령 금지**("울컥하는 순간입니다") → 명명("지금 이 정적이, 첫 약속입니다").
- 하객 참여는 **격식 청유**("함께해 주시기 바랍니다"), 나레이터는 자신을 낮춤(주어를 '두 사람·두 분'에).
- **3의 법칙**은 클립당 최대 1회. 한 문장 12~18음절(최대 25), 정점일수록 짧게.
- 마지막 문장은 5~7어절로 끊고 **여운 침묵 0.5~1초**.

**구간별 체크(P1)**
- **입장**: 첫 문장 7어절 이내 · 형용사 2개↓ · 나레이터 자기지시("제가 진행") 없음. (현행 6종 대체로 부합 — D/E는 문장 다소 길어 호흡 점검)
- **성혼선언**: '신랑 신부' 호칭 · `~습니다`체 · 사실 선포 위주(감정어 최소) · 클리셰 0. (현행 양호)
- **편지 낭독**: 나레이터는 프레임만, 낭독 뒤 **해설 금지**(짧은 명명 1문장 + 침묵). (현행 LETTER·letterEnd 양호 — letterEnd가 '해설'로 흐르지 않는지만 확인)
- **폐식**: 3중 감사 나열 금지(담백 1회) · 마지막 문장이 가장 짧게. (현행 close는 4문장 — 마지막 문장 길이·여운 점검)

# 버킷 B · 추가 클립 후보 (누락·신규 순간) — 출처 갈래 3·4  ★결정 필요(P1)

| 후보 | 무엇 | 나레이션 | 적합도 | 추천 |
|---|---|---|---|---|
| **봉인 편지함(타임캡슐)** | 편지·와인을 상자에 봉인 → N주년 개봉. '와인 유니티'와 다른 축(미래로 보내는 약속), 손에 남는 조용한 감동 | 필요(봉인 의미 1~2문장) | 높음(절제·무이름·기록과 정합) | **대본 추가 검토** |
| **부재한 이를 기리는 순간** | 먼저 떠난·못 온 어른 위한 빈자리·촛불 1점 + 짧은 정적. 이름 안 불러도 어른 반응 큼 | 필요(과묵하게 프레이밍) | 높음(어른 배려의 정수) | **옵션으로 추가 검토**(밝은 축하 코스엔 미노출) |
| **원격 하객 교감 큐** | 입장 직후 부부의 카메라 인사 + 화면 속 하객과 사운드 교감. 기존 '온라인 참석' 연출 강화 | 필요(교감 큐 여는 멘트) | 중~높음(저비용 개선) | **추가 검토** |
| **온라인 참석 배려 '한 줄'** | 입장/폐식에 원격 하객 호명 삽입구("화면 너머 함께해 주시는 분들도…") | 기존 클립에 삽입구 | 높음 | **삽입 검토**(입장·폐식 선택 변형) |
| **폐식 후 마무리 요약 방송** | 배웅·다음 동선·화장실 등 핵심 재요약(고령 배려 wrap-up) | 필요(안내방송 5번째) | 높음(브리핑 5-2와 동일) | **1클립 추가 검토** |
| **실시간 대기·재개 브릿지** | 순서 지연·오열 시 틀 중립 멘트 1~2 | 필요 | 중(운영 안전망) | **2클립 추가 검토**(브리핑 5-4) |

| 비공개(퍼스트룩) 서약 | 예식 전 둘만의 서약 기록 | 불필요(촬영 연출) | 중~높음 | **촬영 SOP**로(더빙 아님) |

# 버킷 C · 녹음·편집 세팅 — 출처 갈래 1  ★즉시 적용(P0)

대본 시트 상단 '세팅'에 반영. 43클립 공통 프리셋 + 정점 개별 튜닝.

**문안·입력(녹음 전 대본 손질)**
- 문장을 15~25자로 쪼개 마침표로 자동 쉼 생성 · 의미 단위마다 쉼표 1개.
- 정점(편지·성혼선언)은 **말줄임표(…)** 로 0.5초 정지 유도 · 핵심어 앞뒤 미세 쉼("이제 · 부부가 · 되었습니다").
- **숫자·시간은 한글로**("세 시 삼십 분"), 이름·영어는 **발음 표기**로(오독·연음 방지).

**세팅(합성 티 제거)**
- 속도·피치는 소폭만 — 정점 -5~-10%(느리게), 밝은 순간 +5~10%. **극단값 회피**.
- 감정군 프리셋: 차분(안내)·따뜻/먹먹(편지·성혼선언·베일·헌정)·밝음(입장·축배). 군별 일관.
- 제품: **타입캐스트**(문장별 감정+스마트이모션 초안→정점 수동보정) / **클로바더빙**(끝음 길이로 여운) / **ElevenLabs**(Stability 30~55·Style 25~50, 정점은 Stability↓).

**편집·믹싱**
- 클립 간 **무음 1.5~2.5초**(정점 뒤 2.5, 밝은 전환 1.5) — TTS는 여백을 안 남기니 편집으로 확보.
- BGM은 목소리보다 **-12~-18dB**, 목소리 구간 자동 더킹.
- 출력 **mp3 192kbps↑**, 낭독 **-16 LUFS**, 합본 **-14~-16 LUFS**로 균일화(볼륨 널뛰기 방지).
- **식장 스피커 실청 리허설**(헤드폰 OK여도 홀 울림에서 BGM에 목소리 묻힘 확인).

# 버킷 E · 게스트 경험·접근성 (안내방송 문안 개선) — 출처 갈래 4  ★결정 필요(P1)

식전 안내방송 4종을 어른·접근성 관점으로 개선(원천 `ritual-data.js` › `GUEST`. **코워크 확인 후 적용**).
- **천천히·핵심 앞뒤 반복** — 지정석·QR 같은 핵심은 첫머리+끝 요약.
- **QR은 비-스캔 대안 병기 필수** — "어려우시면 그대로 두셔도 돼요 · 종이 안내·직원 안내로 똑같이 보여 드려요".
- **지정석은 불안 제거 프레임** — "자리를 찾아 헤매실 필요 없이, 성함 있는 편한 자리로 모셨어요"(가나다순 안내).
- **거동·청각 배려 한 줄** — "이동이 불편하시면 직원에게 말씀해 주세요 · 잘 안 들리시면 손 들어 주시면 앞쪽으로 모실게요".
- **포용 언어** — 가족 형태 단정 회피("두 분을 아껴 오신 가족과 귀한 분들").
> 현행 GUEST 문안이 이미 상당 부분 반영(지정석·QR·스태프 안내). **QR 비-스캔 대안 한 줄**과 **청각 배려 한 줄**이 주요 보강 포인트.
