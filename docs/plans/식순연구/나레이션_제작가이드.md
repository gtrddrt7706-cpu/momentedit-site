# 나레이션 제작 가이드 (11/08 확정 · 새 나레이션 추가·수정 때 그대로 따름)

이 문서는 대본이 관리해요. 결정이 바뀌면 이 문서를 먼저 고치고, 근거는 «나레이션_전체재녹음_체크메모_1108.md» 기록에 남겨요.

## 1. 원칙
- 지금 사이트 판이 기준이에요. 더 나빠지지 않는 손질만 해요. 원래 녹음은 지우지 않아요.
- 검증·승인된 옵션은 수정·새 녹음·바꿔 끼우기·시범 할 것 없이 차례대로 전부 넣어서 최종을 만들어요 [APPLY_ALL_VERIFIED].
- 이미 고친 부분(예: 맞절 «신랑 신부» A3)이 있으면 항상 고친 판을 바탕으로 해요.
- 정도(%·초)는 대본이 근거와 함께 추천값 하나로 정해요. 사장님은 «남겨 / 빼»만 판단해요. 여러 단계 비교는 사장님이 원할 때만 만들어요 [RECOMMEND_DEFAULT].
- 사장님께 드리기 전에 대본이 «올리기 전 점검표»(7번)를 통과시켜요. 걸리면 고치거나 한 가지만 여쭌 뒤 드려요 [PRE_DELIVERY_GATE].
- 사이트 반영은 테스트를 다 끝낸 뒤 한 번에 해요. 순간마다 «지금 / 바뀐 뒤» 실청 → 사장님 승인 → 병합 → 대본이 사이트에서 다시 재서 확인해요 [ONE_MERGE].

## 2. 녹음 (새 문장이 필요할 때만)
- 먼저 확인: 기존 녹음이 대부분 좋고 일부만 걸리면 다시 녹음하지 않아요. 걸리는 낱말·구절만 새 테이크에서 가져와 원래 쉼 자리에서 바꿔 끼워요 [SPLICE_FIX].
- Typecast 비즈니스 계정 «일반» 모드로만 녹음해요. 목소리는 우성(진행)과 진희(안내)예요.
- 감정 직접 설정, 스마트 이모션, 끝음 조절은 쓰지 않아요.
- 문단 단위로 한 번에 생성해요. 테이크는 3개(첫 테이크 + 재생성 2)를 받아서 골라요.
- 녹음용 글은 화면 글과 같게 해요. 쉼표도 유지해요(쉼표를 빼면 «신랑 신부»가 더 떴어요).
- Typecast 속도는 목표 빠르기에 가장 가까운 0.1 단위로 골라요(우성은 0.9 근처, 진희는 1.0 근처). 조립할 때 보정하는 양이 5%를 넘지 않게 해요.
- 테이크 고르는 기준:
  - 받아쓰기가 글과 같아야 해요.
  - 말끝이 내려가야 해요. 끝 0.35초가 +1반음 이상 뜨면 버려요.
  - 부르는 말(«신랑 신부,»)의 억양 기울기가 뒤 말과 비슷해야 해요. 끝이 «뚝» 떨어지면 따로 놀아요.
  - 구호는 «신랑 신부,» 뒤에 원래 쉼이 있는 테이크를 골라요. Typecast가 «신랑신부맞절»을 붙여 읽는 테이크가 많아요.

## 3. 빠르기
- 기준: 지금 사이트 판 × 0.97(−3%)이에요 [SPEED3]. 절대값으로는 우성 약 6.87, 진희 약 6.71글자/초예요(측정 정의는 8번).
- 새 녹음은 같은 문단의 지금 판과 같은 글자/초로 맞춰요.
- 강약(승인되면 적용): 감정·엄숙한 문장 −2%, 일반 안내 +2%, 인사·정보가 든 안내·구호는 그대로예요. 문장 하나를 통째로 같은 비율로만 바꿔요.
- 처리 방법: ffmpeg atempo로 원래 녹음에서 한 번만 처리해요. 0.25초 이상 쉼은 길이를 그대로 둬요. 원래 대비 늘리거나 줄이는 양은 5% 안이어야 해요.

## 4. 쉼
- 문장 사이 쉼은 자리마다 따로 정해요 [SEAM_PICK]. 일괄 배율은 쓰지 않아요.
  - 곱씹을 문장 뒤(회상, 감사의 여운): 1.70~1.80초
  - 바로 이어지는 한 흐름: 1.00~1.15초
  - 인사 뒤 안내로 넘어갈 때: 약 1.20초
  - 같은 안내 흐름: 약 1.25초
  - 할 일을 알려 주기 직전: 약 1.45초
- 그대로 두는 것: 구호 앞 기다림, 특수 쉼(0.6 / 3 / 4초), keepGap(입장 구호 앞 1.83초), 반지 8초
- 구호 안(«신랑 신부, ∨ 맞절/인사/입장»): 0.38초예요. 받아쓰기 낱말 시각으로 자리를 찾고, 원래 틈이 없으면 넣지 않아요.
- 문장 안 쉼: 쉼표 0.15~0.45초, 상한 0.45초예요. 낱말 안에서 0.15초 넘게 끊기면 다시 받아요.
- 숨 쉼과 강조 쉼은 기존 녹음에 넣지 않아요. 새 녹음에서만 Typecast «쉼 추가»로 넣어요.

## 5. 하지 않는 것
말끝 늘임, 흐름 곡선, 문장마다 무작위 흔들림, 감정 직접 설정, 끝음 조절, 숨소리 넣기, rubberband, 이미 처리한 소리를 다시 처리하기, 문장 안 일부만 늘이거나 줄이기

## 6. 진행 순서 (옵션 하나 더할 때)
1. 승인된 판 위에 옵션 하나만 더해요. 정도는 대본 추천값이에요.
2. 시범 3~4클립으로 «지금 / +옵션» 페이지를 만들어요. 페이지에 무엇을 바꿨는지 적어요.
3. 점검표를 통과시켜요.
4. 사장님이 «남겨 / 빼»를 정해요.
5. 다음 옵션으로 넘어가요.
6. 다 끝나면 전체에 한 번에 넣고 «지금 / 바뀐 뒤» 전체 실청 → 승인 → 한 번 반영해요.

## 7. 올리기 전 점검표
1. 승인된 옵션 전부와 이미 고친 부분이 들어간 판인가
2. «지금 / 바뀐 것»이 바꾼 한 가지 말고 모두 같은가
3. 원래 녹음 대비 5% 넘게 늘이거나 줄인 곳이 없는가
4. 원래 녹음에서 한 번만 처리했는가 (부분 늘이기·rubberband 금지)
5. 다른 시기·설정의 테이크를 섞었다면, 그 사실과 차이(빠르기·억양·크기)를 재서 적었는가
6. 이음매와 무음 위치가 낱말 안이 아닌가 (받아쓰기로 확인), 이음매 크기 차가 1.5dB 이하인가
7. 알려진 문제를 다시 확인했는가: «신랑 신부» 따로 놂, 구호 끊김, «대신하여» 발음, «하객 안내에서» 발음, 끝 뜸, 끝 잘림
8. 빠르기, 쉼, 끝 반음, 최대 음량, 받아쓰기 숫자를 확인했는가
9. 페이지에 무엇을 바꿨고 무엇이 그대로인지 한 줄로 적었는가

## 8. 측정 방법 (모든 방이 같은 계산을 써요)
- 글자/초: 한글 글자 수 ÷ (말소리 시간 − 문장 안 무음 0.12초 이상). 무음 기준은 −30dB이고, 문장 앞뒤 무음은 빼요.
- 문장 나누기: 0.8초 이상 무음으로 나눠요. 문장 사이가 짧은 테이크는 받아쓰기 낱말 시각과 −25dB 무음으로 찾아요.
- 말끝: 끝 0.35초 평균 − 문장 평균(반음). parselmouth로 재요.
- 받아쓰기: faster-whisper small (ko). 낱말 시각으로 이음매와 무음 위치를 확인해요.
- 참고값: 실제 결혼식 사회자 릴스 37개를 같은 받아쓰기 방법으로 재면 중앙 5.39글자/초(대부분 5.07~5.83)예요. 같은 방법으로 우리 지금 판은 6.04~6.30이에요.
