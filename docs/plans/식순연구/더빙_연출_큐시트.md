# 나레이션 · BGM · 침묵 연출 큐 시트 · 2026-07-20

> 더빙한 나레이션 클립을 **BGM·침묵과 함께** 예식 각 순간에 재생하기 위한 연출 큐. 출처: 리서치 갈래 5(BGM·침묵) + 피크-엔드 원리.
> 원리 한 줄: **BGM은 나레이션이 나올 때 -10~-18dB 자동 더킹**(순간별 차등) · 정점(편지)·성혼선언 **직전에만 음악을 끊어 침묵**을 만들어 대비로 무게를 준다 · 폐식은 **롱 페이드아웃**(끝 인상 = 피크-엔드).

## 순간별 큐 표

| 순간 | BGM 무드 / 템포 | 나레이션 중 음량 | 침묵 배치 | 전환 |
|---|---|---|---|---|
| 식전 안내 | 잔잔·따뜻 · 60~75 BPM · 앰비언트 피아노/현 | 나레이션 0.5초 전 -12dB 더킹 | 없음(계속 흐름) | 입장 30초 전부터 볼륨 살짝 예열 |
| 입장 | 고조·상승 · 80~95 BPM · 스트링 크레셴도 | 음악 우선, 더킹 얕게 -6dB | 없음 | 감정 스웰 지점에 신부 발 맞춤(곡 처음 아님·걸음 실측) |
| 환영·첫인사 | 밝고 포근 · 70~85 BPM | -12dB | 없음 | 서약 진입 전 음량 서서히 하강 |
| 혼인 서약 | 매우 잔잔·저밀도 · 50~65 BPM · 솔로 악기 | -15dB(가장 깊게, 말 또렷) | 문장 사이 침묵은 음악 유지·말만 멈춤 | 마지막 문장 후 반지로 연결 |
| 반지·링워밍 | 따뜻·친밀·부드러운 상승 | -13dB | 없음 | 성혼선언 직전 **음악 페이드아웃 시작** |
| 성혼 선언 | 엄숙→상승 · 선언 순간 크레셴도 정점 | 선언 직전 **완전 정지(침묵 2~3초)** → 선언 → 끝나며 음악 하드 인 | 선언 앞 침묵이 최대 무게 | 침묵→선언→상승 = 1차 클라이맥스 |
| 와인·케이크 | 밝고 경쾌·중간 템포 | -12dB | 없음 | 편지 전 톤 낮추며 정돈 |
| **편지 낭독(정점)** | 극도로 미니멀 · 40~55 BPM · 단일 악기 또는 무음 시작 | 낭독 시 **완전 정지 또는 -18dB↓** · 절정 문단에서만 아주 조용히 재진입 | 도입부·핵심 문장 침묵이 감동을 키움 | 낭독 후 침묵 1.5~2.5초 유지 뒤 헌정 음악 페이드인 |
| 부모님 헌정·덕담 | 따뜻·눈물선·서정 · 55~70 BPM | -14dB | 인사 직후 짧은 정적 허용 | 축배로 갈수록 밝기 상승 |
| 축배 | 밝고 활기·경쾌 · 100~120 BPM | -10dB(얕게) | 없음 | 폐식 위해 여운 톤으로 하강 |
| **폐식·단체촬영** | 따뜻한 여운·희망적 · 75~90 BPM · 풀 편성 | 안내 나레이션 -10dB | 마지막 인사 후 음악만 남겨 여운 | **하드 스톱 금지 · 롱 페이드아웃**(끝 = 피크-엔드) |

## 실행 권장
- **더킹은 자동(사이드체인)** — 나레이션 트랙을 트리거로 음악에 -10~-18dB 게인 리덕션. 수동 볼륨 편집 불필요.
- **더킹 깊이 차등** — 음악이 주인공(입장·축배) 얕게 -6~-10dB / 말이 주인공(서약·편지) 깊게 -15~-18dB.
- **더킹 페이드** — 내려갈 때 0.3~0.5초, 복귀 0.8~1.5초(빠르면 '펌핑' 티).
- **성혼선언·편지 앞은 음악 끊고 침묵** — 침묵→소리 전환이 극적 효과의 핵심.
- **입장 곡은 처음부터 X, 감정 스웰에 큐** — 리허설 때 통로를 스톱워치로 재 걸음에 스웰 맞춤.
- **끝맺음 명시** — 곡마다 자연 페이드 / 하드 스톱 / 크로스페이드 중 무엇인지 못박기(애매하면 어색한 정적).
- **폐식 롱 페이드아웃** — 마지막 인상이 곡 여운.
- **큐 담당 1명** — AI 클립은 타임코드 고정이되, 실제 진행은 흔들리므로 디렉터가 다음 클립·음악을 수동 '준비→발사'. 클립 간 1.5~2.5초 침묵이 이 여유를 흡수.

## 저작권 방향 (★P1 결정)
- 상용 K-pop/시판곡을 **현장 재생·영상 삽입**하면 **KOMCA(한국음악저작권협회) 공연·복제권** 대상 → 청구·분쟁 소지.
- 안전책: **로열티프리·직접 라이선스 라이브러리만 사용.**
  - **Epidemic Sound** — 전 권리 포함 글로벌 라이선스 · Content ID 안전(SNS 배포 강점).
  - **Artlist / Musicbed** — 웨딩 필름 감성·시네마틱 카탈로그 · 단일 라이선스가 상업/개인 폭넓게 커버.
- AI 더빙 나레이션 + 라이브러리 BGM = 촬영·재생·SNS까지 저작권 클린. **정기 구독 1곳 선정**만 결정하면 됨.
