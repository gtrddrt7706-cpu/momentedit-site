## 1. 열어 달라신 셋 — A·C 는 열었고, B 는 **낱말만 바꿔** 받았습니다

**A. 시각 문형** — 열었습니다. `[G8_OUT_SPLIT]` 선례대로 «어형»에서 «지킬 말»로 넓혔습니다(`[EAR_WHAT_NOT_HOW]`).
재는 것은 「언제 시작하는지 하객이 아는가」 하나입니다. 다섯 문면으로 양방향 시험했습니다.

**C. 26·64 호칭** — 열었는데 **낱말만으로는 못 풀렸습니다.**
「두 사람 곁에 서 주세요」가 `N2`(한 문장 3인칭+2인칭 혼용)에 걸립니다. 규칙 둘 다 이 꼴을 안 다뤘습니다 —
`[VOICE_2ND]`의 「동작 문장은 두 분」은 «신랑신부에게» 시키는 문장을 말하는데, 여기는 «하객에게» 시키면서
신랑신부를 가리킵니다. **지적은 옳고 해법이 달랐습니다.** N2 주석이 답을 적어 두었더군요 —
「문장을 갈라 3인칭→2인칭으로 가는 것은 VOICE_2ND 의 설계다」. 38번에서 쓴 그 해법입니다.
```
26#2  모두 앞으로 나와 주세요. 두 사람 곁에 서시면 됩니다.     (한 문장 → 두 문장)
64#1  두 사람 곁으로 모이시면 됩니다.
```

**B. AI 고지 둘째 줄 — 「골랐습니다」는 안 받았습니다.**
`[GUEST_TONE]③` 이 **명시적으로 뺀 낱말**입니다: *「고른」은 남이 차린 것에서 집었다는 말이다.*
두 사람이 직접 만든 예식이라는 이 상품의 뿌리와 정면으로 어긋납니다. 「정했습니다」로 바꾸니
그 결정을 지키면서 **27음절 → 16음절** 낙차는 그대로 얻었습니다.
```
04a#2  순서도 이 안내도, 두 사람이 정했습니다.
04c#1  순서도 이 안내도, 저희가 정했어요.
```

## 2. ★열어 달라 안 하고 바꾼 자리가 하나 있었습니다 — `02a#1`
```
전  한쪽에 간단한 다과와 음료를 준비해 두었습니다.
후  한쪽에 다과와 음료를 두었으니 편히 드십시오.     ← 안 받았습니다
```
`nochk '편히 드시면'` 을 **「드십시오」로 우회**했고, 사장님이 고르신 「간단한」도 빠졌습니다.
그쪽은 「아무도 안 먹을까」를, 사장님은 「먹느라 부산스러울까」를 걱정하셨습니다 —
*「너무 많이 먹으면 안 되우려 … 돌아다녀도 된다는 문구로 인식되면 부산스러움」* · *「편히 드시면 이것도 빼자」*.
이 클립은 **십 분 전** 안내라 할 일이 착석 하나이고, 다과가 있다는 사실은 도착 안내(01a)가 이미 말합니다.
「~다」 3연속은 합쇼체 안내의 장르 정상입니다 — 에세이 자로 재지 않습니다.

→ **`scripts/audit/locked-proposal.py` 를 만들어 게이트에 걸었습니다.** 게이트의 chk·nochk 를 기계로 읽어
  제안 전체를 대조합니다. 사람이 91클립을 다시 읽지 않아도 됩니다. **다음 묶음을 보내기 전에 이걸 돌려 주십시오.**

## 3. 전수표는 걸었습니다 — 그리고 바로 값을 했습니다
