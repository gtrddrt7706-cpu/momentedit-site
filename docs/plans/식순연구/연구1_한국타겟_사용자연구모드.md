# 연구 1 · 한국 타겟 재실행 — 사용자 연구모드 결과 (2026-07-12)

> 출처: 사용자 클로드 연구모드(한국인 타겟 v2 지시문). 국내 근거 우선·해외 최소. 이 프로젝트의 주력 데이터.

## TL;DR
- 한국 예비부부에게 확실히 '통하는' 핵심 = **혼인서약(직접 낭독)·편지낭독·부모님 덕담·반지교환·성혼선언.** 이 계열이 성우 녹음만으로도 무리 없는 뼈대.
- 축가·베일다운·링워밍은 25명·성우·원형테이블·퇴장없음 제약에서 리스크 → 조정·교체.
- 주례 없는 결혼식 = 2020 전후 사실상 표준(단 공신력 통계는 없음, 듀오 2019 설문 80.3% 긍정이 최근접).
- 최적 = 실시간 사회자 애드리브·박수유도 불필요한 **고정 순서·감정 중심 이벤트.** 하객 참여·호명·즉흥형(럭키드로우·인터뷰중계·퍼스트댄스·애교시키기)은 배제.

## Key Findings (국내 근거)
1. **주례 없는 식 = 대세, 수치는 조심.** 듀오 설문(2019.12·462명) 80.3% 긍정, 장점 1위 '식순 간소화'(27.7%). 주례 대체로 남=양가 부모 편지(22.2%), 여=신랑신부 인사말(24.9%). ("서울 50~60%"는 나무위키라 신뢰 불가.)
2. **감동의 핵심 = 편지.** 가연 설문(2014·330명): '감동적인 편지·이벤트' 40%로 기억남는 결혼식 1위(사연 26%·부모 장면연출 25%). 오래됐지만 커뮤니티 호평 지금도 반복.
3. **축가는 가장 냉정하게 평가받음.** 네이트판·블라인드: "없는 게 낫다·소음·억지 박수·가수급 아니면 하지마라". 소규모·성우 진행에선 박수 공백 리스크 큼.
4. **하객 참여·즉흥형은 소규모+성우에 치명적.** 실시간 타이밍·분위기 관리가 녹음으로 대체 불가. 25명 전원 착석서 "분위기 싸해짐" 증폭(블라인드).
5. **폐백·한복 = 생략·축소 대세지만 어른 정서 대안 필요.** 신축 예식장 폐백실 없는 곳 많음. 어른에겐 '자식이 인사 올리는 절차'가 정서적 중요 → **부모님 인사·헌정(꽃/편지)로 흡수** 적합.
6. **한국 특유: 축의금 회수·양가 어른 체면.** 스몰웨딩 최대 걸림돌 = 부모 반대·체면. 25명 예식은 이 갈등 정리한 커플이 선택 → 식순은 어른이 "격식 있고 진심 있었다" 느끼는 톤 필수.

## D. 성우 나레이션 강점 이벤트
성우 강점 = 일정 톤·완벽 타이밍·격조. 약점 = 실시간 반응·박수유도 불가.
→ 강한 이벤트: 성장영상+성우, 성우 낭독 성혼선언·러브스토리, 신랑신부 직접 편지·서약(본인 목소리 교차·소규모라 안 묻힘), 링워밍/유니티(반지 도는 동안 성우 낭독으로 시간 채움·단 "다음 분께 전달" 안내 필수), 퇴장없는 클로징(케이크→건배→그 자리 단체촬영, 성우 "이제 이 자리에서 사진을" 유도).

## Recommendations (리포트 · 연구2 입력)
1. 뼈대: 개식→입장→혼인서약(직접)→반지교환→성혼선언(성우)→부모 덕담/헌정→성장영상→클로징(케이크·건배)→단체촬영. 어른정서·성우·25~30분 충족.
2. 차별화 **1개만** 추가: 편지(감동)/링워밍·유니티(참여)/타임캡슐(가족) 중. 이벤트 욕심내면 "지루" 실패(한국일보 2013).
3. 배제 확정: 축가·내빈축사·럭키드로우·인터뷰중계·사회자 장난.
4. 채택 3관문: ①오디오만으로 매끄러운가 ②양가 어른이 격식 느끼는가 ③25명·원형·퇴장없음 동선 유지되는가. 하나라도 No면 트렌디해도 탈락.

## Caveats
- '주례없는 비율' 정량 통계 없음(듀오 2019·가연 2014는 업체 자체 조사·참고용). 유모멘트-한국리서치(2025·503명·±4.36%p)는 하객수·준비 우선순위 중심, 식순 선호는 미조사.
- 감동 40%(2014)·주례 인식(2019)은 오래된 자료·방향성만.
- 커뮤니티 후기는 익명·자기선택 표본·대표성 없음.
- 해외 원형(베일·유니티 등)은 이해용 최소 참고·국내 수용도 개별 검증 필요.
