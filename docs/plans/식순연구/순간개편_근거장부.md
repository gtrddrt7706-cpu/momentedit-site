# 순간(이벤트) 개편 — 근거 장부

> ★이 파일은 손으로 고치지 않는다 — `docs/plans/식순연구/순간개편_자료표.json` 을 고치고 `node scripts/audit/source-basis.mjs --write` 로 다시 만든다([SOURCE_BASIS]).
> 순서: ① 실전 자료 평균(포함률 · 시간은 도구가 계산) → ② 우리 컨셉으로 거르기(자료는 정답지가 아니다) → ③ 결론.
> 기본 = 그 자료의 기본 식순에 있음(«덕담 또는 축사» 같은 택1은 0.5) · 선택 = 생략 가능 · 끼워 넣기로만 언급 · 시간 = 분이 적힌 자료의 중앙값.
