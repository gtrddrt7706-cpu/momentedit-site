## A. 25~30분 본식의 이상적 감정 아크 모델

**핵심 이론 2개**
1. **Peak-End Rule(카네만)**: 사람은 경험을 '가장 강렬한 순간(peak)'과 '마지막 순간(end)'의 평균으로 기억한다. 길이는 무시된다. → **정점 하나를 확실히 만들고, 끝을 따뜻하게 닫으면** 25분 예식도 강하게 기억된다. ("마지막 5분이 전체를 편집한다.")
2. **통과의례(반 게넵)**: 혼례는 세 통과의례 중 **'통합(두 사람·두 가족이 하나 됨)' 단계가 가장 강조**되는 의식. → 예식은 **통합의 정점(성혼선언·가족 하나 됨)으로 수렴**해야 정서적으로 완결된다.

**아크 형태 (권장)**
```
감정  ▁▂▄▆█▇▆  →  단체촬영
     입장  서약  편지  성혼   폐식
     첫인사 반지  (정점) (통합) 여운
```
- **오프닝(0~3분)**: 입장+첫인사 = 기대·따뜻함. 낮게 시작(바로 정점 금지).
- **상승(중반)**: 서약(직접)·반지 = 두 사람의 약속으로 고조.
- **정점(peak · 중후반)**: **편지 낭독** = 최고 감정(눈물·박수). 연구1 감동 1위·소규모 최강.
- **통합(end 직전)**: **성혼선언(하객 함께 낭독)** = 모두가 증인이 되는 통합의 순간.
- **여운·전환(end)**: 부모님 헌정 또는 밝은 마무리 → 성우가 단체촬영으로 자연 유도.

→ **정점은 종반부에, 그러나 맨 끝은 아님.** 눈물의 정점(편지) 뒤 통합(성혼)·따뜻한 여운으로 착지시켜 단체촬영으로 감정을 이어준다.

## B. 이벤트 배치 원칙 (무엇을 앞/중/뒤에, 왜)

| 위치 | 배치 | 이유 |
|---|---|---|
| 앞(오프닝) | 입장·첫인사 | 격조 있는 성우 톤으로 몰입·기대 형성. 감정은 낮게 출발 |
| 앞~중 | 베일다운(입장 직전 고정)·서약·반지 | 약속의 상승. 시각적·보편적이라 안정감 |
| 중후반(정점) | 편지 낭독 | 감정 최고점. 조용해진 25명이 집중 → 눈물 포인트 |
| 정점 직후 | 반지교환·케이크 등 가벼운 시각적 순서 | **눈물 뒤 숨 고르기(이완)**. 감정 소진 방지 |
| 종반(통합) | 성혼선언(하객 함께)·부모님 덕담/헌정 | 통과의례의 통합·어른 정서. 두 가족이 하나 되는 정서적 착지 |
| 끝(여운) | 부모님 헌정 또는 따뜻한 폐식 멘트 → 단체촬영 | peak-end의 'end'. 밝고 따뜻하게 닫아 촬영으로 연결 |

**추가 원칙**
- **정점은 하나로 집중** (편지 or 서약 중 하나를 확실한 peak로). 감동 이벤트 난발은 오히려 정점을 흐린다.
- **눈물 연속 금지**: 편지 직후 또 다른 감정 폭발을 두지 않는다. 사이에 이완.
- **어른 정서 순간(덕담·헌정)은 중후반 통합 구간**에 — 어른을 주인공으로 세우되 과한 연출은 자제.
- **부모님 인사는 소규모에선 한 번에 묶어** 진행(순서 이슈 최소화 · 아이웨딩·G4MARRY).

## C. 피해야 할 배치 안티패턴 (국내 후기 근거)

1. **이벤트 과다** → 산만·어른 소외·"안 하는 게 깔끔"(블라인드·pgr21·루리웹). 반대로 "구색만 갖춘 5분 예식도 하객 반응 최고"(Threads). → **차별화 이벤트는 1개 원칙**(연구1 계승).
2. **정점을 너무 초반에** → 뒤가 밋밋. peak가 초반이면 end까지 긴 하강.
3. **유쾌·장난으로 끝맺음** → 여운 없이 단체촬영 진입 시 정서 붕 뜸. 끝은 '따뜻함'이지 '웃김'이 아님.
4. **눈물 이벤트 연속** → 감정 소진·피로.
5. **어른 앞 과한 연출**(사회자 장난·호명형) → "분위기 싸해짐"(연구1 배제 확정).
6. **선물·호명으로 하객을 앞에 불러내기** → 어른 참여 불가·산만(루리웹 후기).

## D. 12종으로 짠 코스 3안 초안 (감정 곡선·배열)

> 고정 뼈대: 입장 → 환영/첫인사 → [본문] → 폐식·단체촬영. 아래는 [본문] 배열 초안(연구3·시간라운드서 확정).

**코스 1 · 감동 중심** (편지·서약이 정점)
```
입장 → 첫인사 → [서약(직접) → 반지 → 편지낭독(부모께·정점) → 성혼선언(하객 함께) → 부모님 헌정] → 폐식·단체촬영
```
아크: 낮게 시작 → 서약으로 상승 → 편지 정점 → 성혼 통합 → 헌정 여운. 눈물형.

**코스 2 · 담백 중심** (짧고 깊게)
```
입장 → 첫인사 → [서약(직접) → 반지 → 성혼선언(성우) → 성장영상] → 폐식·단체촬영
```
아크: 군더더기 없이 약속→통합→영상 여운. 차별화 이벤트 0~1개. "5분 예식 호평" 정서.

**코스 3 · 가족 중심** (양가 어른이 주인공)
```
입장(베일다운 직전) → 첫인사 → [부모님 덕담 → 서약(직접) → 반지 → 편지낭독(부모께·정점) → 성혼선언(가족 낭독) → 부모님 헌정 → 타임캡슐] → 폐식·단체촬영
```
아크: 가족 서사 중심. 어른 격식·정서 최대. 통합 강조.

※ 연출 옵션(와인/유니티·링워밍·케이크)은 각 코스의 이완 구간(정점 직후)에 1개까지 스왑 허용.

## E. 한국 어른 정서 만족 포인트
- **격식 = 성우의 안정된 낭독 톤 + 성혼선언의 권위** (어른이 "제대로 된 예식"으로 인식).
- **어른을 주인공으로**: 부모님 덕담·헌정을 통합 구간에 배치해 체면·정서 충족(폐백 대체).
- **과한 연출 배제**가 곧 격식: 장난·호명형 없음이 어른에겐 오히려 품격.
- **부모 인사 한 번에 묶기**로 순서 매끄럽게.
- **진정성 컨셉**: "진심이 담긴 담백함"이 어른·하객 모두의 공감대(아이웨딩·다이렉트결혼준비).
