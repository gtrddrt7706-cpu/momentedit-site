## 순서

1. 타입캐스트 → **대본 가져오기** → **텍스트 붙여넣기** 탭.
2. 파트 파일 하나를 통째로 복사해 붙여넣고 **다음**.
3. **화자 감지** — 위 표의 화자가 그대로 잡히면 정상입니다. 1~4번은 1인, 5번 배역은 여러 명입니다.
4. **보이스 배정** — 각 화자에 목소리를 고릅니다. 파트마다 다른 목소리를 배정하는 게 설계입니다.
5. 문장별로 감정·속도를 다듬습니다. **여기서는 다운로드하지 마세요** — 미리듣기·재생성은 무제한 무료고, 다운로드만 한도를 깎습니다(협의안 §3-①).
6. 전부 확정한 뒤 **다운로드 → 문장별 분리**로 받습니다. 줄 수만큼 파일이 떨어집니다.
7. **파트 번호로 시작하는 폴더에 각각 풀고** `node scripts/assemble-narration.mjs --in <상위폴더>`를 돌립니다.
   문장이 클립으로 붙고, 여백이 들어가고, 음량이 맞춰지고, 나레이션·배역이 갈라져 각 폴더로 떨어집니다.

```
~/Downloads/타입캐스트/
  1_안내/   ← 1_안내.txt 다운로드분 36개
  2_진행_전반/   ← 2_진행_전반.txt 다운로드분 50개
  3_진행_후반/   ← 3_진행_후반.txt 다운로드분 60개
  4_혼주편지/   ← 4_혼주편지.txt 다운로드분 38개
  5_배역/   ← 5_배역.txt 다운로드분 59개
```

**폴더 이름은 파트 번호(`1_`·`2_`…)로 시작하기만 하면 됩니다.** 조립기가 그 번호로 파트를 붙입니다 —
폴더를 안 나누고 한 곳에 다 풀면 파트끼리 섞여서 순서 검증에 걸립니다.
한 파트만 먼저 조립하려면 `--part 3`처럼 지정하세요(A/B 중인 파트만 뽑아 볼 때).

## 5번 배역은 성격이 다릅니다 — 미리듣기 전용 15클립

1~4번은 **당일 식장에서 실제로 울리는 소리**입니다. 5번은 아닙니다.
상담 때 고객이 "우리 예식이 어떤 소리로 흘러가는지" 미리 듣는 용도이고, **당일 콘솔은 이 클립을 재생하지 않습니다.**
그 자리에서는 신랑·신부·부모님이 직접 말합니다. 재생 중 화면에 배지가 뜹니다 — "예시 목소리 · 당일엔 두 분이 직접 말해요".

그래서 녹음 기준이 다릅니다.

- **연기하지 마세요.** 낭독톤으로 갑니다. 울먹임·떨림·감정 고조 금지. 감정 태그를 쓴다면 `[담담하게]`·`[차분하게]` 선에서 멈춥니다.
  서약·편지가 특히 그렇습니다. 예시가 울면 고객은 두 가지를 잃습니다 — 당일의 첫 감정과, "나도 저래야 하나"라는 부담 없음.
- **어른 말투에 사투리·유행어를 얹지 마세요.** 특정 지역·세대의 캐릭터가 되는 순간 밈이 됩니다.
- 화자가 5명(신랑 · 신부 · 아버님 · 어머님 · 하객대표)이라 3단계 「보이스 배정」에서 각각 고릅니다. 원천은 `배역_예시_대사.txt`입니다.

대사는 전부 **가상 인물**의 것입니다 — 신랑 이준호(31) · 신부 정세영(29) · 아버님 이만수(62) · 어머님 김영자(58).
★**고객이 실제로 쓴 서약문·편지는 어떤 경우에도 여기 넣지 않고 TTS도 하지 않습니다.**
①"당일까지 비밀" 정책과 충돌하고 ②실물 낭독의 감정 가치를 미리 소진하며 ③민감 텍스트를 외부로 보냅니다.

### 빠져 있는 2클립 — 하객 군중 (결정 대기)

원천 파일에는 있는데 붙여넣기 파일에서 뺐습니다. 여기 넣으면 안 되는 걸 넣게 되기 때문입니다.

- `R-declare-ask` (서약 응답) — "네, 그러겠습니다."
- `R-declare-chorus` (성혼 합송) — "저희가 오늘 두 사람의 증인이 되겠습니다."

AI 단일 보이스로는 군중 소리를 만들 수 없습니다. 한 사람이 "네, 그러겠습니다"를 말하면
스물다섯 명의 응답이 아니라 **한 명의 대답**으로 들리고, 그 순간 예식이 우스워집니다.
후보 셋 — ①팀·지인 4~5명 실녹음 ②그 구간만 텍스트 카드 ③생략. 추천은 ②입니다(기획서 §6 결정 7).
문안은 어느 쪽으로 결정되든 필요하므로 원천에 남겨 뒀습니다.

## 왜 한 문장이 한 줄인가

'문장별 분리'가 문장 기준인지 줄 기준인지 확인할 방법이 없습니다. **한 문장을 한 줄로 두면 둘 중 무엇이든 결과가 같습니다.**
쪼개져도 조립기가 `manifest.json`대로 다시 붙이므로 손해가 없고, 오히려 문장 사이 여백을 대본 규격대로 정확히 넣을 수 있어 **편집 단계가 통째로 자동화**됩니다.

## 보이스가 정해지면

역할명 대신 캐릭터 이름을 박아 **자동 배정**시킬 수 있습니다.

```bash
node scripts/build-typecast-import.mjs --voice 진행=대길,안내=김경화 앵커,편지=현주
```

배역도 같은 방식입니다 — 화자명이 역할이 아니라 사람이라는 것만 다릅니다.

```bash
node scripts/build-typecast-import.mjs --voice 신랑=한준,신부=현주,아버님=대길
```

타입캐스트가 화자명을 캐릭터로 인식하면 4단계(보이스 배정)가 통째로 사라집니다.
아직 A/B가 안 끝났으므로 **지금은 역할명·인물명이 기본값**입니다.
