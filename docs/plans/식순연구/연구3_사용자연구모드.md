# 연구 3 · 사용자 연구모드 결과 — 나레이션 작법·전환 설계 (2026-07-12) · 주력·제작 매뉴얼

> 학술+실무 출처. 모듈형 오디오 제작의 기술 규격. Claude 딥리서치(진행 중) 결과로 보강 예정.

## TL;DR
- 핵심 기술 = **자기완결형 도입 문장.** 시작 멘트에서 앞 순서 지칭어("이어서·다음은·방금·앞서·계속해서") 전부 제거 → 현재성 표현("지금·이제·오늘")으로 열기. 어떤 순서로 재조합해도 안 깨짐.
- 연결의 공백은 문장이 아니라 **음악 브릿지 + 1.5~2.5초 의도된 침묵**이 메움.
- **초 단위 설계 가능**: 한국어 차분한 내레이션 ≈ 분당 300음절(초당 5음절). 침묵·페이드 표준값 존재.
- 보이스오버는 완성도·신뢰·어른 정서에서 우위. 약점(사회적 현존감·실시간 반응)은 물리구조(25명 원형·지정좌석)+음악+2인칭 호출로 보완.

## B. 모듈형 오디오 블록 구조 (★제작 핵심)
```
[① BGM 페이드인 1~2초] → [② 앞 이벤트 마무리 멘트(자기완결 '닫기')]
  → [③ 브릿지: 음악 상승 + 침묵 1.5~2.5초] → [④ 다음 이벤트 시작 멘트(자기완결 '열기')]
```
**②닫기와 ④열기는 서로를 모른다.** 논리적 연결 없이 ③(음악+침묵)이 정서를 잇는다 = 레고 재조합 가능.

**자기완결 도입문 4조건**: ①앞 순서 지칭어 금지 ②시간 현재성으로 열기(지금·이제·오늘) ③그 이벤트 의미를 스스로 설명 ④닫힌 정서로 끝(다음 재촉 안 함).

**되는/안되는 문형**
| 상황 | ❌ 순서 의존 | ✅ 자기완결 |
|---|---|---|
| 입장 | "이어서 신랑 신부가 입장하겠습니다" | "지금, 두 사람이 함께 걸어 들어옵니다" |
| 서약 | "다음은 혼인서약 순서입니다" | "이제, 두 사람이 서로에게 약속을 건넵니다" |
| 영상 후 | "방금 보신 영상처럼…" | "오늘, 두 사람이 걸어온 시간이 여기 있습니다" |
| 부모 인사 | "다음 순서로 양가 부모님께…" | "오늘, 두 사람을 키워 온 분들이 이 자리에 계십니다" |
| 마무리 | "이것으로 마치고 다음은 사진촬영입니다" | "이제, 이 순간을 오래 간직할 시간입니다" |
근거: '이어서/다음은'=선행 발화 전제 접속·시간부사(없으면 성립 안 함). '이제/지금부터'=발화 시점 기준 직시(deictic)라 자기완결. '오늘'=예식 당일 전체 지시라 어떤 블록에도 참.

**공용 전환 문구(Universal Connector)**
- 열기: "지금, 이 순간." / "이제, 두 사람의 시간입니다." / "오늘 이 자리에서." / "잠시, 마음을 여기에 모아 주세요." / "함께 지켜봐 주시겠습니까."(하객 존대)
- 닫기: "그 마음이, 오래 머물기를." / "이 시간이, 오늘의 두 사람에게 오래 남기를." / "여기, 그 약속이 있습니다."
- 이름은 별도 슬롯(호명 문장만 고객별 추가 녹음). 공용 파일엔 지시표현만.

## A. 도메인별 전환 기법 (핵심만)
- **오디오가이드** = 모듈화 교본: 각 트랙이 앞 트랙 미지칭·독립 재생. 이벤트 블록 = 트랙.
- **기내방송** = 자기완결 모범: 매 방송 "손님 여러분"으로 새로 시작(대한항공 2024~ 녹음 전환).
- **연극 암전**: 음악은 끊지 말고 연속 → 단절감 방지. 조명 낮춰 이벤트 경계.
- **라디오 코너**: 이벤트별 고정 시그니처 음악 → 하객이 "다음 순서" 학습.
- **다큐**: 관통 키워드 하나(예: "오늘"·"약속")를 각 블록 도입에 변주.
- **시상식 개시 선언형** 유효하나 '호명·박수 유도'는 라이브 전용→제거, 음악 고조로 대체.

## C. 전환 타이밍 가이드 (초 단위 · 실무 관행)
| 요소 | 권장 | 비고 |
|---|---|---|
| 이벤트 종료 후 다음 멘트까지 침묵 | 1.5~2.5초 | "침묵도 원고"(KOCCA) |
| 무음 허용 상한 | 3초 이내 | 초과 시 사고로 인지·자동편집 삭제 대상 |
| 음악 페이드인 | 1~2초(짧게) | |
| 음악 페이드아웃 | 3~5초(감정 고조 시 최대 10초) | |
| 두 블록 사이 크로스페이드 | Equal Power 곡선 | 음량 함몰 방지 |
| 문장 사이 pause | 0.4~0.6초 | 호흡 |
| 의미 단락 pause | 1~1.5초 | 곱씹을 시간 |
| 강조·감동 문장 직전 pause | 1.5~2초 | 힘주기 |
| 브릿지 후 시작멘트 직전 침묵 | 2초 내외(음악 살짝 남김) | 단절감 방지 |
**블록 길이 = (음절합÷속도) + pause합 + 도입·종료 침묵 + 페이드.**

## D. 보이스오버 vs 라이브 MC + 보완책
- 우위: 완성도(무실수)·목소리 신뢰(안정 음성)·어른 정서(차분·격식).
- 약점: 사회적 현존감·실시간 반응 없음.
- 보완: ①25명 원형·지정좌석이 '친밀한 공동 현존'으로 현존감 대체 ②2인칭 호출("여러분"·"이 자리에 함께하신 분들") 고정 ③박수·호응 유도 문구 제거(반응 못 기다림)·음악 고조로 대체 ④운영자 수동 큐(오디오가이드식 번호 재생)로 지연 대응 ⑤마무리=퇴장 아닌 '그 자리 전환'("이제, 이 순간을 함께 남기겠습니다").

## E. 한국어 문체 가이드
**좋은 문장 6원칙(다큐 한지원/KOCCA)**: 단문 / 적게(침묵도 원고) / 운율(시에 가깝게·소리내어 씀) / 중계방송 금지(보이는 것 반복 설명 X) / 미사여구 과잉 금지 / 구체가 접착력(단 이름 없이 이미지·시간으로).

**좋은/나쁜 예문**
| ❌ | ✅ |
|---|---|
| "오늘 이 아름답고 뜻깊은 날, 세상에서 가장 행복한 두 사람이…" | "오늘, 두 사람이 함께 섰습니다." |
| "사랑의 맹세를 하는 감동적인 순간입니다" | "이제, 서로에게 약속을 건넵니다." |
| "검은 머리 파뿌리 되도록 백년해로…" | "오랜 시간이 지나도, 오늘의 마음 그대로." |
| "양가 부모님의 하해와 같은 은혜에…" | "두 사람을 키워 온 분들이, 여기 계십니다." |

**이중 경어**: 하객=하십시오체("~주시기 바랍니다"·"함께해 주시겠습니까"). 신랑신부 지칭 존대 조절(과한 '-시-'는 거리감). 부모>신랑신부 자연스럽게(압존법 강제 안 함).

**지칭어 온도·격식표**
| 표현 | 온도 | 격식 | 용도 |
|---|---|---|---|
| 신랑 신부 | 중립 | 높음 | 공식 선언·서약 |
| 두 사람 | 따뜻 | 중간 | **내레이션 본문 주력** |
| 두 분 | 정중 | 최고 | 어른 대상 존대("두 분을 축복해 주십시오") |
| 오늘의 주인공 | 들뜸 | 낮음 | 상투적·절제 |
| 오늘 하나가 된 두 사람 | 서정 | 중간 | 마무리·서약 후 |
→ 본문='두 사람', 공식선언='신랑 신부', 어른존대='두 분' 축.

**클리셰 블랙리스트(사용 금지)**: "검은 머리 파뿌리" / "세상에서 가장 행복한 두 사람" / "백년해로·하해와 같은 은혜" 등 한자 관용구 남발 / "큰절 올리겠습니다" 딱딱한 명령형 / 감정 강요("감동적인 순간입니다"·"박수로 축하해 주세요"←사전녹음은 박수 못 기다림) / "천생연분·운명처럼" 과장 / 성혼선언문 상투 낭독투(→직접 쓴 편지가 반응 좋음).

**낭독 속도 환산(순수 음절 기준)**
- 차분한 내레이션 **300음절/분(초당 5)** · 서정 275 · 안내방송 350.

| 10 | 2.0초 | 2.2초 | 1.7초 |

## Recommendations (제작 단계)
1. **규격 확정**: 페이드인 1.5초·도입 침묵 2초·문장 pause 1초·종료 침묵 2초·페이드아웃 4초. 낭독 속도 300음절/분 성우 지정.
2. **자기완결 감사**: 모든 시작멘트서 "이어서/다음은/방금/앞서/계속해서" 검색·삭제→"지금/이제/오늘". 이름 별도 슬롯.
3. **파일럿 3블록**(입장·서약·마무리) 순서 바꿔 재생→단절감 검증. 어색하면 문장 아닌 **브릿지 음악·침묵** 조정.
4. **단체촬영 연결**: 마무리=전환("이제, 이 순간을 함께 남기겠습니다").
- 임계: 무음 3초 초과→음악으로 덮기 / 재조합 어색→브릿지부터 의심 / 어른 "정신없다"→속도 300 이하로.

## Caveats
- 속도 300음절/분은 학술(말소리와음성과학 2020)+KOCCA 수렴값·±15% 편차·성우 녹음 검증 필수.
- 뉴스 SPM(남356.9·여353.1)=언어치료연구 30권3호(2021).
- 타이밍 관행=음악/방송 일반·웨딩 전용 아님·공간 잔향 보정.
- 해외 연구(social presence·voice trust)=원리 보조. 국내 경어·후기가 핵심.
- 클리셰=정성 판단·세대/지역 수용도 차이.
