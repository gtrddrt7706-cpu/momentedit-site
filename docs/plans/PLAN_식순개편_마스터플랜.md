# PLAN · 식순 개편 마스터플랜 · 결정 로그

> 2026-07-10 시작. 식순 시스템 대개편을 챕터별 → 스텝별로 쪼개, 운영자가 **선택만 하면 완성**되도록 전 결정 항목을 빠짐없이 나열한 문서.
> 답이 나올 때마다 이 문서의 각 스텝에 기록한다 (✅확정 / ⏸보류 / ⬜미진행). 이 문서가 유일한 진실원.

## 대원칙 (사용자 확정 · 2026-07-10)

1. **뼈대(고정 순서)는 운영자가 정한다.**
2. **얹기 이벤트 카탈로그도 운영자가 정한다.**
3. **나레이션은 운영자가 미리 녹음한 오디오 파일**로 준비한다 (자동 생성 아님).
4. **고객은 마이페이지에서 완성된 자기 식순의 나레이션을 직접 들어볼 수 있다.**
5. 기존 구조(뼈대 + 얹기 + 나레이션 3층, mypage.html 단독 · GAS는 저장만)는 유지한다.

## 진행 규칙

- 질문은 **한 번에 1개**, 객관식(추천안 첫 번째 표시). 아래 스텝 순서대로 진행해 누락 방지.
- 답 확정 즉시 이 문서에 기록. 애매하면 ⏸보류로 남기고 다음 스텝으로 (막히지 않기).
- **챕터가 끝나면 확정표를 보여주고 검수** 받은 뒤 다음 챕터로.
- 전 챕터 완료 후: 나레이션 대본 전문 작성 → 녹음 파일 목록 전달 → 구현 → 배포 → 라이브 확인.
