## 1. 상품 강점 (실제 홈 기준)

- **공개 단일가(보증인원 없음):** 시그니처 주말·공휴일 280만 · 평일 210만(VAT 포함). 평일 웨딩스냅 60만(운영초기 한정). "하루 최대 세 팀 한정."
- **추가금 없는 통합가:** 원본 전체 + 보정 10장 + 본식영상 데이터·수정본 + 모바일 청첩장 + 드레스 시착(당일 2벌) + 핑거푸드·음료 + 성우 나레이션까지 단일가에 포함. 옵션(추가 보정 2만/컷, 추가 시착 5만/벌, 다이닝 등)만 별도·투명 단가.
- **140분 시그니처 시퀀스:** 촬영과 예식을 하나로 엮는 5단계 타임라인, 두 공간(캔들존·화이트존) 운영.
- **결제 3단계 구조:** 계약금 10%(예약금 충당)·중도금 40%(예식 D-149)·잔금 50%(예식 D-9). 상담 예약금 10만(계약 시 전액 차감·미계약 시 환불).

## 2. 기술·개발 역량 강점 (★정보통신업 핵심 근거)

**이건 소개용 홈페이지가 아니라, 외부 솔루션 임대 없이 자체 개발한 웹 애플리케이션이다.**

- **프레임워크 0 · 순수 자체 구현:** React·Vue·jQuery·Bootstrap 등 일절 없음. 모든 캐러셀·아코디언·모달·달력·서명패드·좌석표를 순수 JS로 직접 구현. 외부 리소스는 Google Fonts와 지도 임베드뿐.
- **고객 포털이 사실상 SPA(단일 페이지 앱):** `mypage.html` 약 6,500줄(JS 약 5,300줄·함수 약 400개). 뷰 라우팅·토큰 인증·서버 왕복·클라이언트 상태관리를 갖춘 앱. 정적 페이지가 아님.
- **자체 구현한 고급 위젯(라이브러리 없이):**
  1. **손글씨 전자서명 패드** — `<canvas>` 포인터 드로잉, DPR 보정, 중요조항 확인 게이트, PNG 이미지 생성 후 서명본 아카이브
  2. **커스텀 달력 date-picker + 실시간 예식일 가용성 조회**(과거일·마감 슬롯 비활성)
  3. **좌석 배치 캔버스** — 삼각함수 좌표 계산으로 원형 테이블 자동 배치, 탭 편집, 자리별 음료 집계, 입석 초과요금 계산
  4. **QR코드 생성·저장**(청첩장·좌석·안내 공유 링크)
  5. **당겨서 새로고침·뒤로가기 오버레이 스택·토스트/모달** 등 앱 UX 자체 구현
  6. **식순 빌더**(order-preview) — 5개 코스 프리셋, 19+ 순간, 시간예산 자동계산, 순간별 나레이션 오디오 프리뷰
- **오프라인 우선(stale-while-revalidate):** 마지막 서버 스냅샷을 로컬 캐시해 재방문 시 즉시 렌더 후 백그라운드 갱신. localStorage 쿼터 초과 대비 처리까지.
- **컴포넌트 간 통신:** 계약서 뷰어·식순 빌더를 iframe으로 띄우고 `postMessage`(origin 검증)로 데이터 교환.
- **자체 백엔드 연동:** Google Apps Script `/exec`를 action 기반 REST형 API로 사용(마이페이지에서만 30종+ action 호출) + Vercel 서버리스 함수(AI·OG). 총 시스템 약 8.6만 줄(핵심 로직 약 1.6만 줄) 실측.

## 3. AI·자동화 강점

- **AI 상담 위젯(홈·상담·마이페이지):** 즉답 트리(키 없이 작동) + 자유질문 시 `/api/advisor`(Claude Sonnet)로 응답. 못 풀면 자동 에스컬레이션 → 카톡 연결 + 대화 전문을 `/api/handoff`(Claude Opus)가 {분류·요약·제안답변·확신도}로 관리자 브리핑. 카톡 클릭 전환수만 개인정보 없이 집계.
- **식순 AI 상담사·애프터웨딩 AI 컨시어지:** 현재 화면·구성을 실시간 그라운딩해 추천. 장소는 검증 DB+카카오 지도에서만(환각 방지).
- **무인 운영 라이브(`live.html`):** 예식 시각에 시트에 영상ID 입력되면 하객 화면이 새로고침 없이 자동 폴링·부착(최대 2시간), 동시접속 실패 시 자동 재시도.
- **운영 자동화:** 상담 예약→코드·메일·캘린더 자동 처리(더블부킹 방지), 결제 마일스톤 리마인드, 미서명 계약 자동 파기, 주간 백업·영수증 감사·월간 장소검증, 관리자 알림 메일 전용(문자비 0).

## 4. 하객 경험 강점 (여정 전체를 자체 시스템으로)

- **디지털 참석(`live.html`):** Vimeo 1080p **비공개(unlisted)** 재생을 자체 UI로 감싸 광고·목록노출·추적 제거. 원거리·어른 하객 대상.
- **모바일 청첩장:** 8종 고유 디자인 컨셉 × 2 호스트 변형(신랑신부·가족) = 16종 마스터를 Python 빌드 파이프라인으로 생성. 커플별 파일 생성 없이 시트 데이터로 렌더, 랜덤 토큰 열람 보호.
- **좌석 안내(`seat.html`):** 이름 검색→내 자리. **프라이버시 기본값 '내 자리만'**(서버가 본인 테이블만 응답·타인은 익명 점). 동명이인 오안내 방지.
- **하객 안내 허브(`guide.html`):** 좌석·식사·다이닝·사진모으기를 한 링크로. **하객 노출 시 가격정보 자동 필터링.**
- **어른 안내(`parents.html`):** 글자크기 4단계, **음성 낭독(TTS)**, A4 인쇄 최적화 등 시니어 접근성 특화.

## 5. 품질·완성도 신호

- **SEO·구조화:** JSON-LD 4종(Organization·LocalBusiness+OfferCatalog·FAQPage), OpenGraph·Twitter Card, sitemap·robots, 소셜 봇 전용 OG 메타 주입.
- **PWA:** manifest·apple-touch-icon·동적 theme-color.
- **접근성:** aria 속성 다수(홈 88개), role, 키보드 대응, `prefers-reduced-motion`, **한글 IME 조합 유실 방지**, 스크린리더용 숨김 제목.
- **성능:** 폰트 비차단 로드, preconnect, lazy-load, IntersectionObserver, rAF 스로틀, 캐시 우선 렌더.
- **보안:** 전 입력값 HTML 이스케이프(저장형 XSS 방지), 토큰 기반 접근, Referrer origin-only(토큰 유출 차단), 보안 헤더(HSTS 등), GA4 IP 익명화.
- **검증 체계:** GitHub Actions CI 4종 + 감사 스크립트 7종 + 단위 테스트. 1인 개발이지만 자동 검증 보유.

## 6. 신뢰·투명성 신호

- 사전 공개 가격·추가금 없는 통합가 → 정부 결혼서비스 가격 투명화 정책과 정렬.
- 전자계약(손서명·동의기록·자동 보관) + 환불·변경 견적 엔진(계약 조항을 코드로).
- 개인정보 처리방침, 주민번호 미수집, 미계약 고객 PII 자동 파기.

## 정정 주의 (과장 방지 · 실사 대비)

- **좌석·식순은 "드래그앤드롭"이 아니다** — 좌석은 탭 편집+자동좌표, 식순은 ↑↓ 버튼 재정렬. "탭·버튼으로 조정"이 정확.
- **라이브는 자체 스트리밍 서버가 아니다** — Vimeo 비공개 재생을 자체 UI·자동화로 감싼 것. 촬영·업로드는 운영자 SOP 의존.
- **QR 생성 라이브러리** 출처는 외부 스크립트(자체 구현 아님) — "QR 생성 기능 제공"까지만.
- 코드 작성은 AI 코딩 도구로 가속. 설계·통합·검수·운영은 대표가 직접.
