# 국가지원금 신청 준비 리스트 (로드맵)

> 대표 정희준 · 모먼트에디트 · 2026-07-21
> 1차: 중진공 청년전용창업자금(융자) · 소요 1억·최대 1억 신청
> 표기: 🔴급함 · 🟡중요 · 🟢때 되면 / (나) 대표 직접 · (자동) 내가 처리 가능

---

## A. 지금 즉시 (문서·발송)

- [ ] 🔴 **사업소개서 "보완본" 재송부** — 팀장이 받은 건 구버전. 최신본(경력·사업성·1억)으로 교체. (나: 문구·파일 준비 완료)
- [x] (자동) 사업소개서·자산팩트시트·시장문제해결·메일본문 최신화 완료
- [x] (자동) 저장소 비공개·코드 식별자 제거
- [ ] 🟡 (나) 메일 서명란 연락처 실제 값 기재

## B. 재무 준비 (승인·한도의 핵심)

- [ ] 🔴 (나) **소비성 부채 상환** — 퇴직금으로 중고차(1,770만)+신용대출(3,010만) ≈ 4,780만 상환 → 전세대출만 남김. **신청·심사 전에 완료**해야 한도에 반영.
- [ ] 🟡 (나) **마통 5천 잔액 0 유지** — 심사 시점에 당겨쓰지 않기(부채↑ 방지). 사업 주자금은 융자로.
- [ ] 🟡 (나) 재무 증빙 준비: 재직증명서·근로소득 원천징수영수증(소득), 신용조회 확인서, (상환 후) 대출 잔액 확인서
- [x] (자동) 개인재무요약(대외비·계좌번호 없음) 작성 완료 — 컨설턴트 요청 시 전달

## C. 미팅 준비 (7월 중 1차)

- [ ] 🔴 (나) **일정 조율** — 팀장에게 가능일 회신
- [ ] 🟡 (나) 미팅 3대 확인 질문 (아래) 메모 지참
  1. 제 조건 현실적 승인 한도 (1억 다 나올지)
  2. 전세대출 1.92억이 한도에 미치는 영향 / 소비성 부채 상환 시 상향 폭
  3. 신청 타이밍(재직 중 vs 퇴사 후) · 시설/운전 배분·거치기간
- [ ] 🟡 (나) **시각 증빙 지참** — 스튜디오·인테리어 시공 결과물 사진, 사이트 라이브 시연(모바일)
- [ ] 🟢 (나) "융자 신청 시 필요 서류 체크리스트 달라" 요청

## D. 사업 실체 준비 (개업 전후)

- [ ] 🟡 (나) **사업장(임대) 확정** — 보증금·위치. 소요자금표의 임대 보증금(예시 3천)을 실제값으로.
- [ ] 🟡 (나) **통신판매업 신고** — 오픈 즈음(자료 이미 준비됨: `momentedit-docs/legal/통신판매업_신고준비.md`)
- [ ] 🟢 (나) 홈택스 종목 정정(웨딩스냅 749400 등), 사업용 카드·계좌 분리
- [ ] 🟢 개업(2026.10.26) → 첫 실계약·본식으로 사업 실체·초기 실적 확보

## E. 사업계획서 완성 (컨설턴트와)

- [ ] 🟡 (나) **정량 수치 확정** — 소요자금 세부(임대·인테리어·장비), 목표 월 예식 수. 확정 주면 (자동) "예시"를 "확정"으로 반영
- [ ] 🟡 매출·상환 시뮬레이션 컨설턴트 검토·보정
- [ ] 🟡 (나) **SW 프로그램저작권 등록** — CROS 온라인 5만 원·7일. 핵심 모듈 즉시 등록(지식재산 증빙)
- [ ] 🟡 (나) **특허·실용신안 1건 출원 검토** — 예약/좌석/나레이션 등(가점 가중치 최상, 출원 중 기재 가능)
- [ ] ★🗳 (결정) **여성기업 확인서 전략** — 배우자(미쿠) 최대출자자 구조 시 27년 초창패·청창사 여성창업 우대. 지금 융자는 정희준 명의 유지, 27년 겨냥 구조 정비를 컨설턴트와 상의
- [ ] 🟢 (나) 지원 전 웨딩/관광테크 **창업경진대회 1회 도전**(가점 계열)

## F. 신청 단계 증빙서류 (미팅 후 체크리스트대로)

- [ ] 사업자등록증(2026.4.1 완료 · `momentedit-docs/legal/business-registration.pdf`)
- [ ] 신분증·주민등록등본, 소득·재직 증빙, 신용·부채 현황
- [ ] 사업계획서(완성본), 자금 소요·조달 계획서
- [ ] (해당 시) 임대차계약서·통신판매업 신고증

## G. 향후 연계 (2027)

- [ ] 🟢 개업 후 B2C 운영·매출 실적 축적 → **초기창업패키지**(개업 후) 준비
- [ ] 🟢 **청년창업사관학교**(준입교형 등) — 26년 11월 말 접수 시작에 맞춰 준비
- [ ] 🟢 성장 트랙 구체화: **프랜차이즈·다점포 확장**(자체 시스템=가맹 운영 백본) + **B2B SaaS**(멀티테넌트·구독 과금)
- [ ] 🟢 **일본 고객 유치**(배우자 일본 인스타 마케팅·일본어 응대) 채널 가동

## 우선순위 3줄 요약

1. **🔴 보완본 재송부 + 미팅 일정 잡기** (지금)
2. **🔴 소비성 부채 상환 + 마통 잠그기** (신청 전 · 한도 좌우)
3. **🟡 소요자금·목표 매출 확정 → 사업계획서 마무리** (미팅 전후)
