## 가점 둘을 «지어내지 않고» 충족한 방법

1. **AI 가점** — 없던 기능을 쓴 게 아니라 **이미 있는 것을 지표 언어로 한 번 부른 것**이다.
   `api/after-concierge.js` 주석 실측: 「① 대화 층: **장소 이름을 직접 말하지 않는다**
   ③ 카드 층: 장소 사실은 전부 카카오 API 원문 그대로 — **AI가 지어낼 수 없음**」
2. **지역 가점** — 「고양에서 사업합니다」로 끝내지 않고 **돈의 흐름**으로 적었다.
   다이닝 식사비를 우리가 청구하지 않고 고객이 인근 파트너에게 직접 낸다(라이브 사이트 실측 ·
   `collectDinePool` 은 스튜디오 **반경 7km** 를 훑는다). 즉 예식 한 건이 지역 상권으로 간다.
   ★**이건 신청서용으로 만든 말이 아니라 원래 그렇게 굴러가는 구조다.**
