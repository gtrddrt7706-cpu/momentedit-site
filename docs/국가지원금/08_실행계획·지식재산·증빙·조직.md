## 2. 지식재산(IP) 전략

- **① SW 프로그램저작권 등록(즉시·저비용):** 자체 개발 시스템을 컴퓨터프로그램 저작물로 **한국저작권위원회 CROS(온라인)** 등록. **수수료 온라인 5만 원·등록면허세 3,600원·처리 약 7일**(확인). → 8.6만 줄을 즉시 "객관적 지식재산"으로 전환 + 창작시점·권리자 공적 확정.
  - 등록 단위(안): ① 고객여정 관리 플랫폼 ② AI 상담·컨시어지 ③ 청첩장·하객 안내 ④ 전자계약·정산 엔진
- **② 특허·실용신안 1건 출원 검토(가점 가중치 최상):** 예약 매칭·좌석 배치·나레이션 자동화 등 고유 프로세스에 신규성이 있으면 변리사 자문 후 출원. **출원 중(등록 전)이어도 신청서에 기재 가능**(청창사·초기창업패키지 지식재산 가점). 저작권보다 배점 강함.
- **③ 상표 출원:** 'Moment Edit / 모먼트에디트' 상표(브랜드 보호·프랜차이즈 대비).
- **가점 활용(확인):** 지식재산(특허·실용신안·프로그램저작권)은 초기창업패키지 **서류 가점(최대 3점)**·청년창업사관학교 **가점(최대 3점, 계열 캡 0.5점)**의 인정 계열. *(단 각 공고에 'SW저작권' 명시 여부·정확 배점은 그해 공고 원문 확인 — 미확인 항목. 미인정 시에도 기술성·진입장벽 정성 근거로 활용.)*
