## 2. 경력 요약 (심사 3요소 대응)

**① 경력·아이템 정합성 — 저는 공간·스튜디오 사업을 직접 키워 온 실전형 창업자입니다.**

**② 비즈니스모델·사업성·차별성**

- 현재 B2C 마이크로웨딩 스튜디오(추가금 없는 공개 단일가). 정부의 결혼서비스 가격 투명화 정책 방향과도 일치합니다.
- **인테리어를 직접 시공하고 운영 시스템을 직접 개발**하므로 초기 창업비·고정비가 낮습니다 → 자금 효율이 높고 융자 상환 부담이 작습니다.
- 자사 운영용으로 만든 시스템을 향후 웨딩 벤더 대상 B2B SaaS(정보통신업)로 확장할 계획입니다.

**③ 대표자 의지**

- 반복해서 사업을 직접 만들고 키워 왔고, 이번에는 개업 전 단계에서 이미 운영 전 과정을 담은 시스템(약 8만 6천 줄, 별도 직원·외주 없이 부부 2인 운영·시스템은 대표 직접 개발)까지 구축했습니다. 안정적 직장을 퇴사하고 창업에 전념합니다.
