# 자산 근거표 — 신청서에서 무엇을 증명하는가

> 작성 2026-09-07 · 회의 01 산출물 · 실측 기준일 2026-09-07
> **자산 목록이 아니라 «증거표»다.** 왼쪽이 심사 항목, 오른쪽이 그것을 뒷받침하는 실측치다.
> 신청서에 그대로 옮기지 말고 여기서 골라 쓴다. 숫자는 전부 저장소 실측이며 명령을 함께 적어 재현 가능하게 했다.

---

## 0. 이 표가 필요한 이유

우리 최대 약점은 **실적 0**이다. 고객도 매출도 없다.
멘토기관 평가지표 세 축 중 우리가 숫자로 답할 수 있는 것은 **③ 아이디어 구체성**,
그중에서도 **«초기 실행 가능성 — 단기간 내 구현 또는 검증 가능성»** 하나다.

> 평가지표 원문(반복 표현): *"단기간 내 구현 또는 검증 가능성이 있는지"*,
> *"현재 보유한 자원으로 아이디어를 빠르게 실행하고 고객 반응을 검증 가능한지"*,
> *"사업기간 내 시제품(MVP)을 제작하여 실제 고객 반응을 확인할 수 있는 구체적인 실행 계획 여부"*

**"만들 수 있습니다"가 아니라 "이미 만들었습니다"로 답한다.** 그것이 이 표의 용도다.

## 3. 정직하게 적을 약점 (먼저 쓰는 편이 낫다)

심사자가 물을 것을 우리가 먼저 꺼낸다. 숨겼다가 지적당하는 것보다 낫다.

| 약점 | 사실 | 어떻게 쓸 것인가 |
|---|---|---|
| **실적 0** | 고객 0 · 매출 0 · 개업일 2026-10-26 | 감추지 않는다. "그래서 이번 사업으로 첫 고객 검증을 하겠다"로 연결 |
| **단일 사업장 전제** | `momentedit.kr` 451회 · 사업자번호 38회 · 단일 식장 정보를 32개 HTML 이 참조 | **이것이 곧 할 일이다.** "기능 개발이 아니라 상수 분리와 다중 테넌트화가 남았다"고 명시 |
| 결제 미가동 | 토스 플래그 OFF · 라이브 키 미등록 | 코드는 완성. 사업자 요건 갖춰지면 켠다 |
| 일부 배선만 | 지도 iframe 값 비어 있음 · GA4 측정 ID 없음 | 굳이 쓰지 않는다. 물으면 답한다 |
| 시장 검증 없음 | 다른 스튜디오에 팔아본 적 없다 | 이번 사업기간의 목표로 세운다 |

## 4. 숫자 재현 명령 (심사·검증에서 물으면)

```bash
git log --oneline | wc -l                    # 커밋 3,624
git log --reverse --format=%ad --date=short | head -1   # 2026-05-14
find . -name '*.gs' | xargs wc -l | tail -1  # GAS 16,707줄
ls scripts/audit/* automation/tests/* | wc -l # 감사·테스트 파일
find assets -name '*.mp3' | wc -l            # 298
```

**주의 — 저장소를 통째로 제출하지 않는다.** 1차에서 1R 합격자 5,000명의
아이디어 200자 요약과 심사평이 유출된 이력이 있다(사업 참여 AI 업체의 비정상 API 호출).
**«무엇을 푸는가»는 구체적으로, «어떻게 구현했는가»는 결과 수치만** 낸다.

## 5. 아직 안 정해진 것

- **의제 1(아이템 방향)** 이 정해져야 이 표에서 무엇을 쓸지 갈린다.
  A안(웨딩 벤더용 SaaS)이면 이 표가 그대로 근거가 되고, C안(축을 넓힌 제3안)이면 절반이 버려진다.
- **시장 규모 숫자**는 별도 리서치 중 (`모두의창업_시장경쟁_리서치.md` 로 이어붙일 예정).
- 도전신청서 **항목별 글자수 제한** 미확인 → 분량 배분을 아직 못 정한다.
