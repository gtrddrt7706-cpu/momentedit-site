## ★대표가 정해 주셔야 답이 나오는 것 둘

### ① 보정업체 — 쓰는 겁니까, 안 쓰는 겁니까

- ⑪번에서 대표: *「고객이 셀렉 후 보정 들어가는 건 **우리가 해야지**」*
  → 그래서 계약서를 안 고쳤고(계약서가 「사진 보정은 '을'이 **직접 수행**」이라 못 박고 있다),
    변동비도 45만 원 그대로 두었다.
- 오늘 대표: *「**보정업체 비용** 전기 인터넷 보안 등등 고정비 더 두어야 할 거 같아」*

**둘이 다릅니다.** 갈래가 셋입니다.

| | 무엇 | 그러면 |
|---|---|---|
| **가** | 셀렉 10장은 우리가, **원본 전체 1차 보정만** 업체에 | 계약서 그대로 OK · 고정비(또는 변동비)에 그 비용 추가 |
| **나** | 보정을 **전부** 업체에 | ★**계약서 제4조·제3조를 고쳐야 한다**(직접 수행 조항) + 개인정보 처리위탁 조항 신설 |
| **다** | 업체를 **안 쓴다** | 지금 그대로. 고정비에 안 넣는다 |

### ② 부가세 10% — ★이건 고정비에 넣으면 **이중 계산**입니다

신청서 Q3-2 는 이미 이렇게 적고 있습니다.

> 공헌이익은 **부가가치세를 제외한 공급가 기준**입니다.

즉 주말 330만 원에서 **부가세를 이미 빼고** 300만 원으로 계산했습니다.
고정비에 부가세를 또 넣으면 **같은 세금을 두 번 빼는 것**이 됩니다.

★다만 대표가 말한 「세금」이 **부가세가 아니라 다른 것**이면 이야기가 다릅니다.
종합소득세·지방소득세·4대보험 사업자 부담분 같은 것은 **아직 안 들어가 있습니다.**
어느 쪽인지 알려 주시면 그대로 넣겠습니다.
