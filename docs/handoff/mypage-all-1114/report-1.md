## 쓰지 않은 것 · 장치 한계
- 오른쪽 아이콘 레일 · 말풍선 · 드레스 스티커는 확정 설계라 언급하지 않았어요.
- «행 강조» · «행 아래 기한 줄»은 사장님이 걷은 것이라 되살리지 않았어요(시안 1은 NOW 한 줄로 피했어요).
- 점검 장치가 신고 없이 상태를 넣어서 생긴 장면(25 «중도금 다시 입금» 등)은 결함으로 세지 않았어요.
- 점검자 E 의 «예식 확인서 알림 없음»은 틀린 말이었어요(메일 · 처리 이력은 있음) → 25번처럼 «관리 카드 줄 없음»으로 고쳐 적었어요.
- ChatGPT 1라운드는 보냈지만(«마이페이지 화면 검토» 대화), 브라우저 탭이 응답하지 않아 결과를 아직 못 읽었어요. 읽는 대로 반영 표를 덧붙일게요.
- 릴스 분석 방의 Hallmark 결과는 아직 받지 못했어요. 받으면 하나씩 keep / drop 할게요.
