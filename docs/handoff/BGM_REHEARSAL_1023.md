# 당일 콘솔 음악 리허설 점검표 [BGM_CONSOLE2_1023]

BGM 섹션 라운드 2(사장님 결정 «8구간») PR 3. 리허설 날 스튜디오에서 이 표를 위에서부터 한 번씩 해 본다.
모든 칸의 기준은 하나다 — **사람이 아직 말하거나 움직이는데 원치 않는 다음 나레이션이 나가거나 음악이 커지지 않는가.**

## 0. 시작 전

- [ ] 콘솔 설정 «리허설»에서 **그날의 장소 · 출력 이름**(예: «스튜디오 PA» · «유선 스피커»)을 고르거나 새로 저장한다. 위쪽 줄에 «리허설 ‹이름›»이 보인다.
- [ ] «구간 음악»에서 구간마다 곡 파일이 ✓ 인지 본다. «곡 파일 필요»인 구간은 앞 곡이 이어진다(정적은 없다).
- [ ] «소리 파일 확인»에서 입장 음악이 «받아 둠»인지 본다. «곡 길이 모자람 · 맞절은 피아노로»가 보이면 감사 인사 ~ 덕담(M4) 곡 파일이 꼭 있어야 한다.
- [ ] 노트북 전원 연결 · 절전 끄기 · 화면 꺼짐 끄기(콘솔은 화면이 꺼지지 않게 붙잡지만, 운영체제 절전은 막지 못한다).

## 1. 상황별

| 상황 | 콘솔이 하는 일(지금 코드) | 리허설에서 볼 줄 | 막히면 |
|---|---|---|---|
| **낭독이 1분 넘게 이어짐**(편지 · 축사 · 덕담) | 사람 구간은 디렉터 GO 전까지 끝나지 않는다(현장 모드는 자동으로 넘기지 않는다) · 음악은 그 크기 그대로(축사 · 편지 «음악 없이» −90 · «음악과 함께» −20 [HOLD_LIVE]) · 덕담은 정해 둔 시간을 넘기면 마무리 글이 바뀐다(ALT_CLIP) · 덕담 2분 30초에 음악을 조금 올린다(BLESS_PER_SPEAKER · 정해 둔 동작) | □ 2분을 그냥 두어도 다음 나레이션이 나가지 않는다 □ 그동안 음악이 커지지 않는다(덕담 2분 30초 한 번만 예외) | 화면 진행 막대는 예상 시간을 넘겨도 멈춰 있을 뿐이다 — 끝나면 GO |
| **GO 를 두 번 누름** | 1.5초 안의 두 번째 GO 는 무시하고 «방금 눌렀어요»를 띄운다(GO_GUARD_MS) · 축배 «위하여»에서는 첫 GO = 축배 음악 올리기 · 두 번째 GO = 마무리 [TOAST_GO] | □ 빠르게 두 번 눌러도 한 순서만 넘어간다 □ 축배에서 빠르게 두 번 눌러도 마무리가 바로 나가지 않는다 | 잘못 넘어갔으면 «뒤로»(PageUp · ←) — 한 칸 되돌리고 멈춘다 |
| **입장 곡이 일찍 끝남** | 하이라이트 뒤 180초가 안 되는 곡은 설정 화면에 «곡 길이 모자람 · 맞절은 피아노로» · 받는 말 · 맞절에서 피아노(M4)를 미리 깔고 **곡 끝 3초 전부터** 겹쳐 이어받는다 [ENTRY_SHORT] · M4 곡 파일이 없으면 앞 구간 곡(화촉)이 이어받는다 | □ 걷는 도중 곡이 끝나도 음악이 비지 않는다 □ 이어받는 음악이 맞절 크기(−12)보다 커지지 않는다 | 곡을 더 긴 판으로 바꾸거나 M4 곡 파일을 넣는다 |
| **네트워크 끊김** | 구간 곡 · 직접 넣은 곡은 이 기기(IndexedDB)에 있어 끊겨도 나온다 · 두 분 목소리 · 입장 곡은 시작 전에 받아 둔다(rfPrefetch · 관리자 로그인 기기) · 나레이션 클립은 사이트에서 받는다 — 못 받으면 그 순서를 **문안 카드**(글 + 예상 시간)로 넘긴다 | □ 와이파이를 끈 채 한 순서를 GO 해 본다 — 음악은 이어지고 나레이션 자리는 문안 카드가 뜬다 | 당일엔 «클립 폴더 선택»으로 나레이션 클립을 이 기기에서 물려 두면 끊겨도 소리가 난다 |
| **play() 실패**(브라우저가 소리를 막음) | 소리는 첫 GO(누름)에서 열린다 · 나레이션이 막히면 «재생 막힘»으로 문안 카드 · 구간 곡이 막히면 앞 곡이 그대로(바꾸기만 안 된다) | □ 새로 연 탭에서 시작 → 첫 GO 에 음악 · 나레이션이 다 들린다 | 시작 단추를 누른 뒤 아무 곳이나 한 번 눌러 소리를 연다 |
| **절전 · 화면 꺼짐** | 화면 깨우기 잠금(wakeLock)을 건다 · 다시 보이면 다시 건다 · 탭이 뒤로 가면 브라우저가 타이머를 늦출 수 있다(이어지는 큐가 늦게 나간다) | □ 10분 동안 화면이 꺼지지 않는다 □ 다른 창으로 갔다 와도 순서가 저절로 앞서 나가지 않는다 | 콘솔 탭을 늘 앞에 둔다 · 노트북 덮개를 닫지 않는다 |
| **유선 출력으로 바꿈**(블루투스 → 선) | 소리는 운영체제 기본 출력을 따른다 · 크기는 리허설 프로필(장소 · 출력 이름) 값 | □ 출력을 바꾼 뒤 «리허설»에서 그 출력 이름 프로필을 고른다 □ 말 아래(−16) · 낭독 아래(−20)에서 목소리가 묻히지 않는다 | 출력마다 프로필을 따로 저장한다(예: «PA» · «유선») |

## 2. 귀로 맞출 다섯 값(«리허설» 칸)

| 값 | 시작값 | 무엇을 들을까 |
|---|---|---|
| 말 아래(duckSpeech) | −16 dB | 나레이션 · 서약 낭독 아래 음악이 말을 덮지 않는가 |
| 음악이 주인공(duckMusic) | −8 dB | 화촉 · 입장 앞 · 박수 동안 음악이 충분히 들리는가 |
| 낭독 아래(duckRead) | −20 dB | 축사 · 편지 «음악과 함께»에서 음악이 거의 안 들리게 깔리는가 |
| 축배 크기(toastLevel) | 0 dB | «위하여!» 뒤 GO 에 신나게 오르되 과하지 않은가 |
| 축배 오름(toastUpMs) | 0.6초 | 오르는 순간이 갑작스럽지 않은가 |

«음악 없이»는 값이 아니라 늘 음소거다(축사 · 편지 · 식전 영상 · 축가).

## 3. 시계(AudioContext) 메모

- 입장 장면의 곡 시작 · 하이라이트(H) · 크기 곡선은 이미 **AudioContext 시계로 예약**한다(`src.start` · `setValueCurveAtTime` · entry-scene).
- 화면 타이머(setTimeout)를 쓰는 자리: 대사 끝 → 다음 큐, 짧은 입장 곡 이어받기(곡 끝 3초 전). 검사(bgm-seg8 ⑥)에서 이어받기는 계산한 자리와 0.1초 안으로 맞았다(곡 끝 37.4초 · 이어받기 34.4초).
- 탭이 뒤로 가면 화면 타이머는 늦어질 수 있다 — 위 «절전 · 화면 꺼짐» 줄.
