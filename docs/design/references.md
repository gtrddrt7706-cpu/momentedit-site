# 웹 디자인 레퍼런스 [DESIGN_REFS_1107]

> 2026-11-07 사장님이 보내 주신 레퍼런스 셋 · 대본 방 전달. 요지는 «더 예쁘게»를 되풀이하지 말고 레퍼런스와 기법 이름으로 지시한다.
> 쓰는 곳: **우리 웹 화면** — 홈 · 식순 빌더 · 마이페이지 · 청첩장. 식전 영상은 협력사가 만들어서 해당 없음.

## 쓰는 법

1. **마음에 드는 것을 보여 주고 «어디가 좋은지» 콕 집어 말한다** — «글자가 흐림에서 걷히는 속도» · «멈춤이 짧다» · «사진이 천천히 밝아진다»처럼 한 자리 · 한 성질.
2. **기법 이름으로 지시한다** — 아이캔디의 기법 이름, React Bits 의 컴포넌트 이름(예: `BlurText` · `FadeContent` · `GradualBlur` · `ScrollReveal`)을 그대로 쓴다. «더 예쁘게»로 반복하지 않는다.
3. 지시 한 번 = 레퍼런스 하나 + 이름 + 바꿀 점 하나 + 넣을 자리 하나.

## 먼저 지킬 것 (레퍼런스보다 앞선다)

- CLAUDE.md [DESIGN_RULES_1011] 금지 6 · `momentedit-design` 「절대 하지 말 것」 — bounce · spring · elastic · 회전 · 3D 틸트 · 패럴랙스 과다 · 글로우 · 네온 · 자동 재생 캐러셀 · 장식 이모지는 레퍼런스에 있어도 쓰지 않는다.
- 움직임 값은 우리 자를 쓴다 — 시간은 모션 램프 [MOTION_RAMP5](0.12 · 0.3 · 0.45 · 0.7 · 1.2초) · 이징은 `var(--ease)` · 한 섹션 3개 이하 · 순차 지연 80ms 이하 · 스크롤 하이재킹 · 스크럽 금지.
- `prefers-reduced-motion: reduce` 면 움직임 없이 마지막 모습으로 바로.
- 폰 성능 — `transform` · `opacity` 만 움직인다 · 셰이더 · WebGL · 파티클 배경은 쓰지 않는다.

## 라이브러리는 끌어오지 않는다 · 기법만 본다

- 우리 페이지는 정적 HTML(빌드 없음 · React 없음)이다. React Bits 컴포넌트를 설치하거나 코드를 복사하지 않는다.
- React Bits 라이선스는 MIT + Commons Clause(컴포넌트 자체를 팔거나 재배포하지 않는 조건) — 그래서 더욱 **기법만 보고 CSS · 작은 JS 로 직접** 짠다.
- 걸러질 갈래(참고): 배경 대부분(셰이더 · 파티클 · 네온) · 커서 효과 · 글리치 · 스크램블 류 글자 · 튕기는 마이크로 동작.

## 넣는 때

- 새 움직임을 실제로 넣는 것은 **다음 화면 작업 때** · 사장님께 시안 먼저(금지 6의 6번 · 디자인 작업은 승인 전 병합하지 않는다).
- 후보 표(레퍼런스 이름 · 넣을 자리 · 왜 우리 브랜드에 맞나 · 길이 · reduced-motion · 폰 성능)는 별도 차례에 만든다.
