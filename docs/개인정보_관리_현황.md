## 2. 보안 — 인증·암호

| 항목 | 방식 | 상태 |
|---|---|---|
| 비밀번호 | salt + SHA-256 스트레칭(150라운드) · **원문 미보관** · 상수시간 비교 | 🟢 |
| 세션 | UUID 토큰(122비트) · 30일 만료 · 로그인 시 회전 | 🟢 |
| 비번 재설정 | HMAC 서명 링크 · 1시간 만료 · 상수시간 비교 | 🟢 |
| 로그인 실패 | 응답 모호화 + 지연 → 계정 존재 여부 노출 차단(enumeration 방어) | 🟢 |
| 전송 | 전 구간 HTTPS | 🟢 |
