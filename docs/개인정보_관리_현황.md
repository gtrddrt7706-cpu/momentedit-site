## 2. 보안 (🟢 견고 — 감사로 확인됨)

| 항목 | 방식 |
|---|---|
| 비밀번호 | salt + SHA-256 스트레칭 · **원문 미보관** · 상수시간 비교 |
| 세션 | UUID 토큰(122비트) · 30일 만료(로그인 시 잔여 15일 미만이면 연장) · **멀티기기: 유효 토큰 재사용**(2026-07-16 · 부부 폰·PC 동시 사용) · 회전(전 기기 로그아웃)은 비밀번호 재설정 시 — 유의: 로그인이 더 이상 기존 토큰을 무효화하지 않으므로, 유출 의심 시 반드시 비번 재설정 |
| 비번 재설정 | HMAC 서명 · 1시간 만료 |
| 로그인 실패 | 모호화 + 지연 → 계정 존재 여부 노출 차단 |
| 전송 | 전 구간 HTTPS |
| **접근통제** | 고객=본인 세션 토큰으로 **자기 행만** · 관리자=단일 게이트웨이 화이트리스트 · **외부 무인증으로 고객 마스터 조회 불가**(전수 확인) |

**🟡 배포 대기 (3차 · GAS 계층)**
8. 파기 완전화 — 상담예약·서명이미지·AI인계 PII도 함께 파기 · AI인계 30일 실파기
9. 결과물 6개월 링크 자동 제거 · 하객편지·청첩장 제3자 PII 예식 후 6개월 파기

11. 초상권/포트폴리오 동의 문구를 계약서·실제에 맞춰 통일

**🟡 배포 대기 (4차 · 감사 재실행 · 방어 강화)**
12. **CSV·수식 인젝션 방어** — 시트에 기록되는 고객 입력(이름·편지·문의·AI인계 등)이 `= + - @`로 시작하면 텍스트로 고정(엑셀 열람·시트 내 IMPORTXML/HYPERLINK 유출 벡터 차단)
13. **결과물 파기 순서 정정** — 만료 '당일 통지+즉시 삭제'가 겹치던 로직을 '통지 먼저 → 다음 실행에 삭제'로(계약서 12조③ 이행 · 도입 첫 실행 대량 무통지 삭제 방지)
14. **쿠키·GA4 정직 공개** — 처리방침 §8을 실제(GA4 방문통계·분석 쿠키·IP익명화)에 맞춰 정정(과거 '추적 쿠키 미사용' 문구가 GA4와 불일치하던 것)
15. **파기 동시성 안전** — 고객·부부 자동파기에 실행 락 + 쓰기 직전 재검증(배치 중 계약 발생 시 오파기 방지)
16. **개인번호 하드코딩 제거** · 입금확인 링크 이중클릭 락 · 관리자 비번 변경 시 기존 세션 무효화 · 변경수수료 콤마 총액 방어 · 보안 응답헤더(referrer·frame·nosniff 등)

**🟡 배포 대기 (5차 · 코드리뷰 8각도 → 검증 후 수정)**
17. **수식 인젝션 방어 완결** — 방어를 뚫던 경로 차단: (a) 파기 시 행 통째 재기록에서 보호가 벗겨져 수식이 되살아나던 것, (b) 미적용 싱크(질문flag·카톡연결·AI비용·결제로그·질문해결) 보강. 트리거를 Google Sheets 실제 수식 시작(`=`)로 정밀화해 정상 데이터(`+82` 전화·`-` 메모) 오염도 제거.
18. **파기 오파기 방지 강화** — 배치 도중 재활동(로그인 등)한 고객은 재검증에서 제외 · '이미 익명화' 판정을 전체 PII 기준으로(신원 4개만 지운 잔여 PII 영구보관 방지)
19. **결과물 파기 7일 유예 보장** — 통지일 기준 7일 지난 뒤 삭제(계약서 12조③ · 백로그도 최소 7일) · 이미 파기된 건엔 안내 미발송
20. **파기 락 점유 최소화** — 하위 시트 파기를 락 밖으로(주간 파기 중 고객 가입·결제 차단 시간 축소) · 계약 프리필/관리자 화면의 문자 총액 `NaN원`·`0원` 방어

## 6. 알려진 격차 (🔴 정직하게 기재 · 구조적으로 남는 것)

과장하지 않기 위해 **여전히 남는 것**을 명시한다.

- **레거시 청첩장 eventId**: 랜덤화 이전 생성 건은 추측 가능(계좌·라이브 영상은 게이트로 방어, 이름·부모성함은 노출 여지 · 기존 링크 보존 위해 소급 변경 안 함).
- **관리자 토큰**: localStorage 저장이라 관리자 페이지 XSS 시 탈취 위험(GAS 구조상 서버 세션 쿠키 어려움 · 렌더 이스케이프로 XSS 자체를 차단).
- **주간 백업**: 익명화 후에도 백업본에 최대 8주 원본 잔존(시간 한정 · 이후 rotation 소멸).
- **AI로 나가는 재무 PII**: 예식일·결제금액이 Anthropic으로(위탁 고지됨 · 계좌·서명·연락처는 제외해 범위 최소화).
- **Drive 결과물 원본**: 링크는 6개월 후 자동 제거하나 Drive 파일 자체 삭제는 관리자 수동(오삭제 방지).
