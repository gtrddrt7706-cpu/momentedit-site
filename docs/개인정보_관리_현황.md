## 1. 무엇을 · 어디에 저장하나

| 구분 | 내용 |
|---|---|

## 2. 보안 (🟢 견고 — 감사로 확인됨)

| 항목 | 방식 |
|---|---|
| 비밀번호 | salt + SHA-256 스트레칭 · **원문 미보관** · 상수시간 비교 |
| 세션 | UUID 토큰(122비트) · 30일 만료 · 로그인 시 회전 |
| 비번 재설정 | HMAC 서명 · 1시간 만료 |
| 로그인 실패 | 모호화 + 지연 → 계정 존재 여부 노출 차단 |
| 전송 | 전 구간 HTTPS |
| **접근통제** | 고객=본인 세션 토큰으로 **자기 행만** · 관리자=단일 게이트웨이 화이트리스트 · **외부 무인증으로 고객 마스터 조회 불가**(전수 확인) |

## 6. 알려진 격차 (🔴 정직하게 기재 · 구조적으로 남는 것)

과장하지 않기 위해 **여전히 남는 것**을 명시한다.

- **레거시 청첩장 eventId**: 랜덤화 이전 생성 건은 추측 가능(계좌·라이브 영상은 게이트로 방어, 이름·부모성함은 노출 여지 · 기존 링크 보존 위해 소급 변경 안 함).
- **관리자 토큰**: localStorage 저장이라 관리자 페이지 XSS 시 탈취 위험(GAS 구조상 서버 세션 쿠키 어려움 · 렌더 이스케이프로 XSS 자체를 차단).
- **주간 백업**: 익명화 후에도 백업본에 최대 8주 원본 잔존(시간 한정 · 이후 rotation 소멸).
- **AI로 나가는 재무 PII**: 예식일·결제금액이 Anthropic으로(위탁 고지됨 · 계좌·서명·연락처는 제외해 범위 최소화).
- **Drive 결과물 원본**: 링크는 6개월 후 자동 제거하나 Drive 파일 자체 삭제는 관리자 수동(오삭제 방지).
