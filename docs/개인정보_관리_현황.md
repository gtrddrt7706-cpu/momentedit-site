## 1. 무엇을 · 어디에 저장하나

| 구분 | 내용 |
|---|---|

## 2. 보안 (🟢 견고 — 감사로 확인됨)

| 항목 | 방식 |
|---|---|
| 비밀번호 | salt + SHA-256 스트레칭 · **원문 미보관** · 상수시간 비교 |
| 세션 | UUID 토큰(122비트) · 30일 만료 · 로그인 시 회전 |
| 비번 재설정 | HMAC 서명 · 1시간 만료 |
| 로그인 실패 | 모호화 + 지연 → 계정 존재 여부 노출 차단 |
| 전송 | 전 구간 HTTPS |
| **접근통제** | 고객=본인 세션 토큰으로 **자기 행만** · 관리자=단일 게이트웨이 화이트리스트 · **외부 무인증으로 고객 마스터 조회 불가**(전수 확인) |

## 6. 알려진 격차 · 개선 로드맵 (🔴 정직하게 기재)

과장하지 않기 위해 **아직 남은 것**을 명시한다. 모두 조치 계획에 올라 있다.

- **결과물 사진 6개월 삭제**: 방침은 약속하나 현재는 통지만 · 자동 삭제/링크 만료 미구현.
- **제3자 PII 영구보관**: 하객편지·청첩장 부모성함/계좌가 파기 트리거 없이 잔존.
- **레거시 청첩장 eventId**: 랜덤화 이전 생성 건은 추측 가능(계좌·영상은 게이트로 방어, 이름·부모성함은 노출 여지).
- **관리자 토큰**: localStorage 저장이라 관리자 페이지 XSS 시 탈취 위험(구조적 · 서버 세션화 검토).
- **주간 백업**: 익명화 후에도 백업본에 최대 8주 원본 잔존(시간 한정).
- **AI로 나가는 재무 PII**: 예식일·결제금액이 마스킹 없이 Anthropic으로(위탁 고지됨 · 범위 최소화됨).
